1. Conceptos básicos del cobro

Cuando el cliente trae plata para saldar deuda, el sistema distribuye el pago automáticamente con el método FIFO (First In First Out): se salda primero la deuda más antigua y luego las siguientes.

Venta antigua
$3.000
←
Venta media
$2.500
←
Venta nueva
$1.500
←
Pago
$5.500

FIFO: el pago de $5.500 cancela la antigua ($3.000) + la media ($2.500). La nueva ($1.500) sigue abierta.

Tres tipos de operación de cobro

OperaciónCuándo se usaResultado
Pago de deuda (FIFO) Cliente paga su deuda total o parcial Si paga más → excedente a Saldo a favor
Adelanto / Saldo a favor Cliente deja plata sin tener deuda Todo el monto va a Saldo a favor
Aplicar favor Cliente prefiere usar saldo a favor para deuda Se hace desde Nueva Venta, no aquí

2. Dónde está el módulo de cobros

Sidebar → Venta → Cuentas Corrientes

Pantalla "Cuentas Corrientes" — Aging + Top deudores

La pantalla muestra:

  • Aging — 4 tarjetas con la suma de deudas según antigüedad: 0-30 / 31-60 / 61-90 / 90+ días.
  • Top deudores — lista de los 20 clientes con más deuda + buscador.

3. Paso 1 — Encontrar al cliente

1

Buscar y elegir

  1. En la pantalla Cuentas Corrientes, escribir parte del nombre o documento en el buscador.
  2. Hacer clic en la fila del cliente.
  3. Se abre la pantalla individual del cliente con saldos + movimientos.

4. Paso 2 — Revisar saldos y movimientos

2

Pantalla individual del cliente

Pantalla del cliente — saldos + tabla de movimientos

4 tarjetas de saldo:

  • 🔴 Deuda corriente — lo que el cliente debe ahora.
  • 🔵 Seña reservada — Seña activa.
  • 🟢 Saldo a favor — plata del cliente disponible.
  • ⚪ Estado / Plazo — Activo / En revisión / Bloqueado + días configurados.

Tabla de movimientos: todas las operaciones del cliente en orden cronológico, con saldos después de cada movimiento. Útil para ver el historial completo.

5. Paso 3 — Hacer clic en "Registrar pago"

3

Botón verde "Registrar pago"

En la esquina superior derecha. Solo está habilitado si el cliente tiene deuda corriente > 0.

⚠ Si está deshabilitado → el cliente ya no tiene deuda. Si igual quiere dejar plata, usar "Adelanto / saldo a favor" (ver paso 4).

6. Paso 4 — Llenar el modal de pago

4

Modal "Registrar pago — [Cliente]"

Modal "Registrar pago" — campos completos
CampoQué poner
Tipo de operación Pago de deuda (FIFO) — si hay deuda. Distribuye automáticamente entre las deudas más viejas.
Adelanto / saldo a favor — si NO hay deuda, o el cliente quiere dejar plata para futuras compras.
Monto Cuánto está pagando. Pre-cargado con la deuda total. Editar si paga menos o más.
Si paga más → el excedente va a Saldo a favor automáticamente.
Método de pago Efectivo, transferencia, tarjeta, mercado pago, etc. (NO aparecen Crédito / Favor / Seña — son virtuales).
N° de recibo Obligatorio. Número del talón físico o recibo que se entrega al cliente.
Nota Opcional. Para auditoría.

7. Paso 5 — Confirmar

5

Hacer clic en "Registrar pago"

El sistema:

  • Crea el registro de pago.
  • Distribuye el monto con FIFO (más vieja primero).
  • Si sobra, lo acredita como saldo a favor.
  • Actualiza los chips del cliente (Deuda baja, Favor sube si hay excedente).
  • Registra el movimiento en el ledger.
✓ Aparece toast verde de confirmación.
✓ La pantalla se refresca con los nuevos saldos.
✓ Aparece una nueva fila "Pago recibido" en la tabla de movimientos.
✓ Entregar el comprobante físico al cliente.

8. Casos especiales

El cliente paga más de lo que debe

Deuda $5.000, paga $7.000 → cancela $5.000 + acredita $2.000 a favor. El chip 🟢 sube de $0 a $2.000.

El cliente paga sin tener deuda (adelanto)

  1. Tipo → "Adelanto / saldo a favor".
  2. Monto que entrega.
  3. Método y N° de recibo.
  4. Confirmar. → Todo va a saldo a favor.

Pago parcial

Procedimiento normal con tipo "FIFO". Las deudas más viejas se cancelan en orden. Las nuevas siguen abiertas.

El cliente quiere usar su saldo a favor

Esto se hace desde Nueva Venta, no desde Cuentas Corrientes:

  1. Abrir Nueva Venta con ese cliente.
  2. Ir al modal de pago.
  3. Hacer clic en el chip 💵 Usar Saldo a favor: $XXX.

Devolución de mercadería + saldo a favor

  1. Devolución en módulo de ventas (botón "Devolver Ropa").
  2. El sistema acredita el monto como saldo a favor automáticamente.
  3. El cliente puede pedir efectivo o usarlo en compras futuras.

El cliente dice que ya pagó pero su deuda sigue

  1. Verificar la tabla Movimientos del cliente.
  2. Si el pago no aparece, posibles causas:
    • Operador anterior no lo registró.
    • Se registró a otro cliente con nombre similar.
  3. Buscar recibo físico → verificar quién atendió → registrar el pago atrasado.

9. Cambiar estado del cliente (admin/gerente)

!

Política del cliente

Para cambiar de Activo / En revisión / Bloqueado:

  1. Pantalla del cliente → "Política" (esquina superior derecha).
  2. En el modal cambiar estado, límite o plazo.
  3. Guardar.
📋 Resumen de estados:
  • Activo — venta normal a crédito.
  • En revisión — pausa temporal (puede cobrar pero no vender más a crédito).
  • Bloqueado — sin crédito por completo.
⚠ Solo admin / gerente deberían cambiar el estado. El cambio queda registrado.

10. Errores comunes

MensajeCausaSolución
"Indique un número de recibo" Campo N° de recibo vacío Escribir el número del talón físico
"El monto debe ser mayor a cero" Monto = 0 Ingresar un monto > 0
Botón "Registrar pago" deshabilitado Cliente no tiene deuda Usar tipo "Adelanto / saldo a favor"
El monto se aplicó pero la deuda no bajó tanto como esperaba FIFO aplicó descuentos / intereses pendientes primero Revisar tabla de movimientos para detalle

11. Resumen rápido — cobro estándar

🚀 Flujo en 5 pasos

  1. Sidebar → Cuentas Corrientes → buscar al cliente → click.
  2. Click en "Registrar pago".
  3. Llenar: Monto, Método, N° de recibo.
  4. Click en "Registrar pago" → confirmar.
  5. Entregar recibo físico al cliente.

✓ El cliente se va con su deuda actualizada (o saldada).
✓ El sistema actualiza saldos automáticamente con FIFO.
