1. Conceptos básicos del crédito

Concepto Significado Quien debe a quién
Crédito (cta. corriente, fiado) El cliente se lleva la mercadería sin pagar el total. Lo que falta queda en su cuenta. Cliente → Tienda
Seña (reserva, anticipo) El cliente paga por adelantado para reservar mercadería. Tienda → Cliente (debe entregar)
Saldo a favor (favor) Plata que el cliente tiene a su disposición en la tienda (devoluciones, etc.). Tienda → Cliente (puede usar)

Estados del cliente (política de crédito)

✓ ACTIVO Acepta nuevas ventas a crédito.
⚠ EN REVISIÓN Pausado, no acepta deudas nuevas.
✕ BLOQUEADO No acepta crédito por ningún motivo.

2. Requisitos para vender a crédito

📋 Antes de empezar:
  • El cliente debe estar identificado (DNI o CUIT). Si nunca compró, ver "Cliente nuevo en el momento" abajo.
  • Estado del cliente debe ser Activo. Si es "En revisión" o "Bloqueado", el método "Crédito" no aparece.
  • El monto a fiar no debe superar el límite de crédito del cliente (si tiene uno).

3. Paso 1 — Identificar al cliente

1

Tres formas de elegir cliente

Opción A — Cliente conocido (CUIT o DNI):

Pantalla "Nueva Venta" — campo CUIT/DNI con autocompletado

Opción B — Cliente conocido por nombre:

  • En la lista de la derecha, "Lista de los Clientes", escribir parte del nombre o documento.
  • Hacer clic en el cliente para seleccionarlo.

Opción C — Cliente nuevo en el momento (sin documento):

Cliente nuevo: Tab vacío → número de serie temporal automático + foco al nombre
  1. Hacer clic en el campo Nº CUIT / DNI.
  2. Sin escribir nada, presionar Tab.
  3. El sistema asigna automáticamente un número temporal: S9-00001 (donde 9 = ID de la tienda).
  4. El cursor pasa al campo Nombre y Apellido.
  5. Escribir el nombre del cliente y continuar.
💡 Más adelante… Cuando el cliente traiga su CUIT/DNI real, el administrador edita la ficha y cambia el documento temporal por el real. La deuda y el historial se mantienen intactos.

4. Paso 2 — Verificar saldos del cliente

2

Chips de saldo

Tarjeta del cliente con chips de saldo + estado
  • 🔴 Deuda — monto que el cliente debe.
  • 🔵 Seña — monto que ya pagó por adelantado.
  • 🟢 A favor — saldo disponible para usar.
  • ⚠ EN REVISIÓN o ✕ BLOQUEADO — no se puede vender a crédito.

5. Paso 3 — Cargar los productos

3

Agregar productos a la venta

Como en cualquier otra venta: escanear código, elegir talles/colores, ingresar cantidad, etc.

6. Paso 4 — Elegir "Crédito" como método de pago

4

Modal de pagos

Modal de pagos con "Crédito" seleccionado
  1. Hacer clic en el botón de pagos del POS.
  2. En el desplegable buscar y elegir "Crédito".
  3. Ingresar el monto que queda fiado:
    • Fiado total — todo el monto va a Crédito.
    • Fiado parcial — agregar dos líneas: una de pago en cash + una de Crédito.
  4. Confirmar el modal.
⚠ Si "Crédito" no aparece en el desplegable, significa que:
  • No hay cliente seleccionado, o
  • El cliente está "En revisión" o "Bloqueado".

7. Paso 5 — Aplicar Saldo a favor (opcional)

5

Saldo a favor → opt-in

Si el cliente tiene saldo a favor, en la parte superior del modal aparece un chip clicable: 💵 Usar Saldo a favor: $1.200

🛑 Importante: el saldo a favor NO se descuenta automáticamente. Solo se aplica si el operador hace clic en el chip. Esto evita consumir el saldo del cliente sin su autorización.

8. Paso 6 — Confirmar la venta con F2

6

Generar Venta

  1. Verificar que Total = suma de pagos.
  2. Presionar F2 o el botón "Generar Venta".
  3. El sistema:
    • Crea la venta normalmente.
    • Suma el monto de Crédito a la deuda corriente del cliente.
    • Registra el movimiento en el ledger del cliente.
    • Imprime el ticket.
  4. Aparece un toast de confirmación.
💡 Cliente nuevo + nombre + F2: Si llenaste solamente el nombre (sin documento) y presionás F2, el sistema crea el cliente temporal automáticamente con el número de serie y procede con la venta. ¡No hace falta hacer Tab antes!

9. Casos especiales

Cliente apurado, solo da el nombre

  1. Cargar productos.
  2. Escribir solo el nombre en Nombre y Apellido (sin documento).
  3. Cargar pagos (Crédito por monto total).
  4. F2: el sistema crea el cliente temporal y termina la venta en una sola tecla.

Cliente con deuda alta — quiere fiar más

  1. Verificar el chip Deuda en la tarjeta.
  2. Si supera el límite, "Crédito" se rechaza con mensaje de error.
  3. Hablar con el cliente: que pague una parte primero, o esperar que el admin suba el límite.

Cliente bloqueado

NO hacer la venta. Solo el administrador puede cambiar el estado del cliente desde Cuentas Corrientes → Política.

Suspender una venta a crédito

Si el cliente está apurado o falta algún dato:

  1. Hacer clic en Suspender.
  2. La venta queda guardada con cliente, productos, vendedor y provincia.
  3. Cuando el cliente vuelva, abrir "Ventas Suspendidas" en la columna derecha → click → continuar.

10. Errores comunes

MensajeCausaSolución
"Crédito" no aparece Cliente no seleccionado, o estado distinto de Activo Verificar tarjeta del cliente; hablar con admin si está bloqueado
Cliente sin documento válido Cliente legacy sin DNI/CUIT Editar ficha y agregar documento; o usar Tab para temporal
Excede el límite de crédito Suma de deuda + nueva venta > límite Cobrar antes; o pedir al admin que aumente el límite
Aparece "Consumidor Final" en lugar del nombre Operador no seleccionó cliente — la venta sale anónima Seleccionar cliente o usar Tab + F2 para temporal

11. Resumen rápido — cliente nuevo, fiado total

🚀 Flujo en 5 pasos

  1. Click en CUIT → Tab → número temporal asignado.
  2. Escribir nombre del cliente.
  3. Cargar productos.
  4. Pagos → seleccionar "Crédito" → ingresar monto total.
  5. F2 → confirmar.

✓ El cliente se va con la mercadería. El sistema sabe cuánto debe.
