# Manuales

Los manuales `.md` que usa el AI agent (knowledge base) **se movieron a
`api-ventago/manuales/`** (2026-09-22). Ahí se copian a la imagen Docker del backend.

Antes estaban acá, pero el servidor de producción solo despliega el repositorio
`api-ventago`: esta carpeta nunca llegaba y el AI respondía sin ningún manual.

Guía de formato: `api-ventago/manuales/README.txt`.

En esta carpeta quedan los manuales para clientes (docx / pdf / html) y los scripts
`generate_*_manual.js`.
