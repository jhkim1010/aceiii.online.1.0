| app → backend | all data via HTTPS API; no local DB pool |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-12 | Information Disclosure | JWT stored in plaintext (SharedPreferences) | mitigate | flutter_secure_storage only; token key `mobile_token`; SharedPreferences forbidden for tokens (SPEC) |
| T-37-13 | Spoofing | stale session used after re-login elsewhere | mitigate | dio onError handles 401 MOBILE_SESSION_EXPIRED → deleteAll + redirect /login + toast (criterion 12) |
| T-37-14 | Elevation of Privilege | Sucursal selector exposing branches outside scope | mitigate | selector options sourced ONLY from server scopeBranchIds; server re-enforces on every request (Wave 1) |
| T-37-15 | Tampering | app-side scope override | accept | scope is display-only client state; backend MobileScopeGuard is authoritative (D-02) |
</threat_model>
