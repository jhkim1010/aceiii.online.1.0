<objective>
Build the vendedor MVP screens (the 1차 출시): Home (QR-first), Catálogo (search + stock pills), the signature
color×size variant matrix detail (D-15 — port of web VariantsStockVenta), QR scanner (deeplink → detail),
Comanda/Carrito ("Mandar a Caja", no payment UI), and Done/En espera. This ships vendedor value independently
of revendedor (Wave 5).

Purpose: A vendedor scans a percha QR (D-14 scan-to-detail), sees per-cell stock across their store's branches
(own-branch bold + otras read-only), types quantities directly into the matrix (D-15), and sends the cart to the
desktop Caja queue as a suspended sale (D-13). Own-branch selling only — no cross-branch traslado (UI-D2), no AI
try-on (UI-D1).

Output: All vendedor screens + repositories/providers against the Wave 2 backend + a matrix widget test.
Ends with a blocking human-verify UAT (U1-U6) in dev.

SCOPE DECISIONS (authoritative, override mockup/SPEC):
- UI-D1: "Probar con foto" renders disabled + "Próximamente". No camera/AI code.
- UI-D2: cell input max = own-branch available. Other branches are read-only `otras:N`. Remove `over`(red)/traslado
  banner / xbranch chips / cross-branch allocation.
- D-13: Comanda has NO payment-method / cash-box UI. CTA = "🧾 Mandar a Caja" → suspended sale.
- D-15: matrix cells use direct numeric input (NO +/- stepper). Cart line stepper is fine for adjusting whole lines.
</objective>
