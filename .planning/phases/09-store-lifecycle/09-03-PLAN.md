### StoresUnifiedView 상세 스펙
**상단 KPI 행** (4 카드):
```
┌─────────────┬─────────────┬─────────────┬──────────────────┐
│ 🎁 Trial    │ ✅ Activas  │ ⏸ Suspend.  │ ⚠ Por vencer ≤3d │
│    2        │    12       │    1        │    1             │
└─────────────┴─────────────┴─────────────┴──────────────────┘
```
- 데이터: `GET /store/lifecycle-stats` 단일 호출
- 카드 클릭 시 해당 탭으로 이동

**탭 스트립**:
```
Todas | 🎁 Trial (2) | ✅ Activas (12) | ⏸ Suspendidas (1) | 📦 Archivadas | 🗑 Papelera
```
- 쿼리 파라미터로 상태 유지 `?tab=trial`
- 탭 전환 시 `GET /store?state=TRIAL&page=1&pageSize=20`

**테이블 컬럼**:
| Matriz | Admin | Estado | Trial/Plan | Sucursales | Última actividad | Acciones |
|---|---|---|---|---|---|---|
| 로고 + 이름 + CUIT | admin 이메일 | `LifecycleChip` | `TrialProgressBar` 또는 "—" | 지점 수 | relative time | ⚙ dropdown |

- 액션 드롭다운: "Ver detalle", "Activar", "Suspender", "Archivar", "Extender trial"
- 허용되지 않는 전이는 disabled

### StoreDetailView 상세 스펙
- 상단: 로고 + 매장명 + `LifecycleChip` + trial 카운트다운 (trial일 때)
- 우측: `LifecycleActions` 버튼 그룹
  - [▶ Activar] - TRIAL/SUSPENDED 일 때 활성
  - [⏸ Suspender] - ACTIVE 일 때 활성
  - [📦 Archivar] - SUSPENDED 일 때 활성
  - [↩ Restaurar] - ARCHIVED 일 때 활성
  - [⏰ Extender trial] - TRIAL 일 때 활성 (모달로 새 trialEndsAt 입력)
- 버튼 클릭 시 사유 입력 모달 → `PUT /store/:id/{action}` body `{reason}`
- 하단: **기존 Sucursales / Terminales / Apps 탭 유지** (기존 컴포넌트 재사용)
- 신규: **Historial** 탭 — `lifecycleReason` 이력 타임라인
- Breadcrumb: `Admin / Tiendas / [탭 출처] / [매장명]`

### 상태/데이터 관리
- Redux slice: `storesLifecycleSlice` (선택 탭, 페이지네이션, 캐시)
- KPI stats 는 30초 캐시 (refresh 버튼)
- 탭 전환 시 shallow routing (`router.replace(url, undefined, {shallow: true})`)

## Success Criteria

1. 사이드바에서 "Registros" 메뉴가 사라지고 Tiendas 하나만 남음
2. `/admin/tiendas` 진입 시 KPI 4카드 + 탭 + 테이블 표시
3. 탭 클릭 시 URL `?tab=...` 업데이트 + 데이터 재조회 (full reload 없음)
4. 테이블 행 클릭 시 `/admin/tiendas/[id]` 로 이동, **사이드바 active 유지** (점프 없음)
5. Breadcrumb에 출처 탭 이름이 표시됨
6. 상세 페이지에서 상태 전이 버튼 동작 (허용 전이만 enabled)
7. Trial 매장에 `TrialProgressBar` 로 "14/30 días" 표시
8. 만료 임박(≤3일) 매장은 빨간 배지로 강조
9. 기존 `/admin/registros` 북마크가 `/admin/tiendas?tab=trial` 로 리디렉트
10. 사이드바 리렌더링 최적화 (React.memo 유지)

## Steps

1. Registros 메뉴 제거 + Tiendas 뱃지 props 추가
2. `LifecycleChip`, `TrialProgressBar` 공통 컴포넌트 작성
3. `LifecycleKpiCards` + `/store/lifecycle-stats` 호출
4. `LifecycleTabs` + 쿼리 파라미터 동기화
5. `StoresTable` 통합 (기존 list + with-admin 컬럼 병합)
6. `StoresUnifiedView` 조립
7. `StoreDetailView` 신규 경로 `/admin/tiendas/[id]`
8. `LifecycleActions` + 사유 입력 모달
9. `LifecycleHistory` 탭
10. 기존 `detalle/[id]` 삭제 + 리디렉트 설정
11. 기존 `registros` 삭제 + 리디렉트 설정
12. E2E 수동 테스트: 매장 생성 → Trial → Activate → Suspend → Archive 전이

## Risks

- **기존 상세 페이지 호환성**: 현재 `detalle/[id]` 의 Sucursales/Terminales/Apps 탭 컴포넌트 재사용 시 props 시그니처 확인
- **탭 전환 시 리렌더링**: Redux + shallow routing 조합 검증 필요
- **번역(i18n)**: 신규 문자열 다수 → es/ko 양쪽 번역 키 추가
- **ESLint 빌드 에러**: newline-before-return 주의
