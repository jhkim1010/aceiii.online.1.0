| 백엔드 | api `6bc00a1` | Jenkins ✅ |
| 프론트 | app `dc04024` | front #541 ✅ |

### 규칙 (바꾸려면 여기부터 읽을 것)
- 부호 있는 % 하나: 양수=Recargo, 음수=Descuento
- **옵션의 NULL = "결제수단 기본값 상속", 0 = "이 은행은 면제"** — 뜻이 다르다.
  해석 함수가 `??` 를 쓴다. `||` 로 바꾸면 면제 설정이 조용히 무시된다(테스트가 잡는다).
- % 는 **그 결제수단으로 낸 금액에만** 적용. 잔액 계산은 항상 base(상품분) 기준.
- 조정분은 Recargo/Descuento 항목으로 자동 기록 → 영수증·리포트 수정 불필요.
  재계산 전에 이전 자동 항목(`AUTO_ADJUST_FLAG`)을 걷어낸다. 안 하면 모달 재저장 시 누적된다.
- 금액은 정수 반올림 — 안 하면 `sum(결제)===totalAmount` 완납 판정이 소수점으로 깨진다.

### ★ 아직 실사용 확인 안 됨
운영에서 한 건 판매해 **Recargo 가 판매상세·영수증에 찍히는지, 상태가 Pagado 인지** 확인 필요.

계산 규칙 사본이 둘이다(불가피 — 프론트가 백엔드를 import 못 함). 바꾸면 **양쪽 같이**:
- `api-ventago/src/app/payment-methods/payment-adjust.util.ts` (테스트 16건 있음)
- `ventago-app/src/utils/payment-adjust.ts`

**격언 데이터** (`migrations/2026-08-06-daily-quotes-seed-full.sql`, 재실행 안전):
- 성경 1,000 × 3언어 — 전부 퍼블릭 도메인. es=RV1909 / en=KJV / ko=개역성경
  (출처 `scrollmapper/bible_databases`, MIT. 같은 저장소 KorHKJV 는 저작권 있어 미사용)
- 철학 152 × 3언어 — 저작권 소멸 고전 저자 문구를 **직접 번역**(`translation='Traducción propia'`)
  다국어 퍼블릭도메인 철학 데이터셋이 없어서다. 늘리려면 같은 방식으로 추가.
- **세 언어가 같은 절을 같은 seq 로** 갖는다 → 언어를 바꿔도 그 날 구절이 같다.

### ★ 손대기 전에 알아야 할 것
- **행을 지우거나 `is_active=false` 로 끄면 seq 에 구멍이 난다.** 서비스가 count 로 세고
  날짜로 seq 를 골라 1건을 찾기 때문에, 구멍이 생기면 그 날은 격언이 안 나온다(warn 로그만).
  문구를 빼려면 지운 뒤 재부여할 것 — SQL 은 마이그레이션 파일 주석에 있다.
- **로그인 화면은 인증 전이라 매장을 서버에 못 묻는다.** 공개 API 에 매장 식별자를 넘기지
  않기로 한 설계를 지키려고, 로그인 후 받은 설정을 단말 localStorage(`ventago.frasePref`)에
  적어두고 다음 로그인 화면이 읽는다 → **설정 변경은 그 단말의 "다음 로그인"부터 반영**된다.
- 격언 조회 실패는 **언제나 조용해야 한다**(`silenceErrorToast` + 4s 타임아웃). 로그인은
  매장에서 가장 깨지면 안 되는 화면이라, 장식 때문에 전역 빨간 배너가 뜨면 안 된다.
- 배경은 자체 SVG(`public/images/login-bg/`). 외부 사진 API 를 로그인 화면이 직접 부르면
  오프라인·CSP·레이트리밋·출처표기 네 가지가 한꺼번에 붙는다. 교체법은 그 폴더 README.

## 3-0. (이력) 백엔드 1차 — 스키마 + 공개 API (api `5022e7f`, build #625)

| 항목 | 상태 |
|---|---|
| `daily_quotes` + `store_configs.quote_source/quote_lang` | 로컬 5432 + 운영 5434 양쪽 ✅ |
| 시드 14건 (성경 7 + 철학 7) | 양쪽 ✅ |
| `GET /daily-quotes/today` (@Public) | 운영에서 curl 검증 ✅ |

운영 검증 결과: 인증 없이 200 / 같은 날 동일 문구 / 다음 날 다른 문구 /
잘못된 source → `{"quote":null}`.

**번역본은 퍼블릭 도메인만** (사용자 결정 2026-08-06):
es 성경 = **Reina-Valera 1909**(저작권 만료). RV1960 등 현대 번역 금지.
철학은 고전 저자. `translation` 컬럼에 번역본명 보존 — 나중에 출처 감사 가능.

### 지켜야 할 설계 결정
- **공개 엔드포인트는 매장 식별자를 받지 않는다.** 받으면 인증 없이 "그 매장 설정"을
  외부에서 캐물을 수 있다. 매장 설정은 로그인 후 내려주고, 공개 API 는 언어·출처만 받는다.
- **날짜 계산은 UTC 고정.** 로컬 TZ 로 하면 서버 시간대에 따라 하루 밀려 "어제 격언"이 나온다.
  유틸이 `Date.now()` 를 부르지 않고 호출부가 날짜를 넘긴다(자정 경계 테스트 가능).
- **count → seq 로 1건 조회.** 전체를 읽어 고르면 1,000개일 때 매 로그인마다 1,000행.
- `seq` 는 (source,lang) 안에서 **0..N-1 연속**이어야 한다. 구멍이 있으면 그 날 격언이
  안 나온다(서비스가 warn 로그를 남긴다).
- 기본값 `none` → **켜지 않은 매장의 로그인 화면은 지금과 동일.**

### 남은 작업 → **위 §3 로 이동 (대부분 완료)**

## 4-B. 사이드바 그룹 클릭 바로가기 (app `6251814`)

Venta → `/nueva-venta`, Producto → `/productos`, Materia prima → `/materia-prima/inventario`.
그룹을 펼친 뒤 항목을 또 누르던 두 번 클릭을 없앴다.

- `menuRegistry.ts` 의 `defaultPath` 한 줄로 추가/변경한다.
- **`directPath` 와 다르다** — `directPath` 는 부메뉴 자체를 없애 링크 하나로 만든다.
  `defaultPath` 는 부메뉴를 그대로 둔 채 기본 화면으로만 보낸다.
- 이동해도 그룹을 접지 않는다. 접으면 방금 연 화면의 형제 메뉴가 사라져 클릭이 되레 는다.
- 권한이 없어 그 화면이 children 에서 빠진 사용자에게는 `defaultPath` 를 안 붙인다
  (붙이면 눌러도 403 나는 메뉴가 된다).
