# Phase 99 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

이 Phase 는 새 디자인 언어를 만들지 않는다. 기존 Ventago 다크 네이비+골드 테마(MUI 5)와
`pages/configuracion/index.tsx` 의 `HUB_TABS` 패턴을 그대로 재사용한다. 이 문서는 (1) 신규로
생기는 화면(Dispositivos 탭·Acceso para soporte 탭)의 레이아웃·카피 계약, (2) 기존 화면에
탭/진입점을 추가할 때 지켜야 할 라벨·아이콘·게이트 표기 규칙, (3) Carpetas compartidas 의
막다른 화면을 없애는 빈 상태/오류 상태 카피를 못박는다.

## Spacing Scale

Declared values (must be multiples of 4) — 기존 MUI 테마 8px 기준 그대로 재사용, 이 Phase 가 새 값을 도입하지 않는다:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 아이콘-라벨 간격, Chip 내부 패딩 |
| sm | 8px | 카드 내부 요소 간 간격 |
| md | 16px | 카드 내부 섹션 간격, 폼 필드 간격 |
| lg | 24px | Dispositivos 탭 3-카드 그리드 gap(`Grid spacing={3}`), Acceso para soporte 2-카드 그리드 gap |
| xl | 32px | 허브 탭 콘텐츠 영역 패딩(`Box sx={{ p: 4 }}` — 기존 `configuracion/index.tsx:201` 그대로 재사용) |
| 2xl | 48px | 해당 없음(이 Phase 범위에서 미사용) |
| 3xl | 64px | 해당 없음 |

Exceptions:
- **표 행 높이 30px** — CLAUDE.md Phase 79 고정값(`TABLE_ROW_HEIGHT`). 이 Phase 가 만지는 화면 중 표가 있는 곳(Carpetas compartidas 폴더 목록, Reportes v2 목록)은 기존 `FullTable`/표 컴포넌트를 그대로 쓰므로 자동으로 맞는다 — 새로 표를 만들 경우에만 상수를 import.
- 그 외 예외 없음.

## Color

기존 다크 네이비 + 골드 팔레트(sketch-findings `theme.md`, LOCKED) 그대로 — 이 Phase 는 새 색을 도입하지 않는다.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0f1e` | 페이지 배경(`<body>`) |
| Secondary (30%) | `#1a1a2e` | Card/Dialog/허브 Tabs 패널 표면 — Dispositivos 3-카드·Acceso para soporte 2-카드 전부 이 표면색 |
| Accent (10%) | `#f5a623` (gold) | 아래 목록만 |
| Destructive | `#ef4444` | 아래 목록만 |

Accent(gold) reserved for:
- 활성 허브 탭의 아이콘·밑줄(기존 `Tabs`/`Tab` MUI 기본 primary 색 적용 그대로)
- 각 카드의 주 CTA 버튼 배경(예: "Registrar carpeta", "Generar token", "Vincular" — 기존 패턴 재사용, 신규 버튼도 동일 규칙)
- 신규 섹션 라벨 `CONEXIONES`/`SOPORTE DE VENTAGO` 는 기존 `GENERAL`/`OPERACIÓN`/`AVANZADO` 와 동일하게 `text.disabled` 회색이다 — 섹션 라벨 자체에는 gold 를 쓰지 않는다(혼동 금지, 기존 규약 유지).

Destructive(`#ef4444`) reserved for:
- "Quitar"(reloj) · "Revocar"(Acceso de Ventago) · "Eliminar"(carpeta compartida) 버튼과 해당 아이콘 — 전부 기존 화면에 이미 적용된 패턴, 이 Phase 는 유지만 한다.

## Copywriting Contract

이 Phase 가 **신규로 만드는** 화면·상태만 명시한다. 기존 화면(RelojesCard 내부, AccesoVentagoView 내부, TokenSoporteView 내부)의 기존 카피는 변경하지 않는다 — 탭 바깥 레이아웃(어디에 놓이는지, 카드 헤더에 뭐라고 적는지)만 이 Phase 의 범위다.

### 1. Configuración › Conexiones › Dispositivos (신규 탭, D-02)

3-카드 그리드(`Grid container spacing={3}`, 데스크톱 `md=4` 각 1/3, 모바일 `xs=12` 세로 스택). 각 카드는 아이콘 + 타이틀 + 1줄 설명 + CTA.

| 카드 | 아이콘 | 타이틀 | 설명(1줄) | CTA |
|---|---|---|---|---|
| 1 | `tabler:device-mobile` | App de vendedores | "Cada vendedor necesita un token de dispositivo para vender desde el celular." | "Abrir Vendedores →" → `/configuracion?tab=ventas` (기존 Vendedores 목록의 "Dispositivos" 버튼은 그대로 둔다, 삭제하지 않음) |
| 2 | `tabler:truck-delivery` | App de despacho | "El equipo de despacho usa un token propio para escanear los pedidos online." | "Abrir Control de envíos →" → `/ventas-online` (기존 "Dispositivos" 버튼 유지) |
| 3 | (없음, `RelojesCard` 내장) | Relojes Galaxy Watch | `RelojesCard` 컴포넌트를 그대로 임베드(기존 카피·동작 변경 없음) | `RelojesCard` 내부 "Vincular" 버튼 그대로 |

- 카드 1·2 는 **딥링크일 뿐 기능 재구현이 아니다** — 기존 모달(`VendedorDispositivosModal`, `DispositivosModal`)은 그대로 각자 화면에 남는다(연구 결론: 재작업 최소화).
- 탭 콘텐츠 상단에 `Typography variant='body2' color='text.secondary'` 로 1줄 안내: "Cada canal de venta tiene su propio token de dispositivo. Elegí dónde conectarlo." (3-카드 위, 섹션 타이틀 아래)

### 2. Configuración › Soporte de Ventago › Acceso para soporte (신규 탭, D-01)

2-카드 그리드(`Grid container spacing={3}`, 데스크톱 `md=6` 각 1/2, 모바일 `xs=12` 세로 스택). 각 카드 헤더에 "누가·얼마 동안·무엇을 할 수 있나"를 1줄로 명시 — 이게 이 탭 전체의 존재 이유다(두 접근 수단이 다르다는 것을 사용자가 즉시 구분하게).

| 카드 | 타이틀 | 디스크립터(카드 헤더, 1줄) | 내부 컴포넌트 |
|---|---|---|---|
| 1 | Token de soporte | "Para el equipo de soporte de CoolSistema · dura 5 minutos · puede ver y modificar los datos de tu tienda." | `TokenSoporteView embedded` (기존, 변경 없음) |
| 2 | Acceso de Ventago | "Para un agente de Ventago · elegís 30 min o 2 h · acceso acotado a certificado AFIP, cierre de sesión de terminal o importación legacy." | `AccesoVentagoView` (기존, 변경 없음) |

- 두 카드 사이에 `Divider` 세로선(데스크톱) — 두 수단이 **서로 다른 것**임을 시각적으로 분리.
- 탭 콘텐츠 상단 안내문(`body2`, `text.secondary`): "Dos formas de darle acceso temporal a tu tienda. Elegí según quién lo va a usar."

### 3. Carpetas compartidas — 빈 상태 / 오류 상태 (D-03, 막다른 CTA 금지)

막다른 CTA 방지 규칙(memory `dead-end-cta-is-worse-than-none`)에 따라, **"설정 안 됨"(503)** 과
**"설정은 됐지만 내 항목이 없음"(빈 배열)** 을 서로 다른 카피로 구분한다 — 지금은 둘 다 같은
제네릭 에러/빈 테이블로 보여 사용자가 "고장났다"고 오해한다(연구 확인).

**관리 화면 (`/configuracion/carpetas-compartidas`, Configuración › Avanzado):**

| 상태 | 조건 | Heading | Body | CTA |
|---|---|---|---|---|
| 빈 상태(정상) | Drive 설정됨, 등록된 폴더 0개 | "Todavía no registraste ninguna carpeta" | "Registrá una carpeta de Google Drive para compartirla con tu equipo." | "Registrar carpeta"(기존 버튼, gold) |
| 오류 상태(인프라 미설정) | API 503(`Carpetas Compartidas no está configurado...`) | "La integración con Google Drive no está activada" | "Esta función requiere que el equipo de Ventago habilite la conexión con Google Drive para tu servidor." | "Escribir a soporte" → `/pedidos-soporte`(기존 지원 채널, 신규 경로 아님). **"Reintentar" 버튼을 두지 않는다** — 재시도해도 같은 503 이 반복되므로 그 자체가 막다른 CTA다 |

**직원 화면 (`/carpetas-compartidas`, Herramientas):**

| 상태 | 조건 | Copy |
|---|---|---|
| 빈 상태(정상, 기존 유지) | 서비스는 켜져 있으나 내 역할에 배정된 폴더 0개 | 기존 `sf_empty_user` 그대로: "Aún no hay carpetas asignadas a tu usuario. Contactá al administrador." (변경 없음) |
| 오류 상태(인프라 미설정, 신규) | API 503 | "Carpetas compartidas no está disponible todavía" / "Tu administrador todavía no activó esta función. Si la necesitás, avisale." |

★ 두 화면 다 "GOOGLE_SA_KEY_JSON" 같은 환경변수 이름을 화면에 노출하지 않는다 — 매장
관리자도 그 변수를 직접 설정할 권한이 없다(D-03 연구: 인프라 프로비저닝은 Ventago 쪽
작업). 서버 메시지 원문(`Contactá al administrador para definir GOOGLE_SA_KEY_JSON`)은
로그/개발자용으로 남기고, 화면 카피는 위 표의 문구로 대체한다.

### 4. Talleres › Códigos de defecto (신규 탭, A6)

기존 `/talleres/defect-codes` 페이지를 탭으로 노출만 한다(내부 화면 변경 없음). 탭 라벨
"Códigos de defecto", 아이콘 `tabler:alert-triangle` — 기존 Talleres 탭들과 같은 아이콘+라벨
배열 스타일(`src/views/talleres/components/constants.ts` 패턴) 그대로 추가.

- 이 페이지에 지금 게이트가 전혀 없다(연구 확인, A6) — 플랜 단계에서 적절한
  `allowedModules`(talleres 소속)를 걸 것. 게이트 추가 자체는 코드 결정이라 이 UI-SPEC
  범위 밖이지만, 게이트가 막을 때 보여줄 기본 `WithAccess` 거부 화면은 **기존 공용
  컴포넌트 그대로**(새 카피 불필요).

### 5. Tesorería › Caja fuerte (신규 탭, A5)

기존 `/caja-fuerte` 페이지를 Tesorería 탭 셋에 추가(`buildTesoreriaTabs`, `has('/caja')` 조건
재사용). 탭 라벨 "Caja fuerte", 아이콘 `tabler:building-bank`(Tesorería 의 다른 탭과
아이콘 중복 없는 값으로 선정 — `Estado de Caja`/`Cheques` 는 `tabler:cash` 계열 사용 중).
내부 화면·카피는 변경 없음.

| Element | Copy |
|---------|------|
| title | "Asistencia y adelantos" |
| description(목록 카드 보조 텍스트) | "Asistencia, horas trabajadas y adelantos a vendedores aprobados." |
| icon | `tabler:calendar-check` |
| category | 기존 4개(`ventas`/`finanzas`/`inventario`/`clientes`) 중 어느 것도 맞지 않는다 — **새 카테고리 `equipo`(필터 칩 라벨 "Equipo") 추가를 권고**. 급하면 `finanzas` 로 임시 분류 가능(가불=지출 성격과 가장 가깝다는 점 근거) — 최종 판단은 플랜 단계. |

### 공통 — HUB_TABS 섹션 구조 변경 (D-02 + D-01 반영, 목업 `menu-propuesta.png` 구조 채택)

`HubTab['section']` 유니온에 `'Conexiones' | 'Soporte'` 를 추가하고 `SECTIONS` 배열 순서를:

```
GENERAL → OPERACIÓN → CONEXIONES → SOPORTE DE VENTAGO → AVANZADO
```

- `Integraciones` 탭을 GENERAL → **CONEXIONES** 로 이동(목업 반영, 기존 카피 변경 없음).
- `Dispositivos`(신규) 를 CONEXIONES 에 추가(위 1번).
- `Acceso para soporte`(신규, Token de soporte + Acceso de Ventago 를 대체) 를 **SOPORTE DE VENTAGO** 섹션에 단독 추가. 기존 `token-soporte`/`generar-token` 두 탭 키는 제거하고 북마크 보존을 위해 리다이렉트만 남긴다(코드 결정, 카피 변경 없음).
- `Relojes (Galaxy Watch)` 단독 탭은 제거 — 내용은 Dispositivos 카드 3으로 이동.
- AVANZADO 에는 `Importar Legacy` + `Carpetas compartidas`(신규) 만 남는다.
- 섹션 라벨 표기 규칙은 기존과 동일: `text.disabled` 색, `letterSpacing: 1`, `toUpperCase()` — **새 섹션 라벨도 반드시 스페인어 대문자**(`CONEXIONES`, `SOPORTE DE VENTAGO`) — 다른 섹션(`GENERAL`/`OPERACIÓN`/`AVANZADO`)과 동일 패턴 유지(C12 의 영어 혼용 문제를 새로 반복하지 않는다).

### 사이드바 — 변경 없는 것 확인 (D-05, D-07, D-08)

- 그룹 순서: **Admin 그룹 맨 위 유지**(D-08 LOCKED) — 목업의 "업무 빈도순" 재배열은 **채택하지 않는다**. 이 문서의 참고 이미지는 방향 제시용일 뿐, 그룹 순서는 ANALISIS 문서의 제안이 아니라 CONTEXT.md D-08 을 따른다.
- `ClienteVista`·`CodigoVista`: 현재 위치(Herramientas)·현재 이름 그대로(D-05 LOCKED) — 카피 변경 없음.
- `Control de Envíos` 라벨: 이미 전 출처(사이드바·화면 헤더·브라우저 탭 타이틀) 일치 확인됨(D-07) — 카피 변경 없음.
- `Dashboard ventas`(Venta 그룹): `exclude` 배열에서 제거해 재노출(D-04) — 기존 항목 그대로 복원이므로 새 카피 없음.
