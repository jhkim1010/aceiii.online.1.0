## 범위 노트 — 두 개의 표면 (필독)

이 Phase 는 시각적으로 완전히 분리된 두 표면을 동시에 다룬다. 아래 모든 섹션은 **표면 A / 표면 B** 를 명시적으로 구분해 기술한다. 둘을 섞어서 구현하면 안 된다 (예: 에디터 크롬에 매장 테마 CSS 변수를 쓰거나, 스토어프런트에 Ventago 네이비/골드를 하드코딩하는 것 모두 오류).

| | 표면 A — 에디터 패널 | 표면 B — 공개 스토어프런트 |
|---|---|---|
| 파일 | `tienda-app/src/pages/[storeId]/panel/diseno.tsx` + `components/panel/*` | `tienda-app/src/pages/[storeId]/index.tsx` + `components/sections/*`, `components/macro/*` |
| 사용자 | 매장 admin (magic-link 인증, 데스크톱 도구) | 일반 소비자 (모바일 우선, 아르헨티나 의류 소매) |
| 색 체계 | **고정** Ventago 관리자 다크 네이비+골드 (`sketch-findings-ace-online` 스킬과 동일 계열, 매장 테마와 무관) | **동적** — 매장마다 `tokensToCssVars()` 가 내려주는 CSS 변수만 사용 |
| 언어 | 스페인어 (최종 사용자가 아르헨티나 매장주 — 근거는 아래 「Copywriting Contract」 참조) | 스페인어 (기존 코드베이스와 동일) |
| 승인된 시각 기준 | `tienda-online-editor-mockup.html` (레포 루트) | `tienda-online-templates-mockup.html` (레포 루트, 참고용 — 그대로 이식 아님) |

**shadcn 게이트 skip 사유**: `61-CONTEXT.md`/`61-RESEARCH.md` 가 tienda-app 의존성을 `next`/`react`/`react-dom` 3개로 **LOCKED** 했고 신규 UI/캐러셀/masonry/비디오 라이브러리 도입을 명시적으로 금지한다. 따라서 shadcn 초기화 여부를 사용자에게 묻지 않고 `Tool: none` 으로 확정한다.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 아이콘-텍스트 gap, dots(색상 점) 간격, 배지 내부 미세 패딩 |
| sm | 8px | 아코디언 헤더 내부 gap, 필드 간 세로 간격 하한, 스위치 행 gap |
| md | 16px | 기본 필드/섹션 세로 간격, rails/masonry/reels 카드 gap(12px 대신 16px 권장 — 아래 예외 참조) |
| lg | 24px | 섹션 좌우 패딩(`sf-sec`), 카드 그리드 상하 간격 |
| xl | 32px | 히어로 내부 패딩 하한, 섹션 간 큰 간격 |
| 2xl | 48px | 히어로/AI strip 패딩 상한 |
| 3xl | 64px | 사용 안 함(이 Phase 범위에서 페이지 최상위 대형 여백 없음) |

**Exceptions (LOCKED — 소급 리스케일 금지):**
- 승인된 목업(`tienda-online-editor-mockup.html`)과 기존 코드(`index.tsx`/`ProductCard.tsx`/`Header.tsx`)는 이미 8의 배수가 아닌 세밀한 값(9px/10px/12px/14px/18px/22px/26px 등)을 다수 사용한다. **이 값들은 이미 승인된 시각 기준이므로 4의 배수로 강제 재조정하지 않는다** — 기존 파일의 기존 spacing 은 그대로 유지.
- **신규 컴포넌트**(`RailsLayout.tsx`/`MasonryLayout.tsx`/`ReelsSection.tsx`/`Footer.tsx`/`SectionListEditor.tsx`/`MacroSelector.tsx`)는 아래 명시된 정확한 px 값을 따른다(개별 절 참조) — 대부분 12px(실무 관례상 허용된 근접값) 또는 8의 배수를 사용한다.
- 터치 타겟 예외: quickAdd 버튼(30×30px), WhatsApp 플로팅 버튼(48×48px), reels 탭 영역은 전체 카드(최소 140×248px) — 44px 미만 단독 탭 타겟 없음.

## Typography

### 표면 A — 에디터 크롬 (고정, Ventago 관리자 UI)

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Hint/Label | 11px | 400 | 1.5 |
| Body/Input/Button | 13px | 400 (본문) / 700 (버튼·탭·아코디언 헤더) | 1.4 |
| Section Heading (`.acc-h .t`) | 13.5px | 700 | 1.3 |
| Brand wordmark (topbar) | 15–16px | 800(예외 — 브랜드 워드마크에 한해서만 800 허용) | 1.2 |

- 정확히 2 weight: **400 regular** / **700 bold**. 예외 1건(topbar 브랜드 워드마크만 800) — mockup 그대로.
- 폰트 자체는 표면 A 전용 고정 스택(위 Design System 표 참조), 매장 테마 폰트와 무관.

### 표면 B — 스토어프런트 (동적, 매장별 테마)

크기 스케일은 고정(콘텐츠 위계), 글꼴 패밀리·굵기만 `--font-display`/`--font-body`/`--disp-weight` 로 매장별 변동:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body/Nav/가격 보조 | 13px | 400 (`--font-body`) | 1.5 |
| 상품카드 이름 | 12.5–14px | 400 (`--font-body`) | 1.35 |
| 상품카드 가격 | 14.5–18px | 800(고정, 테마 무관 — 가격은 항상 강조) | 1.2 |
| 섹션 제목(h2, "Novedades" 등) | 20–22px | `var(--disp-weight)` (`--font-display`) | 1.25 |
| Hero h1 | 34px | `var(--disp-weight)` (`--font-display`) | 1.1–1.15 |
| reels/Drop 카운트다운 등 대형 강조 | 26–36px | `var(--disp-weight)` | 1.15 |

- 정확히 2 "역할"만 굵기 변동 대상: **본문(--font-body, 400 고정)** / **디스플레이(--font-display, `var(--disp-weight)` 400~900 매장별)**. 가격만 예외로 800 고정(신뢰감 위해 테마 굵기와 무관하게 항상 굵게).

2. WhatsApp 플로팅 버튼 배경 `#25d366` — WhatsApp 브랜드 가이드라인상 고정. **이 Phase 유일하게 컴포넌트에 리터럴 hex 를 써도 되는 곳.**

**목업 색상 → CSS 변수 매핑 (필수 치환 — 목업을 그대로 복사하면 LOCKED 규칙 위반):**

`tienda-online-editor-mockup.html`의 `.sf` 미리보기 블록은 정적 데모용 하드코딩 값을 일부 포함한다. 프로덕션 이식 시 아래처럼 반드시 CSS 변수로 치환할 것:

| 목업 리터럴 | 치환 |
|---|---|

| `.wapp{background:#25d366}` | **치환 불필요** — 위에서 명시한 유일한 하드코딩 허용 예외 |

## Copywriting Contract

**언어 결정 (연구자 판단, LOCKED 아님이나 강력 권장):** 표면 A(에디터)의 최종 사용자는 매장을 운영하는 아르헨티나 소매업자이며, 승인된 목업(`tienda-online-editor-mockup.html`)이 전체 스페인어로 작성되어 있다. 반면 현재 `diseno.tsx`는 한국어(`"내 매장 홈페이지 꾸미기"`, `"발행하기"` 등)로 되어 있다 — 이는 개발 임시 카피이며 실사용자(스페인어 화자)에게 노출되면 안 된다. **이번 Phase 의 아코디언 전환 작업에서 표면 A 의 모든 사용자 노출 카피를 스페인어로 통일 교체할 것을 권장한다.** 문서/주석은 계속 한국어(CLAUDE.md 규약).

| Element | Copy |
|---------|------|
| Primary CTA (표면 A, 최상위) | `Publicar` (gold 버튼, topbar 우측) |
| Secondary 액션 (표면 A) | `Guardar borrador` (ghost 버튼) |
| Primary CTA (표면 B, hero) | `Ver colección` |
| Primary CTA (표면 B, 상품카드) | `Agregar` (장바구니 담기) / quickAdd 아이콘 버튼은 `＋` 단독(툴팁 "Agregar rápido") |
| Primary CTA (표면 B, reels 오버레이) | `Ver producto` (가격 + 버튼 오버레이) |
| Empty state — 표면 A 섹션 리스트가 0개일 때(엣지 케이스, 기본값상 발생 안 함) | 헤딩: `Todavía no hay secciones` / 본문: `Guardá el borrador para restaurar las secciones por defecto.` |
| Empty state — 표면 B 카탈로그 결과 0개 | 기존 그대로 유지: `No hay productos.` (`index.tsx` 기존 카피 재사용, 신규 작성 불필요) |
| Empty state — rails 개별 선반(row)에 상품 0개 | **텍스트 없음 — 해당 행 자체를 렌더하지 않는다**(숨김). 빈 선반을 보여주지 않는 것이 아르헨티나 소매 공개몰에서 더 신뢰감 있는 UX |
| Empty state — masonry 전체 0개 | 기존 `No hay productos.` 재사용 |
| Empty state — reels 섹션에 영상 0개 | **섹션 자체를 렌더하지 않는다**(숨김) — 관리자가 "표시" 토글을 켰지만 영상을 아직 안 올린 과도기 상태 방어 |
| Error state — 표면 A 저장 실패 | `No se pudo guardar el borrador: {상세 메시지}` (기존 `onSave` 에러 핸들러 패턴 유지, 카피만 스페인어 교체) |
| Error state — 표면 A 발행 실패 | `No se pudo publicar: {상세 메시지}` |
| Error state — 표면 A 이미지 업로드 실패(용량/확장자) | `El archivo supera 2MB o el formato no es válido (PNG/JPG/WEBP).` (영상: `El video supera 20MB o el formato no es válido (MP4/WEBM).`) |
| Error state — 표면 B 초안 로드 실패 | 기존 패턴 유지(변경 없음, 표면 A 전용 흐름) |
| Destructive confirmation | **해당 없음** — 이 Phase 에 삭제류 액션이 없다(섹션 숨김/재정렬만, 이미지 재업로드는 즉시 교체이며 확인 다이얼로그 불필요) |
| 마케팅 팝업(웰컴) 힌트 | 목업 그대로: 제목 `¡10% OFF en tu primera compra!` + 쿠폰 코드 표시 전용, 별도 액션 버튼 없이 `✕`로만 닫음 |
| `variantDots` 옵션 힌트(표면 A, 토글 옆 hint 텍스트) | `Sin datos de color de variantes aún — este interruptor no afecta la vista pública por ahora.` (아래 「Component & Layout Contracts」의 정직한 no-op 처리 참조) |
| masonry 정렬 힌트(표면 A, 레이아웃 선택 옆) | `El orden en Masonry se ve por columna (izquierda a derecha), no fila por fila.` (RESEARCH Pitfall 4 대응 — 사용자 혼란 방지) |

> 템플릿 표준 섹션 밖의 도메인 전용 계약. 플래너/실행자는 아래를 표면 A/B 색·타이포·spacing 계약과 함께 소스 오브 트루스로 사용한다.

### 표면 A — 아코디언 그룹 순서 (목업 canonical, 변경 금지)

목업 순서를 그대로 그룹/제목/이모지까지 따른다(CONTEXT: "목업이 그룹 명칭과 순서 기준"):

1. `🏷 Identidad de marca` — 표시명, 로고 업로드, 파비콘 업로드
2. `🎨 Diseño global` — 기존 유지(프리셋 12종/hue/sat/폰트/radius) + macrostructure 5종 선택기(아래 별도 절)
3. `📣 Barra de anuncio` — 활성 토글, 문구, 링크(선택)
4. `🧩 Secciones del inicio` — `SectionListEditor.tsx`(▲▼/👁) + 섹션별 인라인 편집(hero/benefits/carousel/duoBanners/newsletter/reels)
5. `🛍 Tarjeta de producto` — 6개 스위치(discountBadge/installments/quickAdd/hoverSecondImage/lastUnitsBadge/variantDots)
6. `📚 Catálogo y filtros` — 정렬 기본값, pageSize, showOutOfStock, 필터(talle/color/precio) 토글
7. `💬 Contacto & redes` — WhatsApp 플로팅 토글+번호, Instagram, Facebook, 푸터 텍스트
8. `🛡 Confianza, pagos y envíos` — 결제 로고 chips, 배송사 chips, "Compra protegida" 배지, 정책 링크 토글
9. `📈 Marketing & SEO` — 팝업(토글/제목/쿠폰), SEO 타이틀/설명, Pixel ID

아코디언 인터랙션: 헤더 클릭 시 `open` 클래스 토글, `chev`(›) 아이콘 90° 회전(`transform:rotate(90deg)`, transition 0.2s), 본문은 `display:none`↔`block`(높이 애니메이션 없음 — 목업 그대로, 신규 애니메이션 라이브러리 불필요). 최초 로드 시 1·3·4·7 그룹이 `open`(목업 기본 상태 — Wave A 신규 그룹 우선 노출), 나머지는 접힘.

### 표면 A — macrostructure 선택 UI (5종, 미니 와이어프레임 아이콘)

기존 `MACRO_OPTIONS`(텍스트 버튼 3개)를 아이콘+라벨 5개 그리드로 교체. 아이콘은 **순수 CSS `<div>` 와이어프레임**(외부 이미지/아이콘 폰트 금지, 인라인 SVG도 허용):

| id | 라벨 | 와이어프레임 구성 | 선택 상태 |
|---|---|---|---|
| `marquee` | `Marquee hero` | 상단 전폭 바(높이 40%) + 하단 2×2 균일 정사각형 그리드 | |
| `bento` | `Bento grid` | 불균일 크기 박스 4개(1개 큰 박스 + 3개 작은 박스, 벤토 배치) | |
| `doc` | `Documento largo` | 얇은 가로 바 5개를 세로로 촘촘히 쌓음(고밀도 리스트 암시) | |
| `rails` | `Estantes horizontales` | 가로 바 3줄, 각 줄이 프레임 우측 경계를 살짝 넘어가는(overflow) 형태로 스크롤 암시 | |
| `masonry` | `Masonry irregular` | 세로 열 3개, 각 열 안의 사각형 높이가 서로 다름(신문 조판 암시) | |

각 버튼: 64×48px 와이어프레임 박스(배경 `var(--panel2)`, 요소는 `var(--line)` 배경 3px radius) + 하단 13px 라벨. 선택 상태 = 2px `var(--gold)` 테두리 + 라벨 색 `var(--gold)`(기존 `.seg`/`.segOn` 톤 계승). 5개를 1행 grid(`repeat(5, 1fr)`, gap 8px)로 배치, 380px 패널 폭에서 각 칸 ~64px.

### 표면 B — macrostructure 5종 렌더 계약

기존 3종(marquee/bento/doc)은 `index.tsx`의 `gridStyle` 삼항 분기(그리드 밀도만 다름)를 **그대로 유지 — 회귀 금지**. 신규 2종은 그리드 밀도가 아니라 렌더 구조 자체가 다르므로 최상위 조건 분기로 추가한다.

**`rails`** (`components/macro/RailsLayout.tsx`, 신규):
- 소스별 행 3개 기본: `Novedades`(newest), `Más vendidos`(bestseller 집계), 카테고리별 1개 이상.
- 각 행: `<h2>` 제목(20px, `--font-display`/`--disp-weight`) + 가로 스크롤 컨테이너.
- 카드: flex-basis 150px(모바일) / 200px(≥640px), gap 12px, `scroll-snap-align: start`.
- 컨테이너: `overflow-x:auto; scroll-snap-type:x mandatory; -webkit-overflow-scrolling:touch`, 스크롤바 숨김(`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`).
- 좌우 화살표: 36×36px 원형 버튼, 컨테이너 좌/우 끝에 절대 위치 오버레이, 배경 `var(--card)` + 그림자, 스크롤이 끝에 도달하면 해당 화살표 자동 숨김(`opacity:0; pointer-events:none`).
- 행 단위 lazy load: `IntersectionObserver`(`rootMargin:'200px'`), 화면 진입 전까지 fetch 하지 않음. 로딩 중 자리표시는 카드 개수만큼 회색 스켈레톤 블록(배경 `var(--soft)`, `border-radius:var(--radius)`) — 새 애니메이션 라이브러리 없이 CSS `opacity` pulse(선택)만 허용.
- 상품 0개인 행은 렌더하지 않음(위 Copywriting 참조).

**`masonry`** (`components/macro/MasonryLayout.tsx`, 신규):
- `columns: 2`(기본, 모바일) / `columns: 4`(`@media (min-width:900px)`, 데스크톱) — **JS 라이브러리 금지, 순수 CSS `columns`**.
- `column-gap: 12px`. 카드: `break-inside:avoid; margin-bottom:12px; display:inline-block; width:100%`(Safari `break-inside` 버그 회피 관용구).
- 이미지 래퍼에 `aspect-ratio`(예: `3/4`) 인라인 지정 필수 — 로드 전 높이 확정으로 열 튐 최소화.
- 무한 스크롤: 기존 카탈로그 페이지네이션 재사용, "Cargar más" 텍스트 버튼(`.btn-ghost` 스타일) 또는 `IntersectionObserver` 트리거 — 둘 중 discretion, 신규 무한스크롤 로직 금지.
- **열 우선(column-major) 정렬은 CSS `columns` 의 본질적 특성** — 버그 아님(표면 A hint 텍스트로 관리자에게 사전 고지, 위 Copywriting 참조).

### 표면 B — `reels` 섹션 (`components/sections/ReelsSection.tsx`, 신규)

- 세로 카드 가로 스크롤. 카드 크기: 140×248px(모바일) / 180×320px(데스크톱, `aspect-ratio:9/16` 유지), gap 12px, `scroll-snap-align:start`(rails 와 동일한 스냅 컨테이너 패턴 재사용).
- `<video muted playsInline preload="none" poster={minioImageUrl(item.posterFile)}>` — **`autoplay` 속성 금지**. `controls` 속성도 생략(커스텀 탭 토글).
- 초기 상태: poster 이미지만 표시 + 중앙 반투명 원형 ▶ 아이콘 오버레이(40px, 배경 `rgba(0,0,0,0.45)`, 아이콘 흰색). 탭하면 아이콘 사라지고 재생.
- 탭 핸들러: 클릭한 video 를 제외한 모든 `<video>`를 `pause()`(동시 재생 방지 — 전역 상태 불필요, DOM 순회로 충분).
- 카드 하단 오버레이: 좌측 하단 가격 chip(반투명 다크 배경 `rgba(0,0,0,0.6)`, 흰 텍스트, `var(--radius)` 상한 8px), 우측 하단 `Ver producto` CTA 필(배경 `var(--gold)`, 텍스트 `var(--navy)`).
- 상품 연결(`productId`) 없는 아이템은 가격/CTA 오버레이를 렌더하지 않음(영상만 노출) — no-op, 가짜 가격 표시 금지.
- 영상 0개(섹션 활성이나 items 배열 비어있음) → 섹션 전체 미노출(위 Copywriting 참조).

### 표면 B — 공지바 / 헤더 로고 / 푸터 / WhatsApp (신규 렌더 계약)

- **공지바**: 기존 `Header.tsx`의 하드코딩된 `<div style={s.announce}>` 블록을 `content.announce` 로 완전 대체. `enabled=false` → JSX 자체에서 미렌더(빈 공간 남기지 않음, `display:none` 아님). 스타일은 기존 유지(`background:var(--navy)`, 흰 텍스트, 굵은 gold 강조 가능), 텍스트는 `content.announce.text`, `href` 있으면 `<a>`로 감싸기.
- **헤더 로고**: 기존 하드코딩 워드마크(`Cool<span>Shop</span>`)를 `content.brand` 로 대체. `logoFile` 있으면 `<img>`(높이 28–32px, `object-fit:contain`, `minioImageUrl()` 경유), 없으면 텍스트 워드마크(`content.brand.displayName`, `--font-display`/`var(--disp-weight)`).
- **파비콘**: `content.brand.faviconFile` 있으면 `index.tsx`의 `<Head>`에 `<link rel="icon" href={minioImageUrl(...)} />` 추가.
- **WhatsApp 플로팅 버튼** (`components/WhatsAppFloat.tsx`, 신규 권장): 고정 위치(`bottom:18px; right:18px`, 모바일은 safe-area 고려해 `bottom:16px`), 48×48px 원형, 배경 `#25d366`(브랜드 고정, 위 Color 절 참조), 아이콘 흰색(이모지 또는 인라인 SVG), `z-index` 는 콘텐츠보다 위·팝업 모달보다 아래. `contact.whatsapp` 없으면 렌더 안 함. 링크: `https://wa.me/{숫자만}?text=...`.
- **푸터** (`components/Footer.tsx`, 완전 신규 — 현재 `index.tsx`엔 `<footer>` 자체가 없음): 배경 `var(--navy)`(목업의 하드코딩 `#17161c` 대체 — 위 매핑 표 참조), 텍스트 밝은 톤(고정 `rgba(255,255,255,0.75)` 계열은 다크 배경 전용 예외로 허용). 4열 그리드(브랜드+주소/시간, 도움말 링크, 법적 링크, 결제 로고) → 모바일 2열로 축소(`@media` 또는 CSS Grid `auto-fit`). 결제/배송 로고는 chip(`background:rgba(255,255,255,0.08); border:1px solid rgba(255,255,255,0.13); border-radius:5px; padding:4px 8px; font-size:10.5px`). "Compra protegida" 배지: 🛡 이모지 + 텍스트 + CUIT, 상단 구분선(`border-top:1px solid rgba(255,255,255,0.1)`) 아래 별도 행.
- **마케팅 팝업**: 화면 중앙 오버레이(`background:rgba(0,0,0,0.4)`), 박스 흰 배경 고정(팝업은 항상 밝은 종이 위에 표시 — `var(--card)` 사용 가능하나 다크 테마 매장에서도 팝업 자체는 가독성 위해 밝게 유지 권장, discretion), radius 14px, 패딩 30×34px, 닫기 `✕`(우상단, 회색), 쿠폰 코드는 점선 테두리 pill(`border:1.5px dashed var(--gold); color:var(--gold)`). `sessionStorage` 키 `popup_shown_{storeId}` 로 세션 1회 판정.
