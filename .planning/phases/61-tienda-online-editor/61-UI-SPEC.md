**판정 원칙 (LOCKED — checker 확정):**
- **기존 파일**(`index.tsx`/`ProductCard.tsx`/`Header.tsx`/`diseno.tsx` 등 이미 코드가 존재하는 파일)의 기존 spacing 은 **소급 재조정하지 않는다** — 이미 승인된 목업/코드 실측값(9px/10px/12px/14px/18px/22px/26px 등)을 그대로 유지. 근거: 이미 운영 중인 코드의 시각적 일관성을 깨지 않기 위함.
- **신규 컴포넌트 7종**(`RailsLayout.tsx`/`MasonryLayout.tsx`/`ReelsSection.tsx`/`QuizSection.tsx`/`Footer.tsx`/`SectionListEditor.tsx`/`MacroSelector.tsx`)은 아직 코드가 없으므로 **전부 4px 그리드로 스냅**한다(면제 없음). 목업 실측값 대비 1~2px 조정은 목업의 디자인 의도를 깨지 않는다. 아래 개별 절의 모든 spacing(패딩/마진/gap/카드 크기)은 이미 스냅된 값이다 — 대표 변환: `26→24`, `30→32`, `34→32`, `44→48`, `22→24`, `18→16`, `14→16`, `9→8`, `10.5→12`, `min-height 430→432`, 카드 폭 `190→192`/`150→152`, quickAdd `30×30→32×32`, CTA 패딩 `11×22→12×24`, 배지 패딩 `3×7→4×8`. `rails` 카드 172px, 화살표 28×28px, `columns:4 200px` 은 이미 4의 배수라 변경 없음.
- **구조적 예외는 이번 스냅에 없다** — 전 값이 개별 근거 없이 4px 그리드로 편입됐다(스크롤 스냅 계산·이미지 비율 등으로 그리드보다 우선해야 하는 값이 발생하지 않음).
- `border-radius`(모서리 둥글기)는 이 spacing 그리드의 적용 대상이 아니다 — 기존 `--radius` 테마 토큰이 이미 프리셋별 2~26px 자유 값 체계(`THEME_PRESETS` 참조)로 독립 운영되며, 4px 그리드와 무관.
- 터치 타겟: quickAdd 버튼(32×32px), WhatsApp 플로팅 버튼(48×48px), 화살표 버튼(28×28px, rails), reels 탭 영역은 전체 카드(최소 152×248px 이상), quiz 선택지 카드(패딩 16px, 자연히 48px 이상 높이 확보) — 48px 미만 단독 탭 전용 인터랙티브 타겟은 만들지 않는다(작은 장식 아이콘 버튼은 시각적으로 작아도 주변 카드/여백이 실질 탭 영역을 넓혀준다).

## Typography

### 표면 A — 에디터 크롬 (고정, Ventago 관리자 UI)

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Hint/Label | 11px | 400 | 1.5 |
| Body/Input/Button | 13px | 400 (본문) / 700 (버튼·탭·아코디언 헤더) | 1.4 |
| Section Heading (`.acc-h .t`) | 13.5px | 700 | 1.3 |
| Brand wordmark (topbar) | 15–16px | 800(예외 — 브랜드 워드마크에 한해서만 800 허용) | 1.2 |

- 정확히 2 weight: **400 regular** / **700 bold**. 예외 1건(topbar 브랜드 워드마크만 800) — mockup 그대로.
- 폰트 자체는 표면 A 전용 고정 스택(위 Design System 표 참조), 매장 테마 폰트와 무관.

### 표면 B — 스토어프런트 (동적, 매장별 테마) — **크기 4토큰 · 굵기 2종 + 예외 1건 (checker BLOCK1 해소)**

| Token | Size | Weight | Line Height | 적용 역할 |
|---|---|---|---|---|
| `label` | 12px | 400(기본) — 배지/킥커류만 800 고정 예외(아래) | 1.4 | quiz 킥커(`PREGUNTA N`/`TU SELECCIÓN`, 구 11px), quiz 진행 텍스트(`{n}/{total}`, 구 12px·700→400), 할인/últimas/MATCH 배지 텍스트(구 10~11px), rails `Ver todo →` 링크(구 12px·700→400, `var(--gold-d)` 색상으로만 강조), 카탈로그/결제 필터 chip, reels 상품 오버레이 이름·가격(구 10.5~12px) |
| `body` | 13px | 400 (`--font-body`) | 1.5 | 본문, nav, 상품카드 이름, 상품카드 가격 보조(cuotas), 섹션 부제(rails 배너 부제 구 12.5px 포함) |
| `heading` | 20px | `var(--disp-weight)` (`--font-display`) | 1.25 | 섹션 제목 h2(구 18~22px), quiz 질문 텍스트(구 25px), quiz 결과 헤딩(구 24px), **상품카드 가격**(구 14.5~18px 범위 폐기 → 20px 고정 단일값) |
| `display` | 24–34px (반응형/clamp, 단일 토큰) | `var(--disp-weight)` (`--font-display`) | 1.15 | Hero h1 **전용** — marquee 표준 히어로는 상단(34px), rails 콤팩트 밴드는 같은 토큰의 하단(24px) 사용. 별도 5번째 크기 아님 |

- 정확히 2 weight: **400**(label 기본 / body) / **`var(--disp-weight)`**(heading / display, 매장별 400~900).
- **고정(테마 무관) 예외 굵기 — 딱 1건만 허용**: 배지/킥커류 텍스트는 항상 **800** 고정 — 적용 요소: 할인 배지, últimas unidades 배지, `MATCH NN%` 배지, quiz `PREGUNTA N`/`TU SELECCIÓN` 킥커 라벨. **그 외 label 토큰 요소**(진행 텍스트, `Ver todo →` 링크, 필터/결제 chip, reels 오버레이 텍스트)는 기본 **400** — 색상 대비(`var(--gold-d)`)나 배경(chip 채움)으로 강조하고 굵기는 늘리지 않는다.
- 상품카드 가격은 `heading`(20px, `var(--disp-weight)`)을 따른다 — 이전 초안의 "가격은 항상 800 고정" 규칙을 폐기하고 매장 테마 굵기에 통합했다(섹션 제목과 동일한 위계 처리로 단순화). `ProductCard.tsx` 기존 `fontSize:18` 하드코딩은 Wave B 작업 시 20px 로 조정.
- **버튼 레이블(CTA 문구)은 이 4-토큰 콘텐츠 타이포 계약의 대상이 아니다** — 상호작용 요소이므로 항상 기존 `.btn`/`.btn-gold` 클래스(`globals.css`: `font-size:14px; font-weight:700`)를 그대로 재사용한다. 이전 초안에서 rails/quiz 신규 CTA 버튼("Ver novedades"/"Empezar el quiz →"/"Agregar al carrito"/"Asesorame por WhatsApp" 등)에 개별 지정했던 `굵기 800`/커스텀 폰트 크기는 전부 폐기하고 기존 `.btn` 관례로 통일한다(신규 굵기·크기 역할을 만들지 않기 위함).

고정(테마 무관) 예외 색 — **딱 2개만 허용**:
1. `var(--green)` — 할부(cuotas) 문구 색. `tokensToCssVars()`가 항상 `#1d9e75`를 반환(파라미터 무관) — CSS 변수로 전달되므로 컴포넌트는 여전히 `var(--green)`만 참조, 리터럴 금지.
