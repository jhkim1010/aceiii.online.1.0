상수:
```typescript
const MAX_IMAGE_BYTES = 2 * 1024 * 1024;   // 2MB
const MAX_VIDEO_BYTES = 20 * 1024 * 1024;  // 20MB
```

`uploadAsset(file: Express.Multer.File, kind: string): Promise<{ fileName: string }>` 구현 규칙:
1. `kind` 가 위 8종 whitelist 밖이면 `BadRequestException('지원하지 않는 kind 입니다')`.
2. `file` 이 없거나 `file.buffer` 가 없으면 `BadRequestException('파일이 없습니다')`.
3. 확장자 추출은 `file.originalname` 의 마지막 `.` 뒤 소문자. 확장자 whitelist 실패 시 400. **메시지는 사용자 노출 카피와 일치시킨다**:
   - 이미지 계열: `'El archivo supera 2MB o el formato no es válido (PNG/JPG/WEBP).'`
   - `reelVideo`: `'El video supera 20MB o el formato no es válido (MP4/WEBM).'`
4. **MIME 이중 체크** — `file.mimetype` 이 해당 kind 의 허용 MIME 목록에 없으면 400(확장자 위조 방어). 단 `application/octet-stream` 은 브라우저가 종종 보내므로 확장자가 통과했을 때에 한해 허용하고, 이 예외를 한국어 주석으로 남긴다.
5. **크기 체크** — `file.size > (kind === 'reelVideo' ? MAX_VIDEO_BYTES : MAX_IMAGE_BYTES)` 이면 400. `FileInterceptor.limits` 는 20MB 로 통일돼 있으므로 이미지 2MB 강제는 **반드시 서비스에서** 수행해야 한다(인터셉터만 믿으면 3MB png 가 통과한다).
6. 파일명 재부여: `const fileName = \`theme_${kind}_${randomUUID()}.${ext}\`;` — 원본 파일명은 절대 사용하지 않는다(`store.controller.ts` 의 `Date.now()+originalname` 패턴은 grandfather 코드, 여기서는 금지).
7. `return this.minioService.uploadFile(file, fileName);`
8. 실패 시 `Logger.error` 로그 후 재던짐. 주석은 한국어.

**DB 접근 금지** — 이 서비스는 어떤 pool 도 주입받지 않는다(`new Pool(`/`new Client(` 0건).

```typescript
@Controller('shop')
export class StoreThemeAssetController {
  constructor(private readonly assets: StoreThemeAssetService) {}

  // 테마 에셋 업로드 — 편집 토큰(StoreThemeEditGuard)의 storeId 가 라우트 storeId 와 일치해야 통과
  @UseGuards(StoreThemeEditGuard)
  @Post(':storeId/theme/asset')
  @UseInterceptors(
    // 서버측 하드 상한은 영상 기준 20MB. 이미지 2MB 는 서비스에서 별도 강제한다.
    FileInterceptor('file', { limits: { fileSize: 20 * 1024 * 1024 } }),
  )
  uploadAsset(
    @Param('storeId', ParseIntPipe) storeId: number,
    @UploadedFile() file: Express.Multer.File,
    @Query('kind') kind?: string,
  ): Promise<{ fileName: string }> {
    return this.assets.uploadAsset(file, kind ?? '');
  }
}
```
