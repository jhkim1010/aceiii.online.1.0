- `section.enabled === false || section.questions.length === 0` → `return null`
- **배너**: `Empezar el quiz →` 클릭 시 `setState({ step:'question', idx:0 })`, `answers` 초기화(`{}`).
- **질문(idx)**:
  - 진행바 `{idx+1} / {questions.length}`, `aria-live="polite"`, 시각바 `aria-hidden`
  - 선택지 클릭 시 `answers[question.key] = option`, 마지막 질문이면 `setState({ step:'result' })` 후 매칭 실행, 아니면 `idx+1`
  - `← Volver`(idx>0): `idx-1`
  - 전환 시 헤딩 `focus()` (접근성)
- **매칭 로직(핵심 — 신규 엔드포인트 0)**:
  - `answers` 를 `section.mapping` 으로 카탈로그 파라미터로 변환:
    ```typescript
    const params: { categoryId?: number; globalCategoryId?: number; gender?: string } = {};
    let priceRange: [number, number] | null = null;
    for (const [qKey, ans] of Object.entries(answers)) {
      const target = section.mapping[qKey];   // 'categoryId' | 'priceRange' | 'gender' | 'globalCategoryId'
      if (target === 'categoryId') params.globalCategoryId = Number(ans.value) || undefined;
      else if (target === 'gender') params.gender = ans.value || undefined;
      else if (target === 'priceRange') priceRange = parsePriceRange(ans.value); // "0-10000" 형태 파싱
    }
    ```
  - `listProducts(storeId, { ...params, pageSize: 24 })` **1회** 호출(기존 엔드포인트). 결과를 `priceRange` 로 클라이언트 필터.
  - **단계적 완화**: 정확 매치가 3개 미만이면 조건을 하나씩 빼고 재필터(이미 받은 목록 내에서, 추가 요청 없이). 그래도 부족하면 `listProducts(storeId, { pageSize: 24 })` 전체에서 채운다. 최대 3개.
  - **MATCH 스코어**: 정렬된 결과에서 `const score = Math.max(60, 98 - i * 6);` (i=0..2) — 단조감소, 난수 금지. 첫 카드 98%, 순위대로 감소.
  - **매칭 이유**: 답변한 각 질문의 `option.sub` 를 `✓ {sub}` 3줄로(UI-SPEC "sub 이중 역할").
