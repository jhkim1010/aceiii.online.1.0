'auto' : '3 / 4'` 를 적용하고, 실제 이미지 비율 반영은 Plan 61-12 가 `ProductCard` 에 `imgHeight` 옵션을 추가할 때 연결한다. 이 한계를 한국어 TODO 주석으로 명시한다: `// TODO(Plan 61-12): keepRatio=true 시 실제 이미지 비율 반영은 ProductCard 의 imgwrap 고정 높이(230px) 제거가 선행돼야 함.`
