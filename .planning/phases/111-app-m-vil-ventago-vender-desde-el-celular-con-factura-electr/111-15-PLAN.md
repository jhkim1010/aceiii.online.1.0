## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone→API | JWT + x-mobile-session-token from an untrusted device |
| manager browser→API | approval/revocation actions |
| web session flows→terminals | move/switch-terminal could target phone terminals |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-111-10 | Spoofing | device identity | mitigate | fingerprint taken from the server-side mobile_sessions row, not from headers/body; approval required by a human with editar-terminal/update |
| T-111-10b | Spoofing | JWT of user A + session token of user B | mitigate | MobileTerminalGuard requires mobileSession.userId === req.user.id; spec + mutation |
| T-111-10c | Denial of Service | approved phone kept out by a cached pending result | mitigate | only approved results cached; approve/revoke clear the key |
| T-111-11 | Elevation of Privilege | approve into another store's box | mitigate | Box/Branch lookups with storeId in where; 404 on foreign ids; spec asserts terminal not created |
| T-111-12 | Tampering | body-supplied terminal/box/branch | mitigate | req.device only from MobileTerminalGuard |
| T-111-13 | Spoofing | lost/stolen phone | mitigate | revoke → status revoked + sessions deleted in one tx (next request 401 on every worker) + terminal soft-deleted + cache cleared; token useless outside /mobile/pos/* (Plan 18, D-22) — no residual 6 h window |
| T-111-14 | Tampering | PC session hijack of phone terminal | mitigate | moveToTerminalAndCreateSession rejects TERMINAL_MOVIL; spec + control group |
| T-111-15 | Information Disclosure | cross-tenant device list | mitigate | list/status queries always filtered by req.user.storeId |
| T-111-16 | Denial of Service | lastSeenAt write per request | mitigate | throttled to 1/min/device |
| T-111-17 | Repudiation | who approved/revoked | mitigate | approved_by/revoked_by columns + @Audit |
