<objective>
Phase 6의 15개 useXxxReport 훅을 **controlled mode**로 리팩터한다. 외부(페이지 또는 셸)가 params 상태를 소유하고 훅에 주입하도록 시그니처를 변경한다. 각 훅 모듈은 `xxxDefaultParams()` named export를 추가로 제공한다.

**이 Plan은 훅 파일만 수정한다. 기존 페이지(`XxxReport.tsx`)는 Wave 2(08-02)에서 adapter로 수정한다. 따라서 Wave 1 완료 직후에는 일시적으로 /reportes/* 페이지 빌드가 깨질 수 있으므로 Wave 1과 Wave 2는 동일 브랜치에서 연속 실행 권장 — 또는 훅 시그니처를 backward-compatible overload로 작성해 회귀 방지.**

**권장 전략 (채택):** 훅 시그니처를 `(params?: any)` — optional로 하여, params 미제공 시 내부 `useState(defaultParams)` fallback을 유지하는 과도기 버전을 먼저 커밋. Wave 2에서 페이지가 전부 params를 주입하도록 이전한 뒤, Wave 4 마지막에 fallback 제거 (선택). 이 과도기 방식으로 Wave 1 단독 빌드도 그린 유지.

Purpose: Phase 8 셸(ReportsPreviewPanel)이 slug에 해당하는 훅에 외부 params를 주입해 preview를 렌더할 수 있도록 기반 마련.
Output: 15 hook files refactored + 15 `xxxDefaultParams` named exports.

```typescript
export const vendedorDefaultParams = () => ({
  startDate: DateTime.now().startOf('month').toFormat('yyyy-MM-dd'),
  endDate: DateTime.now().toFormat('yyyy-MM-dd'),
  filter: ''
})

const useVendedorReport = (externalParams?: any) => {
  // 과도기: 외부 params 없으면 내부 state fallback
  const [internalParams, setInternalParams] = useState<any>(vendedorDefaultParams)
  const params = externalParams ?? internalParams
  const setParams = externalParams ? () => {} : setInternalParams

  const [data, setData] = useState<any[]>([])
  const [loading, setLoading] = useState<boolean>(false)

  const getData = useCallback(async () => { ... }, [params])
  const downloadExcel = useCallback(async () => { ... }, [params])

  return { data, getData, loading, params, setParams, downloadExcel }
}
```

Variant C (2 hooks: clientes-credito, alertas) — same as B but defaultParams returns only `{ filter: '' }`.

Variant A (3 hooks: sales, products, stocks) — same controlled signature + preserve helpers (`setThisMonth`, `setToday`, `clear`, drilldown fetchers). Helpers use `setParams` internally. In controlled mode, helpers should call setParams only if internal fallback active; otherwise they become no-ops (페이지에서 helper를 로컬로 재구현할 것 — Wave 2).

Hook return shape unchanged externally so Wave 2 페이지 이전 전까지 기존 호출이 그대로 동작.
