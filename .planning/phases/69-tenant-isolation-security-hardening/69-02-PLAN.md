  <action>
4개 파일 전부에서 `io(WS_URL, { transports: ['websocket'] })` 호출을 다음으로 바꾼다:

`const token = localStorage.getItem('accessToken')` 를 `useEffect` 안 `io()` 직전에 읽고,
`if (!token) return undefined` (또는 해당 훅의 기존 early-return 형태)로 **토큰이 없으면 연결 자체를 만들지 않는다.**
그다음 `io(WS_URL, { transports: ['websocket'], auth: { token } })`.

각 훅의 `useEffect` 의존성 배열은 그대로 둔다 (토큰을 deps 에 넣으면 매 렌더 재연결 위험).
`TeamChatPanel.tsx` 는 컴포넌트라 `useAuth()` 의 user 존재 여부로 이미 게이팅될 수 있으니,
기존 조건은 유지하고 토큰 체크만 추가한다.

`register_*` emit 페이로드는 **그대로 둔다** — 서버가 무시하게 되어 있어도 구버전 서버 호환을 위해 남긴다
(단 `register_user` 의 값은 서버에서 폐기되므로 신뢰 대상이 아니다).

주석은 한국어로, 왜 토큰이 필요한지(69-01 핸드셰이크 인증) 1줄씩 남긴다. ESLint `lines-around-comment` /
`newline-before-return` 을 반드시 지킨다.
  </action>
