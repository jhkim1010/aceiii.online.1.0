<objective>
`/realtime` 공용 Socket.io 게이트웨이(R1 / CR-01)에 **핸드셰이크 인증**과 **room 소유권 검증**을 넣는다.
현재는 인증 없이 접속한 소켓이 클라이언트가 보낸 `userId`/`storeId`/`terminalId`/`branchId` 를 그대로 신뢰해
`user:*` · `store:*` · `terminal:*` · `branch:*` room 에 가입한다. ID 는 순차 정수라 열거 가능하고,
`ws-cors.ts` 는 Origin 없는 네이티브 접속을 허용하므로 CORS 는 방어가 아니다.

공용 게이트웨이에 이식한다. 신규 기능 0 — 인증 경로만 추가한다.
Output: 인증된 소켓만 room 에 가입하는 `/realtime` 게이트웨이 + 회귀 테스트.

`WebsocketGateway.handleConnection` 을 다음 순서로 재작성한다.

1. IP rate-limit: 모듈 스코프에 `const connectLimiter = new SocketRateLimiter(SOCKET_CONNECT_LIMIT, SOCKET_CONNECT_WINDOW_MS)` 를 두고
   `client.handshake.address` 키로 `tryConsume` 한다. 초과 시 `auth_error` emit + `disconnect(true)` 후 return.
2. 자격증명 추출: `const credential = client.handshake.auth?.token ?? client.handshake.headers['x-api-key']`.
3. credential 이 있으면 **JWT 우선 판정** — `this.jwtService.verifyAsync(credential, { secret: process.env.JWT_SECRET_KEY })`
   성공 시 `client.data.kind = 'user'`, `client.data.userId = payload.id`, `client.data.storeId = payload.storeId`,
   `client.data.authenticated = true`.
4. JWT 검증이 실패하면 **API Key 판정** — `this.branchAgentModel.findOne({ where: { apiKey: credential }, include: [{ model: Branch, attributes: ['id','storeId'] }] })`.
   찾으면 `client.data.kind = 'agent'`, `client.data.agentId`, `client.data.branchId = agent.branchId`,
   `client.data.storeId = agent.branch.storeId`, `client.data.authenticated = true` 로 세팅하고
   `websocketService.registerClient(client, credential)` 로 apikey room 에 가입시킨다.
5. 둘 다 실패하거나 credential 이 없으면 **연결은 유지하되 미인증 상태**로 둔다
   (`client.data.authenticated = false`). 동시에 `AUTH_GRACE_MS = 10_000` 타이머를 걸어
   유예 시간 내 인증되지 않으면 `auth_error` emit + `disconnect(true)`.
   타이머 핸들은 `client.data.authTimer` 에 보관하고, 인증 성공 시점과 `handleDisconnect` 에서 `clearTimeout` 한다.
   유예는 오직 레거시 `print-agent/src/index.js`(핸드셰이크 없이 접속 후 `register_api_key` emit)를 위한 것이다.
6. `welcome` emit 은 인증 성공 소켓에만 보낸다.

`websocket.module.ts` 에 `JwtModule.registerAsync({ useFactory: () => ({ secret: process.env.JWT_SECRET_KEY, signOptions: { expiresIn: '24h' } }) })`
와 `SequelizeModule.forFeature([Terminal, Branch, BranchAgent])` 를 imports 에 추가하고,
게이트웨이 생성자에 `JwtService` + `@InjectModel(Terminal) @InjectModel(Branch) @InjectModel(BranchAgent)` 를 주입한다.
순환 의존을 피하기 위해 `PrintService` 는 주입하지 않고 `BranchAgent` 모델을 직접 조회한다.

`emitToAll` 호출부는 현재 0건이므로 브로드캐스트 경로는 건드리지 않는다.
