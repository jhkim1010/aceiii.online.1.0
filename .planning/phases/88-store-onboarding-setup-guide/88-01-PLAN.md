# 88-01 · W1 — 서버 계산기

**이 웨이브의 목표:** 화면을 만들기 전에 **값이 맞는지부터 맞춘다.** 끝나면 `GET /auth/me` 응답에
`onboarding` 이 정확히 실려 오고, 브라우저 없이 curl 로 검증할 수 있다.

**대원칙 3개 (SPEC §3):** 완료는 저장하지 않고 파생한다 · 판정은 「시드값 이탈」이다 · 새 엔드포인트로
왕복을 늘리지 않는다.

### 「시드값 이탈」의 일반 규칙

`createStoreDefaults()` 는 **단일 트랜잭션**이라 시드 20종의 `created_at` 이 매장 생성 시각과 사실상 같다.
그래서 테이블마다 다른 규칙을 만들지 않고 하나로 쓴다:

```
beyond_seed(t, s) :=  t.created_at > s.created_at + interval '5 minutes'   -- 나중에 추가했다
                  OR  t.updated_at > t.created_at  + interval '1 minute'   -- 시드를 손봤다
```

여유값 5분/1분의 근거: 시드는 한 트랜잭션(로그상 수백 ms), 사람의 첫 조작은 최소 분 단위.
**레거시 임포트(Phase 86)로 들어온 매장은 이 규칙에 걸리지 않을 수 있다** — 그러나 D-12 로
기존 매장은 전부 숨김이므로 W1 범위에서는 문제가 되지 않는다. 신규 매장이 임포트를 쓰면
`import_legacy` 가 `eventually_due` 라 체크리스트 밖이다.

## 1. 태스크

### TASK-1 — 마이그레이션 (파일 1개)
`api-ventago/migrations/2026-09-XX-onboarding-guide.sql`

```sql
-- w4-exempt: store_onboarding_state / onboarding_events 는 이 배포에서 처음 만들어져
--            읽는 코드가 아직 없다. 인덱스 잠금 대상 트래픽이 존재하지 않는다.
SET lock_timeout = '5s';

-- 1) 매장별 「가이드 영구 닫기」 — 추가만, nullable
ALTER TABLE stores ADD COLUMN IF NOT EXISTS onboarding_hidden_at timestamptz NULL;

-- 2) D-12: 기존 매장에는 보이지 않는다. 배포 순간부터 신규 매장만 대상.
UPDATE stores SET onboarding_hidden_at = now() WHERE onboarding_hidden_at IS NULL;

-- 3) 저장하는 것은 「의도」뿐. 완료 여부는 저장하지 않는다(SPEC D-2).
CREATE TABLE IF NOT EXISTS store_onboarding_state (
  id            serial PRIMARY KEY,
  store_id      integer NOT NULL REFERENCES stores(id),
  branch_id     integer NULL     REFERENCES branches(id),
  step_code     varchar(40) NOT NULL,
  dismissed_at  timestamptz NULL,
  snoozed_until timestamptz NULL,
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL DEFAULT now()
);
-- branch_id 가 NULL 인 행도 하나만 있어야 하므로 COALESCE 로 유일성을 만든다
CREATE UNIQUE INDEX IF NOT EXISTS uq_store_onboarding_state
  ON store_onboarding_state (store_id, COALESCE(branch_id, 0), step_code);

-- 4) append-only 원장 — 완료를 「고정」하고(SPEC D-3) 이탈 단계를 측정한다
CREATE TABLE IF NOT EXISTS onboarding_events (
  id          bigserial PRIMARY KEY,
  store_id    integer NOT NULL REFERENCES stores(id),
  branch_id   integer NULL,
  user_id     integer NULL,
  step_code   varchar(40) NOT NULL,
  event       varchar(20) NOT NULL,   -- viewed|started|completed|dismissed|undismissed
  occurred_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS ix_onboarding_events_store_step
  ON onboarding_events (store_id, step_code, occurred_at DESC);

-- 5) 운영(5434) owner 이전 — 누락 시 앱(coolsistema)이 permission denied 500
DO $$
BEGIN
  IF EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'coolsistema') THEN
    ALTER TABLE store_onboarding_state OWNER TO coolsistema;
    ALTER TABLE onboarding_events      OWNER TO coolsistema;
    ALTER SEQUENCE store_onboarding_state_id_seq OWNER TO coolsistema;
    ALTER SEQUENCE onboarding_events_id_seq      OWNER TO coolsistema;
  END IF;
END $$;
```

### TASK-2 — `OnboardingService.resolve()` (핵심)
`api-ventago/src/app/onboarding/onboarding.service.ts` (신규)

- [ ] 술어 **8개를 단일 쿼리 1회**로. 라운드트립 8회 금지:

```sql
-- $1 = store_id, $2 = branch_id
SELECT
  EXISTS (SELECT 1 FROM products p
           WHERE p.store_id = $1 AND COALESCE(p.is_generic,false) = false
             AND COALESCE(p.is_active,true) = true)                          AS load_products,
  EXISTS (SELECT 1 FROM price_type_ranges r JOIN stores s ON s.id = r.store_id
           WHERE r.store_id = $1
             AND (r.created_at > s.created_at + interval '5 minutes'
               OR r.updated_at > r.created_at + interval '1 minute'))        AS set_prices,
  EXISTS (SELECT 1 FROM payment_methods m JOIN stores s ON s.id = m.store_id
           WHERE m.store_id = $1
             AND (m.created_at > s.created_at + interval '5 minutes'
               OR m.updated_at > m.created_at + interval '1 minute'))        AS check_payment_methods,
  EXISTS (SELECT 1 FROM branch_agents a
           WHERE a.branch_id = $2 AND a.last_seen_at IS NOT NULL)            AS connect_printer,
  EXISTS (SELECT 1 FROM sales sa
           WHERE sa.store_id = $1 AND sa.branch_id = $2)                     AS first_sale;
```
