1. `extract-and-build-payload.sh` 생성 — 기존 DB에서 5개 쿼리를 실행하고 결과를 하나의 import-payload.json으로 조합하는 bash 스크립트
2. 환경변수로 DB 접속 정보를 받음:
   ```bash
   LEGACY_HOST=${LEGACY_HOST:-localhost}
   LEGACY_PORT=${LEGACY_PORT:-5432}
   LEGACY_DB=${LEGACY_DB:-legacy_db}
   LEGACY_USER=${LEGACY_USER:-postgres}
   LEGACY_PASS=${LEGACY_PASS:-}
   TARGET_BRANCH_ID=${TARGET_BRANCH_ID:-1}
   ```
3. psql로 각 쿼리 실행 → JSON 결과를 임시 파일에 저장
4. jq 또는 node로 5개 JSON을 하나의 payload로 조합:
   ```json
   {
     "categories": [...],
     "colors": [...],
     "sizes": [...],
     "parents": [...],
     "variants": [...],
     "targetBranchId": N
   }
   ```
5. NULL/빈값 정제: null legacyId, 빈 name 등 제거
6. 결과: `import-payload.json` 출력
  </action>
  <verify>
    <automated>bash api-ventago/migrations/extract-and-build-payload.sh && python3 -m json.tool import-payload.json > /dev/null && echo "Valid JSON"</automated>
  </verify>
  <acceptance_criteria>
    - extract-and-build-payload.sh 실행 시 import-payload.json 생성
    - JSON이 유효하고 categories/colors/sizes/parents/variants/targetBranchId 키 모두 존재
    - parents 배열의 각 항목에 legacyId, sku, name, price 존재
    - variants 배열의 각 항목에 sku, name, price, parentLegacyId 존재
  </acceptance_criteria>
