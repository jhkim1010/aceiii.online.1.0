## Notas HTTP contract (backend implements in 96-05/96-06/96-07 — frontend codes against this)

All `/notas*` routes require JWT + permission `ver-notas` (read) except where noted.
- `GET /notas?tab=todas|mi|enviadas|archivadas|vencidas&q=<text>&page=0&pageSize=50` → `NotasListResponse`
- `GET /notas/unread` → `{ total: number; mi: number; replies: number }` (total = badge)
- `GET /notas/:id` → `NotaDetail` (404 if not visible)
- `GET /notas/:id/reads` → `NotaReadsResponse` (403 unless can.seeReads)
- `GET /notas/:id/history` → `NotaHistoryEntry[]`
- `POST /notas` multipart → `NotaDetail`   (personal / selected users) fields: title, body, importance, expiresOn, recipientIds ("4,5"), files[] ≤5
- `POST /notas/todos` multipart → `NotaDetail` (requires `notas-enviar-todos` create) fields: title, body, importance, expiresOn, pinned ("true"|"false"), files[] ≤5
- `PATCH /notas/:id` JSON `{ title, body, importance, expiresOn: string|null }` → `NotaDetail`
- `POST /notas/:id/archive` → `{ ok: true }`
- `POST /notas/:id/pin` JSON `{ pinned: boolean }` → `{ pinned: boolean }`
- `POST /notas/:id/seen` → `{ ok: true }`
- `POST /notas/:id/ack` → `{ ackAt: string }`
- `POST /notas/:id/replies` multipart fields: body, photo (≤1 image) → `NotaReplyItem`
- `POST /notas/:id/reactions` JSON `{ emoji: ReactionKey; replyId?: number }` → `{ active: boolean }`
- `GET /nota-adjuntos/:attachmentId` → binary stream (auth + visibility checked)
- Store users for the recipient picker: reuse `GET /team-chat/users` → `{ id, name, lastName, username }[]` (D-01: reuse, do not modify team-chat)
- Socket `/realtime` events: `nota:new` `{ id, title, importance, audience, senderId, senderName }`,
  `nota:reply` `{ notaId, notaTitle, replyId, userId, userName }`, `nota:reaction` `{ notaId, replyId }`,
  `nota:changed` `{ notaId }`

From ventago-app/src/hooks/useApi.ts:
```ts
export function useApi<T = unknown>(url: string | null, options?: SWRConfiguration): { data, error, isLoading, mutate }
```
From ventago-app/src/services/api.service.ts (`apiConnector`): `get(path, params?)`, `post(path, body)`,
`patch(path, body)`, `sendFile(path, formData)` (POST multipart), `getBlob(path, params?) => Promise<Blob>`.
Use `apiConnector.remove` never `.delete` (not needed here).
From ventago-app/src/configs/access-structure.ts: `funcionesEnAmbito(estructura: EstructuraApp[], ...)` returns function slugs present in `/me` structure.
