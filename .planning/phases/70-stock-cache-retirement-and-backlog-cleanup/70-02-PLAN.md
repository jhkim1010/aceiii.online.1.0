### T1 — 삭제 직전 재검증 (건너뛰지 말 것)
조사는 2026-08-03 기준이다. 각 브랜치마다 **삭제 직전에** 다시 확인한다:

```bash
git fetch --all --prune
git log --oneline origin/main..<branch>          # 0줄이어야 삭제 가능
git merge-base --is-ancestor <branch> origin/main && echo MERGED || echo NOT_MERGED
```

**한 줄이라도 나오면 삭제하지 말고 보고한다.**

### T2 — 독립 히스토리 백업
`split/mobile-sales-app` 은 `origin/main` 과 **공통 조상이 없다**(`git merge-base` 결과 없음). 다른 브랜치와 성격이 다르므로 먼저:

```bash
# 1) mobile-sales-app 서브모듈에 초기 커밋들이 온전한지 확인
cd mobile-sales-app && git log --oneline | tail -20
# 2) 루트에서 태그 백업
cd .. && git tag archive/split-mobile-sales-app split/mobile-sales-app
git push origin archive/split-mobile-sales-app
```

태그 push 가 성공한 것을 **확인한 뒤에만** 브랜치를 지운다.
