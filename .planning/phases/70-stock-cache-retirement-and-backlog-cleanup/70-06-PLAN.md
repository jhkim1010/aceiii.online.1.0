<objective>
**이 Phase 의 핵심.** `trg_stocks_sync_product_cache` 를 폐기하고 `products.stock` 을 진단용 파생값으로 강등한다.

현행 트리거는 변형이 팔릴 때마다 **부모 행까지 잠근다**:

```sql
UPDATE products SET stock = COALESCE(stock,0) + NEW.stock
 WHERE id = v_product_id OR (v_parent_id IS NOT NULL AND id = v_parent_id);
```

마드레 하나에 변형 20개가 달려 있으면 그 20개의 모든 판매가 **부모 행 한 줄에서 직렬화**된다. 터미널이 늘수록 정확히 여기서 막힌다 — 읽기를 아무리 빠르게 해도 소용없는 지점이다.

`stock_balances` 는 `ProductBranch` 단위라 부모 행을 건드리지 않는다. 마드레 합계는 읽을 때 자식을 더한다(`idx_sb_store_parent`).

Purpose: 쓰기 경합 제거. 이게 Phase 63(터미널 3,000대) 의 선결 조건이다.
Output: 부모 행 잠금이 없는 쓰기 경로 + 되돌릴 수 있는 마이그레이션.
</objective>
