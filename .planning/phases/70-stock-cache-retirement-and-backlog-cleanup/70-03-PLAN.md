### T2 — 삭제 액션
`COLUMNS_PARENT` / `ProductParentList.tsx` 에 삭제 아이콘 칼럼 추가.

- `apiConnector.remove('/products/' + id)` — **`.delete()` 아님** (프로젝트 규약)
- 확인 대화상자에 상품명·SKU 표시
- **삭제 전 재고 이력 경고**: 해당 상품에 `stock_balances.movimientos > 0` 이면 "이 상품에는 재고 이력이 있습니다" 를 대화상자에 표시. 원장은 append-only 라 상품을 지워도 이력은 남는다는 점을 사용자가 알아야 한다
- 성공 후 목록 갱신(SWR mutate 또는 재조회). 실패 시 에러 스낵바
- 권한 `eliminar-un-producto` 가 없으면 아이콘 자체를 렌더하지 않는다

### T3 — SKU 수정
`BasicDataCard` 의 sku 필드는 `autoSku` 해제 시 편집 가능하다. 저장 시 `PUT /products/:id` 를 호출하도록 연결.

- SKU 중복은 백엔드가 거부한다 → 그 에러 메시지를 스낵바로 그대로 노출
- 권한 `editar-un-producto` 없으면 필드를 읽기 전용으로

### T4 — 백엔드 확인만
`products.controller.ts` 의 두 엔드포인트가 **`storeId` 를 강제하는지** 확인한다. 안 하고 있으면 그것만 고친다 (다른 매장 상품 삭제 방지). 그 외 백엔드 변경 없음.
