## Step 0 (Pre-flight): print-agent를 gitlink → 일반 디렉토리로 변환

**왜 필요한가:** `print-agent`는 현재 root repo에 gitlink(SHA 160000 mode)로
등록되어 있으나 `.gitmodules`가 없고 자체 GitHub remote도 없다. 이 상태에서
`actions/checkout@v4`를 실행하면 runner는 `print-agent/` 를 빈 디렉토리로
내버려둬 CI 빌드가 즉시 실패한다.

**해결:** Wave 5 시작 직전에 print-agent를 root repo의 **일반 디렉토리**로 통합.
api-ventago/ventago-app과 달리 print-agent는 외부 remote가 없으므로
서브모듈로 유지할 이유가 없다.

```bash
# 1. print-agent 자체 nested git 제거 (로컬 히스토리 보존이 필요하면 별도 백업)
rm -rf print-agent/.git

# 2. gitlink 제거 + 일반 디렉토리로 재스테이징
cd /Users/marcoskim/Trabajos_Programming/ACE_online_1.0
git rm --cached print-agent         # gitlink 엔트리 제거
git add print-agent/                 # 실제 파일들을 blob으로 추가

# 3. 확인
git ls-tree HEAD print-agent || true # (이전 gitlink)
git ls-files print-agent | head -5   # main.js, package.json, src/*, renderer/* 등이 나와야 함

# 4. 커밋 (Wave 5 첫 커밋)
git commit -m "chore(11-05): promote print-agent gitlink to regular directory for CI"
```

**주의:**
- `print-agent/.git` 삭제 시 nested repo의 Wave 1~4 커밋 히스토리는 소실된다.
  필요하면 `print-agent/.git` 를 `~/backups/print-agent-repo-backup/.git`로 복사해 보관.
- 루트 repo에는 Wave 1~4의 "변경 결과물"이 이미 루트 커밋(`612db76`, `0c8c5b2` 등)의
  gitlink bump 형태로 기록되어 있다. 승격 후에는 파일 내용이 직접 추적된다.
- `api-ventago`, `ventago-app` 는 외부 GitHub remote가 있는 정상 서브모듈이므로 건드리지 않는다.

## Step 1: GitHub Actions 워크플로우 (0.3일)

**모노레포 전략:** root repo가 `npm workspaces`를 사용하므로 `cd print-agent && npm ci`는
workspace 부모를 추적하지 못해 실패한다. root에서 `npm ci`로 전체 워크스페이스를 한 번에
설치한 뒤 `-w print-agent` 플래그로 빌드 스크립트만 실행한다.

```yaml
# .github/workflows/build-print-agent.yml

name: Build & Release Print Agent

on:
  push:
    tags:
      - 'print-agent-v*'    # 예: print-agent-v1.0.0

permissions:
  contents: write           # Release 생성 + 파일 업로드 권한

jobs:
  # ── Windows .exe 빌드 ──────────────────────────────────────────────────
  build-windows:
    name: Windows NSIS Installer
    runs-on: windows-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        # 참고: print-agent는 Step 0 pre-flight에서 gitlink → 일반 디렉토리로 승격됨.
        #       submodules 옵션 불필요 (api-ventago/ventago-app은 빌드에 불필요).

      - name: Setup Node 20
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
          cache-dependency-path: package-lock.json    # root lockfile

      - name: Install workspace dependencies (root)
        run: npm ci --workspaces=false --include-workspace-root=false --include=print-agent
        # 위 플래그 조합이 동작하지 않는 npm 버전 대비 fallback:
        #   npm ci
        # (루트에서 모든 워크스페이스 일괄 설치)

      - name: Rebuild native modules for Electron
        run: npx --yes electron-builder install-app-deps --projectDir print-agent

      - name: Build Windows installer
        run: npm run build:win -w print-agent
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Upload .exe to Release
        uses: softprops/action-gh-release@v2
        with:
          files: print-agent/build/VentaGO-Print-Agent-Setup-*.exe
          tag_name: ${{ github.ref_name }}
          fail_on_unmatched_files: true    # glob 매칭 실패 시 즉시 에러 (조용한 실패 방지)

  # ── macOS .dmg 빌드 ────────────────────────────────────────────────────
  build-macos:
    name: macOS DMG
    runs-on: macos-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node 20
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
          cache-dependency-path: package-lock.json

      - name: Install workspace dependencies (root)
        run: npm ci

      - name: Rebuild native modules for Electron
        run: npx --yes electron-builder install-app-deps --projectDir print-agent

      - name: Build macOS DMG
        run: npm run build:mac -w print-agent
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          # 코드 서명 없이 빌드 (개발 초기)
          CSC_IDENTITY_AUTO_DISCOVERY: false

      - name: Upload .dmg to Release
        uses: softprops/action-gh-release@v2
        with:
          files: print-agent/build/VentaGO-Print-Agent-*.dmg
          tag_name: ${{ github.ref_name }}
          fail_on_unmatched_files: true
```

**주의사항:**
- `secrets.GITHUB_TOKEN`은 GitHub이 자동 제공 — 별도 설정 불필요
- `CSC_IDENTITY_AUTO_DISCOVERY: false` — 코드 서명 없이 빌드 (개발 단계). macOS 사용자는 Gatekeeper 경고 시 System Settings → Privacy에서 허용 필요
- 나중에 서명이 필요하면 `CSC_LINK`, `CSC_KEY_PASSWORD` secret 추가
- **네이티브 모듈 재빌드 필수:** `escpos-usb`는 libusb 바인딩이라 Electron ABI에 맞춰
  재컴파일해야 한다. `electron-builder install-app-deps` 가 자동 처리.
- **cache-dependency-path는 root `package-lock.json`** — 모노레포라서 print-agent 독립
  lockfile은 존재하지 않는다.

## Step 2: `print-agent/package.json` build 스크립트 확인

**핵심 변경 요점:**
1. **`artifactName` 명시** — electron-builder 기본 파일명은 공백 포함 (`"VentaGO Print Agent Setup 1.0.0.exe"`).
   워크플로우 glob `VentaGO-Print-Agent-Setup-*.exe`가 매칭 실패한다.
   → `artifactName`을 명시해 하이픈 포함 고정 이름으로 생성.
2. **latest URL 안정화** — 버전 없는 이름(`VentaGO-Print-Agent-Setup.exe`)을 사용해야
   `releases/latest/download/VentaGO-Print-Agent-Setup.exe` 영구 링크가 동작.
3. **`postinstall` 제거** — 워크플로우가 `electron-builder install-app-deps`를 명시적으로
   호출하므로 postinstall에 중복 추가하지 않는다 (로컬 개발 시 불필요한 재빌드 방지).
4. **`publish: never`** — electron-builder 자체 Release 자동 업로드 비활성화 (Actions에 위임).
5. **`win.icon` / `mac.icon` 는 파일이 존재할 때만 빌드에 포함**. 현재 `logo.ico`/`logo.icns`는
   미작성 상태 → Step 2에서 icon 필드를 주석 처리하거나 placeholder 아이콘 생성 필수.
   (또는 electron-builder 기본 아이콘 사용)

```typescript
export const PRINT_AGENT_DOWNLOADS = {
```

**주의:** macOS는 Intel/Apple Silicon 두 개를 제공한다. `PrinterConfigTab` 의
다운로드 버튼도 `Mac (Intel)` / `Mac (Apple Silicon)` 로 분리하거나,
`navigator.userAgent` 기반 자동 감지 후 단일 버튼 노출 둘 중 택일.
운영 단순성을 위해 버튼 2개로 명시적 노출을 권장.

### `PrinterConfigTab.tsx` — 완성 형태

```tsx
// ventago-app/src/views/sucursales/PrinterConfigTab.tsx

import { useState } from 'react'
import {
  Box, Typography, Button, Paper, Stack, Chip,
  IconButton, Tooltip, Divider, CircularProgress,
  Dialog, DialogTitle, DialogContent, DialogActions,
} from '@mui/material'
import ContentCopyIcon  from '@mui/icons-material/ContentCopy'
import RefreshIcon      from '@mui/icons-material/Refresh'
import CheckCircleIcon  from '@mui/icons-material/CheckCircle'
import RadioButtonUncheckedIcon from '@mui/icons-material/RadioButtonUnchecked'
import DownloadIcon     from '@mui/icons-material/Download'
import OpenInNewIcon    from '@mui/icons-material/OpenInNew'
import useSWR, { mutate } from 'swr'
import { apiConnector } from 'src/services/api.service'
import { PRINT_AGENT_DOWNLOADS } from 'src/config/printAgent'

// ── SWR fetcher ──────────────────────────────────────────────────────────────
const fetcher = (url: string) => apiConnector.get(url).then((r: any) => r.data)

interface PrinterConfigTabProps {
  branchId: number
}

export default function PrinterConfigTab({ branchId }: PrinterConfigTabProps) {
  const [copied, setCopied]           = useState(false)
  const [regenDialog, setRegenDialog] = useState(false)
  const [regenLoading, setRegenLoading] = useState(false)

  // 30초 폴링으로 온라인 상태 갱신
  const { data, isLoading } = useSWR(
    `/print/config/${branchId}`,
    fetcher,
    { refreshInterval: 30_000 }
  )

  const apiKey    = data?.apiKey    ?? '—'
  const isOnline  = data?.isOnline  ?? false
  const lastSeen  = data?.lastSeenAt
    ? new Date(data.lastSeenAt).toLocaleString('es-AR')
    : null

  // API Key 클립보드 복사
  const handleCopy = () => {
    navigator.clipboard.writeText(apiKey)
    setCopied(true)
    setTimeout(() => setCopied(false), 2000)
  }

  // API Key 재발급
  const handleRegen = async () => {
    setRegenLoading(true)
    try {
      await apiConnector.post(`/print/config/${branchId}/regenerate-key`, {})
      await mutate(`/print/config/${branchId}`)
    } finally {
      setRegenLoading(false)
      setRegenDialog(false)
    }
  }

  return (
    <Box sx={{ p: 3, maxWidth: 620 }}>

      {/* ── 에이전트 상태 ── */}
      <Typography variant="overline" color="text.secondary">
        Estado del Agente
      </Typography>
      <Stack direction="row" alignItems="center" spacing={1} mt={0.5} mb={3}>
        {isLoading ? (
          <CircularProgress size={16} />
        ) : isOnline ? (
          <CheckCircleIcon sx={{ color: 'success.main', fontSize: 20 }} />
        ) : (
          <RadioButtonUncheckedIcon sx={{ color: 'text.disabled', fontSize: 20 }} />
        )}
        <Typography variant="body2" fontWeight="bold">
          {isOnline ? 'Conectado' : 'Desconectado'}
        </Typography>
        {lastSeen && (
          <Typography variant="caption" color="text.secondary">
            · última vez: {lastSeen}
          </Typography>
        )}
      </Stack>

      {/* ── API Key ── */}
      <Typography variant="overline" color="text.secondary">
        API Key
      </Typography>
      <Paper
        variant="outlined"
        sx={{ display: 'flex', alignItems: 'center', px: 2, py: 1, mt: 0.5, mb: 1 }}
      >
        <Typography
          variant="body2"
          fontFamily="monospace"
          sx={{ flex: 1, overflow: 'hidden', textOverflow: 'ellipsis', whiteSpace: 'nowrap' }}
        >
          {apiKey}
        </Typography>
        <Tooltip title={copied ? '¡Copiado!' : 'Copiar'}>
          <IconButton size="small" onClick={handleCopy}>
            <ContentCopyIcon fontSize="small" />
          </IconButton>
        </Tooltip>
      </Paper>
      <Button
        size="small"
        startIcon={<RefreshIcon />}
        color="warning"
        onClick={() => setRegenDialog(true)}
        sx={{ mb: 3 }}
      >
        Regenerar API Key
```
