## Step 1: DB 마이그레이션 — `branch_printer_configs` (0.2일)

```sql
-- Sequelize 마이그레이션 파일
-- api-ventago/src/migrations/YYYYMMDD-create-branch-printer-configs.ts

CREATE TABLE branch_printer_configs (
  id           SERIAL PRIMARY KEY,
  branch_id    INTEGER NOT NULL REFERENCES branches(id) ON DELETE CASCADE,
  api_key      VARCHAR(64) NOT NULL UNIQUE DEFAULT gen_random_uuid()::text,
  is_online    BOOLEAN NOT NULL DEFAULT FALSE,
  last_seen_at TIMESTAMPTZ,
  printer_info JSONB,        -- { type, vendorId, productId, host, port }
  created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  CONSTRAINT uq_branch_printer UNIQUE (branch_id)
);

CREATE INDEX idx_bpc_api_key ON branch_printer_configs(api_key);
```

**Sequelize 모델:** `BranchPrinterConfig`
- `branchId: number` (FK → branches)
- `apiKey: string` (UUID v4 자동 생성)
- `isOnline: boolean`
- `lastSeenAt: Date | null`
- `printerInfo: object | null`

### `print.gateway.ts` — Socket.io 게이트웨이

```typescript
// 지점별 print-agent WebSocket 연결 수락
// 네임스페이스: /print-agent

@WebSocketGateway({ namespace: '/print-agent', cors: true })
export class PrintGateway {
  @WebSocketServer() server: Server;

  // agent_online 수신 → DB isOnline=true, lastSeenAt=now
  @SubscribeMessage('agent_online')
  async handleOnline(
    @ConnectedSocket() client: Socket,
    @MessageBody() payload: { branchId: number; version: string },
  ) {
    await this.printService.setOnline(payload.branchId, true, client.id);
    client.join(`branch:${payload.branchId}`);  // room 등록
  }

  // disconnect → DB isOnline=false
  async handleDisconnect(client: Socket) {
    await this.printService.setOfflineBySocketId(client.id);
  }

  // print_ack 수신 → 로그 (선택)
  @SubscribeMessage('print_ack')
  handleAck(@MessageBody() payload: { invoiceId: number; status: string }) {
    // 필요 시 로그 기록
  }
}
```

### `print.service.ts` — emit 메서드

```typescript
// pool 낭비 없이 단일 UPDATE
async emitPrintInvoice(branchId: number, data: PrintInvoiceDto): Promise<void> {
  this.gateway.server
    .to(`branch:${branchId}`)
    .emit('print_invoice', data);
  // fire-and-forget — await 없음
}

async emitPrintFiscal(branchId: number, data: PrintFiscalDto): Promise<void> {
  this.gateway.server
    .to(`branch:${branchId}`)
    .emit('print_fiscal', data);
  // fire-and-forget — await 없음
}

// API Key 인증 (WebSocket 연결 시 auth.token 검증)
async validateApiKey(apiKey: string): Promise<BranchPrinterConfig | null> {
  // SELECT 1회 — pool 최소 사용
  return this.bpcRepo.findOne({ where: { apiKey } });
}

// 온라인 상태 업데이트
async setOnline(branchId: number, isOnline: boolean, socketId?: string) {
  await this.bpcRepo.update(
    { branchId },
    { isOnline, lastSeenAt: new Date(), printerInfo: { socketId } },
  );
}
```

### PrintGuard (WebSocket 인증)

```typescript
// 연결 요청 시 auth.token → validateApiKey() → 실패 시 disconnect
@Injectable()
export class PrintGuard implements CanActivate {
  async canActivate(context: ExecutionContext): Promise<boolean> {
    const client = context.switchToWs().getClient<Socket>();
    const token  = client.handshake.auth?.token;
    const cfg    = await this.printService.validateApiKey(token);

    if (!cfg) { client.disconnect(); return false; }

    client.data.branchId = cfg.branchId;  // 이후 핸들러에서 사용

    return true;
  }
}
```

## Step 5: electron-builder 패키징 (0.3일)

```bash
# Windows NSIS 인스톨러
cd print-agent
npm run build:win
# → build/VentaGO-Print-Agent-Setup-1.0.0.exe

# macOS DMG
npm run build:mac
# → build/VentaGO-Print-Agent-1.0.0.dmg
```

**주의사항:**
- Windows 빌드는 Windows 환경 또는 Wine 필요
- macOS 빌드는 macOS 환경 필요 (코드 서명 선택)
- `asar: true` 설정으로 소스 보호
- `extraResources` 미사용 — 모든 의존성은 `files`에 포함
