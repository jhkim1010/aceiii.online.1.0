# Plan 11-06 (Wave 6): Nueva Venta "Imprimir Temp" 임시 티켓 출력

## 목표

`nueva-venta` POS 화면에서 판매 확정 전 상태의 카트 스냅샷을
**"Imprimir Temp"** 버튼 한 번으로 지점 Print Agent에 전달하여
80mm 감열지에 **임시(견적) 티켓**으로 출력한다.
고객 확인용 견적/미리보기 용도이며 판매번호·CAE 없이, DB 기록 없이 실행된다.

1. 신규 파일 작성:
   ```ts
   import apiConnector from 'src/services/api.service'

   export interface TempTicketPayload {
     branchId?: number
     store?: { name?: string; address?: string; phone?: string; cuit?: string; logoUrl?: string }
     invoice?: { seller?: string; client?: string }
     items: Array<{ quantity: number; name: string; unitPrice: number; subtotal: number }>
     totals: { subtotal: number; totalAmount: number; transport?: number }
     discounts?: Array<{ name: string; amount: number }>
     recharges?: Array<{ name: string; amount: number }>
   }

   // 임시(견적) 티켓 출력 — 백엔드가 지점 Print Agent로 fire-and-forget emit
   // Agent 오프라인이어도 예외 던지지 말고 { ok: false } 반환
   export async function printTempTicket(payload: TempTicketPayload) {
     try {
       const res = await apiConnector.post('/print/temp', payload)

       return res?.data ?? { ok: false }
     } catch (err) {
       return { ok: false, error: (err as any)?.message || 'network' }
     }
   }
   ```
2. `api.service.ts`에서 `apiConnector`의 정확한 export 이름 확인 후 import 경로 맞춤 (`default` vs named)
