# Plan 11-01 (Wave 1): 그래픽 출력 파이프라인 코어

## 목표

Electron 앱의 핵심 출력 엔진을 완성한다.
텍스트 모드가 아닌 **HTML → PNG → ESC/POS 래스터** 방식으로
80mm 감열지에 색상·볼드·2줄 줄바꿈이 표현되는 현대적 티켓을 출력한다.

---

## ✅ 완료된 파일

### 1. `src/formatter.js` — HTML 티켓 생성기

**핵심 함수:** `formatInvoiceHtml(data)` → HTML 문자열

**레이아웃 섹션:**
- 최상단 배너: `DOCUMENTO NO VÁLIDO COMO FACTURA` (검정배경·흰글)
- 매장 헤더: 매장명(대문자·굵게), 주소, 전화, CUIT
- 티켓 메타: 번호(Copia N / #), 날짜, 시간, 판매자, 고객
- 상품 테이블: 4컬럼 (Cnt / Descripcion / P.Unit / SubTot)
- 소계 구역: `<table class="sum-table">` — 행별 색상 적용
- 결제수단: ★ 아이콘 + 방법 + 금액
- 푸터: 고객 감사 메시지

**소계 구역 행 순서 및 스타일:**

```
Subtotal          209.000   ← .subtotal-line (color:#333, bold)
+ Recargo —  ...  +20.900   ← .plus (color:#1565c0, bold)
− Descuento — ... −10.450   ← .minus (color:#c62828, bold)
− Desc. {item} ..  −5.000   ← .minus (상품별 할인도 여기로)
+ Envío           + 2.500   ← .plus (transport > 0일 때만)
─────────────────────────
TOTAL          $ 217.950    ← .total-block (검정배경·흰글·30px)
```

**상품 행 규칙:**
- 개별 discount는 행에 표시 안 함 — 전부 소계 구역으로
- 상품명 2줄 제한: `-webkit-line-clamp: 2` (넘치면 말줄임표)

**입력 데이터 스펙:**
```javascript
{
  store:    { name, address?, phone?, cuit? },
  invoice:  { number, date, copy? },
  seller:   { name },
  client:   { name?, document? },
  items:    [{ code?, name, quantity, unitPrice, subtotal, discount? }],
  discounts:[{ name, amount }],
  recharges:[{ name, amount }],
  totals:   { subtotal, transport?, totalAmount },
  paymentMethods: [{ method, option?, amount, change? }],
  footer:   { line1?, line2? },
}
```

**하위 호환:** `formatInvoice(data, width=48)` — 텍스트 fallback (Electron 없는 환경용)

### 2. `src/renderer-engine.js` — Electron offscreen BrowserWindow

```javascript
// 핵심 API
async function renderHtmlToPng(html, width = 576, timeout = 10000)
  → Buffer (PNG)
```

**구현 특징:**
- 싱글턴 패턴: `offscreenWin` 한 번만 생성 후 재사용 (pool 낭비 없음)
- 직렬 큐: Promise 체인으로 동시 render 방지
- `offscreen: true`: 화면에 창 안 띄움
- `capturePage()`: Electron 내장 Chromium 렌더링 → PNG NativeImage
- 높이 자동: `executeJavaScript('document.body.scrollHeight')` → `setSize(576, h)`
- `webSecurity: false`: 로컬 파일 로드 허용
- Electron app `ready` 이후에만 호출 가능

**의존성:** Electron 내장 Chromium (별도 Puppeteer 불필요)

### 3. `src/print-pipeline.js` — 3단계 파이프라인

```javascript
// 핵심 API
async function printTicket(data, printerConfig)
```

**3단계:**
1. `formatInvoiceHtml(data)` → HTML
2. `renderHtmlToPng(html, 576)` → PNG Buffer
3. `printImage(pngBuffer, printerConfig)` → 프린터 출력

**에러 처리:** 각 단계 실패 시 throw — 호출자(main.js)에서 catch하여 `print_ack` 에러 응답

## 검증 방법

```bash
# 미리보기 HTML 생성 (브라우저에서 직접 확인)
node gen-preview.js
# → ticket-preview.html 생성

# 샘플 데이터 포함 항목:
# - 상품 3개 (1개는 이름이 길어 2줄)
# - recharges: [{ name: 'Tarjeta Crédito 10%', amount: 20900 }]
# - discounts:  [{ name: 'Cliente VIP 5%', amount: 10450 }]
# - items[0].discount = 5000 (상품별 할인)
# - totals.transport = 2500 (+ Envío 행)
# - paymentMethods: [{ method: 'Tarjeta', option: 'VISA Cuotas 3', amount: 217950 }]
```

**육안 체크리스트:**
- [ ] Subtotal 행이 굵게 표시됨
- [ ] `+ Recargo` 행이 파란색으로 표시됨
- [ ] `− Descuento` 행이 빨간색으로 표시됨
- [ ] `− Desc. {상품명}` 행(상품별 할인)이 빨간색으로 표시됨
- [ ] `+ Envío` 행이 파란색으로 표시됨
- [ ] TOTAL 블록이 검정배경·흰글·큰 숫자로 표시됨
- [ ] 긴 상품명이 2줄로 표시됨
- [ ] 상품 행에 discount 행이 없음
