<objective>
`getMatrix()` 응답의 각 셀에 **편집 가능 여부**를 싣는다.

Purpose: 지금 프론트는 `branchId`·`productBranchId` 로 합산/모호성만 판정할 수 있고,
**부모(madre) PB 여부는 응답에 없다**. 그래서 "부모는 입력칸을 주지 않는다" 를
프론트만으로는 구현할 수 없다(CODEX C8).
</objective>

<constraints>

- 기존 응답 필드는 건드리지 않는다(추가만) — 다른 소비자가 있다.
- 부모 판정은 기존 `findMadreProductIds` 를 재사용한다(판정이 두 벌이 되면 갈라진다).
</constraints>

<tasks>

   - `AMBIGUOUS_PB` — 기여 PB 가 2개 이상(`byBranch.length > 1`)
   - `MADRE` — 부모 PB (원장 트리거가 막는다)
2. 부모 판정은 매트릭스의 productId 들을 **한 번에** 조회(제품마다 개별 쿼리 금지).
</tasks>
