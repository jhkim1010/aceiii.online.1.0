<objective>
Phase 12의 표준 사례 Wave. Vendedor 보고서를 `vendor-cockpit-mockup.html`의 디자인대로 완전 재구현한다. 이 Wave가 완료되면 나머지 14개 보고서가 동일한 패턴을 복제할 수 있는 reference가 된다.

**구현 항목:**

1. **KPI Strip** (`VendorKpiStrip.tsx`)
   - 4개 KPI: 총매출 / 총건수 / 객단가 / 평균할인율
   - 각 KPI에 전기 대비 ↑↓ % 표시 (녹색/빨강/회색)
   - 우측에 🥇 Top Vendedor 위젯 (아바타+이름+매출)

2. **VendorCard** (`VendorCard.tsx`)
   - props: `vendor, rank, selected, onSelect, compareMode`
   - 구성: 아바타(이니셜+컬러) / 이름 / 메달 또는 #순위 / 큰 매출 / 전기대비 / Meta 게이지바 / 건수·객단가·할인율·환불 / 7일 sparkline / 배지 (🔥⚠💎)
   - selected 상태: 파란 테두리 + 그림자
   - 약 170×220px

3. **VendorCardGrid** (`VendorCardGrid.tsx`)
   - 헤더: 제목 + 정렬 select + ⚖ Comparar 토글
   - `auto-fill, minmax(170px, 1fr)` 그리드, gap 10px
   - 정렬: 매출/건수/객단가/Meta%/할인율
   - 비교 모드: 다중 선택(최대 4명)

4. **VendorDetailTabs** (`VendorDetailTabs.tsx`)
   - 좌측: 선택된 판매원 정보 (아바타 + 이름 + 메달 + 요약)
   - 탭 3개: 📈 Tendencia / 🛒 Mix / 📋 Ventas (N)
   - 탭 콘텐츠는 각각 별도 컴포넌트

5. **VendorTendenciaChart** — 일별 매출 SVG 라인 차트 (recharts 또는 D3)

6. **VendorMixPanel** — 좌측 카테고리 도넛, 우측 Top 10 상품 막대

7. **VendorVentasTable** — 기존 venta 리스트, 행 클릭 → 드로워

8. **VentaDetailDrawer** — fixed right 380px, 슬라이드 애니메이션
   - 헤더: venta 번호 + 닫기
   - 본문: 고객/날짜/결제수단/판매원, 상품 라인 표, subtotal/descuento/total

9. **useVendedorReport 확장** — `getVendedorCockpit(params)` 호출, `{ kpis, vendors, selectedVendorDetail }` 반환

10. **백엔드 통합 엔드포인트** (`vendedor.service.ts`)
    - 신규 메소드 `getVendedorCockpit(storeId, params)`
    - **단일 connection, 단일 쿼리**로 KPI 집계 + 판매원별 집계 + sparkline 데이터를 raw SQL로 한 번에 반환
    - sequelize.query with QueryTypes.SELECT, 7일 sparkline은 generate_series + LEFT JOIN
    - Pool 사용량: 1 connection × 1 query (현재 N+1 패턴 대비 압도적 절약)

**참조:** `vendor-cockpit-mockup.html` 픽셀 단위로 일치시킬 것.

**Pool 절약 검증:**
- Wave 종료 후 마지막 Jenkins 빌드 로그를 확인하고, 신규 엔드포인트 호출 시 `pg_stat_activity`에서 connection이 1개를 초과하지 않는지 검증.
