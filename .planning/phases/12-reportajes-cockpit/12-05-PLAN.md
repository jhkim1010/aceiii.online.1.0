<objective>
Inventario 카테고리 5개 보고서를 Cockpit 패턴으로 마이그레이션.

**Stocks (Stock Rpt Gen) cockpit:**
- KPI: 총 SKU / 총 재고가치 / 부족 품목 / 데드 스톡 수
- Primary: 카테고리별 재고 가치 treemap 또는 막대
- Detail: 📋 SKU 리스트 / ⚠ 부족 / 💀 데드 스톡

**Corregido cockpit (재고 정정):**
- KPI: 정정 건수 / 영향 금액 / 사용자별 통계
- Primary: 일별 정정 막대
- Detail: 📋 Lista / 👤 사용자별 / 📈 추세

**Movidos (이동) cockpit:**
- KPI: 이동 건수 / 출발지 / 도착지
- Primary: 출발지→도착지 sankey 또는 막대
- Detail: 📋 Lista / 🏬 매장 간

**Fallados (불량) cockpit:**
- KPI: 불량 건수 / 손실 금액 / Top 불량 품목
- Primary: 일별 불량 막대 + Top 5 품목
- Detail: 📋 Lista / 📦 품목별

**Ingreso (입고) cockpit:**
- KPI: 입고 건수 / 입고 금액 / 공급사 수
- Primary: 일별 입고 + 공급사별 도넛
- Detail: 📋 Lista / 🏭 공급사별 / 📈 추세

**Pool 절약:** 모든 보고서 단일 엔드포인트, 단일 쿼리 패턴. 부족 품목 같은 alert는 같은 쿼리 내 CASE WHEN으로 계산.
</objective>
