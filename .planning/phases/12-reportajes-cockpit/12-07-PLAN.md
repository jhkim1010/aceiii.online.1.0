<objective>
Phase 12의 옵션 B (비교 모드)와 옵션 D (개인화/배지)를 모든 보고서에 통합.

**구현 항목:**

1. **Compare Toggle + Compare Panel**
   - 카드 그리드 헤더에 ⚖ Comparar 토글 (이미 12-02에서 UI는 만들어짐, 여기서 로직 완성)
   - 활성 시 카드 다중 선택 (최대 4개, 각각 다른 색)
   - 하단 Detail Area의 탭이 자동으로 비교 뷰로 전환:
     - Tendencia: 여러 색 라인이 겹쳐서 표시
     - Mix: 카테고리 stacked bar로 비교
     - Lista 탭은 비교 모드에서 비활성

2. **Meta(목표) 입력 시스템**
   - DB: `users` 테이블에 `monthly_sales_target NUMERIC NULL` 컬럼 추가 (PostgreSQL 안전 마이그레이션)
   - 신규 API: `PUT /users/:id/meta` (단일 connection)
   - 프론트 다이얼로그: 카드 더블클릭 또는 카드의 Meta 게이지바 클릭 시 입력 모달
   - Meta 값이 있으면 카드 게이지바가 그 값 기준으로 채워짐, 없으면 평균값 기준 fallback
   - 마이그레이션은 운영 서버 안전 우선 — 컬럼 추가만, 인덱스/제약 없음

3. **배지 룰 엔진** (`BadgeRules.ts`)
   - 🔥 연속 1등: 최근 N주 동안 1등이면 표시
   - ⚠ 할인 과다: 할인율이 평균의 1.5배 이상
   - 💎 객단가 챔피언: 객단가가 평균보다 30% 이상 높음
   - 룰은 프론트에서 계산 (백엔드 데이터에서 파생)

4. **Pool 절약 — JOIN 통합**
   - `vendedor.service.getVendedorCockpit`에 `LEFT JOIN users u ON ... SELECT u.monthly_sales_target` 추가
   - **메타 조회를 위한 별도 쿼리/connection 금지**
   - 변경 전후 `pg_stat_activity`로 connection 수 동일 확인

**운영 안전 체크리스트:**
- 마이그레이션은 트랜잭션 안에서 실행
- 컬럼 NULL 허용 → 기존 행에 영향 없음
- 롤백 스크립트 동봉 (DROP COLUMN)
- Jenkins 빌드 후 마지막 로그 확인 → 회귀 없음 검증
