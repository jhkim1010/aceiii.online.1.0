DISCLAIMER_SINTETICO_ES : DISCLAIMER_REAL_ES); si viola uq_forecast_runs_running → { enCurso: true } (capturar UniqueConstraintError / código 23505, no relanzar).

Retención: DELETE FROM forecast_runs WHERE store_id = $1 AND kind = 'backtest' AND id NOT IN (las 10 más recientes) — CASCADE borra hijos.
