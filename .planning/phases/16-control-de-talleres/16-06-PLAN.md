### `createBulkForRecepcion(recepcion: Recepcion, items: QcItemInput[], parentEnvio: Envio, transaction: Transaction): Promise<QcItem[]>`

한국어 주석 필수. 처리 순서:

1) **서버 측 검증** (각 item 별로 루프):
   - `quantity > 0` 보장 (0 이하 → `BadRequestException('QC 수량은 0보다 커야 합니다')`)
   - `defectCodeId` 또는 `defectCustomText` 중 하나는 반드시 존재
   - `severity` ∈ {MINOR, MAJOR, CRITICAL}, `action` ∈ {ACCEPT, REWORK, SCRAP, CLAIM}
   - **(T-16-06-06)** `severity` ∈ {MAJOR, CRITICAL} 이면 `photoUrl` NOT NULL 필수. 누락 시 `BadRequestException('사진이 필요합니다 (MAJOR/CRITICAL)')`.
   - `photoUrl` 이 존재한다면 `^talleres/qc/${recepcion.storeId}/` 로 시작하는지 검증 → 아니면 `BadRequestException('사진 경로가 유효하지 않습니다')` (T-16-06-02)

2) **bulkCreate** — `qcItemModel.bulkCreate(items.map(i => ({ ...i, recepcionId: recepcion.id, storeId: recepcion.storeId })), { transaction })`.

3) **processSideEffects(insertedItems, parentEnvio, recepcion, transaction)** — `for ... of` 로 순차 처리 (Promise.all 금지, pool 낭비 방지 — CLAUDE.md):

   **ACCEPT**: 추가 작업 없음, continue.

   **REWORK**: `await this.envioService.createReworkChild(recepcion, item, transaction)` 호출 (Task 의 envio.service 섹션 참조). 반환된 child envío id 를 logger.info.

## 7) `recepcion.service.ts` 확장 — 기존 createRecepcion 수정

전체 로직을 **하나의 transaction 에서 처리**하도록 `qcItems` 처리를 주입:

```typescript
// 생성자에 QcItemService 추가 (forwardRef 불필요 — QcItemService 는 EnvioService 에 forwardRef)
constructor(
  @InjectModel(Recepcion) private readonly recepcionModel: typeof Recepcion,
  @InjectModel(Envio)     private readonly envioModel: typeof Envio,
  @InjectModel(Lote)      private readonly loteModel: typeof Lote,
  private readonly sequelize: Sequelize,
  private readonly qcItemService: QcItemService,
) { super(recepcionModel); }

async createRecepcion(data: any): Promise<Recepcion> {
  const qcItems: QcItemInput[] = Array.isArray(data.qcItems) ? data.qcItems : [];
  const { qcItems: _drop, ...recepcionData } = data;

  const transaction = await this.sequelize.transaction();
  try {
    const envio = await this.envioModel.findByPk(recepcionData.envioId, { transaction });
    if (!envio) throw new BadRequestException('Envío no encontrado');

    const totalReturn = (recepcionData.receivedQuantity || 0) + (recepcionData.rejectedQuantity || 0);
    if (totalReturn > envio.pendingQuantity) {
      throw new BadRequestException(/* 기존과 동일 메시지 */);
    }

    // 1) recepción 생성
    const recepcion = await this.recepcionModel.create(recepcionData, { transaction });

    // 2) envío pending/status 갱신 (기존 로직 유지)
    const newPending = envio.pendingQuantity - totalReturn;
    await envio.update({
      pendingQuantity: newPending,
      status: newPending === 0 ? EnvioStatus.COMPLETED : EnvioStatus.PARTIAL,
    }, { transaction });

    // 3) 수령분 lote 복귀 (기존 로직 유지)
    if (recepcionData.receivedQuantity > 0) {
      const lote = await this.loteModel.findByPk(envio.loteId, { transaction });
      if (lote) {
        await lote.update({
          availableQuantity: lote.availableQuantity + recepcionData.receivedQuantity,
        }, { transaction });
      }
    }

    // 4) *** NEW: QC items + side effects — 동일 트랜잭션 (T-16-06-04) ***
    if (qcItems.length > 0) {
      await this.qcItemService.createBulkForRecepcion(recepcion, qcItems, envio, transaction);
    }

    await transaction.commit();
    return recepcion;
  } catch (err) {
    await transaction.rollback();
    throw err;
  }
}
```

**CRITICAL (T-16-06-04):** `createBulkForRecepcion` 내부에서 SCRAP underflow 또는 REWORK 실패 또는 CLAIM 단가 미존재로 throw 되면 `await transaction.rollback()` 으로 **recepción 자체도 롤백**되어 부분 실패 상태가 남지 않음.

## 1) 백엔드 scorecard — `dashboard.service.ts` 확장

`TalleresDashboardService` 에 `getVendorScorecard(storeId, vendorId, days=90)` 추가. 기존 `getKanbanBoard` 아래에 배치.

```typescript
// scorecard 응답 타입
interface VendorScorecardResponse {
  vendorId: number;
  days: number;
  defectRate: number;
  onTimeRate: number;
  reworkRate: number;
  sparkline: Array<{ weekStart: string; defectRate: number }>;
  generatedAt: string;
}

async getVendorScorecard(storeId: number, vendorId: number, days = 90): Promise<VendorScorecardResponse> {
  const safeDays = Math.max(1, Math.min(365, Number(days) || 90));
  const cacheKey = `talleres:scorecard:${storeId}:${vendorId}:${safeDays}`;
  const cached = this.cacheService.get<VendorScorecardResponse>(cacheKey);
  if (cached) return cached;

  const windowStart = new Date();
  windowStart.setDate(windowStart.getDate() - safeDays);
  const startIso = windowStart.toISOString();

  // 1) 기간 내 해당 vendor 의 recepciones (envio → vendor 조인)
  //    raw SQL 1회로 집계 — Promise.all 로 3개 별도 쿼리보다 pool 절약
  const [rows]: any = await this.sequelize.query(`
    SELECT
      SUM(r.received_quantity + r.rejected_quantity) AS received_total,
      SUM(COALESCE(qc.total_qty, 0))                  AS defect_qty,
      COUNT(DISTINCT r.id)                            AS recepcion_count,
      SUM(CASE WHEN qc.has_rework THEN 1 ELSE 0 END)  AS rework_recepcion_count
    FROM talleres_recepciones r
    JOIN talleres_envios e ON e.id = r.envio_id
    LEFT JOIN (
      SELECT
        recepcion_id,
        SUM(quantity) AS total_qty,
        BOOL_OR(action = 'REWORK') AS has_rework
      FROM talleres_qc_items
      GROUP BY recepcion_id
    ) qc ON qc.recepcion_id = r.id
    WHERE e.vendor_id = :vendorId
      AND e.store_id  = :storeId
      AND r.created_at >= :startIso
  `, { replacements: { vendorId, storeId, startIso }, type: QueryTypes.SELECT });

  // 2) onTimeRate — 완료된 envío 중 dueDate 이내 완료 비율
  const [ontimeRows]: any = await this.sequelize.query(`
    SELECT
      COUNT(*) FILTER (WHERE e.status = 'COMPLETED') AS total_completed,
      COUNT(*) FILTER (
        WHERE e.status = 'COMPLETED'
          AND e.due_date IS NOT NULL
          AND (
            SELECT MAX(r2.recepcion_date) FROM talleres_recepciones r2 WHERE r2.envio_id = e.id
          ) <= e.due_date
      ) AS on_time_completed
    FROM talleres_envios e
    WHERE e.vendor_id = :vendorId
      AND e.store_id  = :storeId
      AND e.created_at >= :startIso
  `, { replacements: { vendorId, storeId, startIso }, type: QueryTypes.SELECT });

  const received = Number(rows?.received_total || 0);
  const defects  = Number(rows?.defect_qty || 0);
  const recepciones = Number(rows?.recepcion_count || 0);
  const reworks  = Number(rows?.rework_recepcion_count || 0);
  const completed = Number(ontimeRows?.total_completed || 0);
  const onTime    = Number(ontimeRows?.on_time_completed || 0);

  // 3) Sparkline — 12주 버킷 (주의: 운영 PG10 에 date_trunc 존재)
  const [sparkRows]: any = await this.sequelize.query(`
    SELECT
      date_trunc('week', r.created_at)::date AS week_start,
      SUM(r.received_quantity + r.rejected_quantity) AS received_total,
      SUM(COALESCE(qc.total_qty, 0))                  AS defect_qty
    FROM talleres_recepciones r
    JOIN talleres_envios e ON e.id = r.envio_id
    LEFT JOIN (
      SELECT recepcion_id, SUM(quantity) AS total_qty
      FROM talleres_qc_items GROUP BY recepcion_id
    ) qc ON qc.recepcion_id = r.id
    WHERE e.vendor_id = :vendorId
      AND e.store_id  = :storeId
      AND r.created_at >= NOW() - INTERVAL '12 weeks'
    GROUP BY 1
    ORDER BY 1 ASC
  `, { replacements: { vendorId, storeId }, type: QueryTypes.SELECT });

  const sparkline = (sparkRows as any[]).map(r => ({
    weekStart: String(r.week_start).slice(0, 10),
    defectRate: Number(r.received_total) > 0 ? Number(r.defect_qty) / Number(r.received_total) : 0,
  }));

  const result: VendorScorecardResponse = {
    vendorId,
    days: safeDays,
    defectRate: received > 0 ? defects / received : 0,
    onTimeRate: completed > 0 ? onTime / completed : 0,
    reworkRate: recepciones > 0 ? reworks / recepciones : 0,
    sparkline,
    generatedAt: new Date().toISOString(),
  };

  this.cacheService.set(cacheKey, result, 5 * 60 * 1000);
  return result;
}
```

// HTML Canvas 기반 이미지 다운스케일 — max edge, JPEG quality 옵션
// 실패 시 원본 File 반환하도록 fallback
export async function resizeImageToBlob(
  file: File,
  maxEdge = 1280,
  quality = 0.82,
): Promise<Blob> {
  try {
    const bitmap = await createImageBitmap(file);
    const scale = Math.min(1, maxEdge / Math.max(bitmap.width, bitmap.height));
    const w = Math.round(bitmap.width * scale);
    const h = Math.round(bitmap.height * scale);

    const canvas = document.createElement('canvas');
    canvas.width = w;
    canvas.height = h;
    const ctx = canvas.getContext('2d');
    if (!ctx) return file;

    ctx.drawImage(bitmap, 0, 0, w, h);

    return await new Promise<Blob>((resolve) => {
      canvas.toBlob(blob => resolve(blob || file), 'image/jpeg', quality);
    });
  } catch {
    return file;
  }
}
