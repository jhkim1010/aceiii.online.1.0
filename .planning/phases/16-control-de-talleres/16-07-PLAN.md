<objective>
Wave 7 — Tarifa Historización + Auto-liquidación 구현. EXTENSION.md § 3 Wave 7 전체 스펙을 단일 플랜으로 다룬다.

1. **(TALLERES-14) VendorEtapa 단가 이력화** — 기존의 단일 `unitPrice` 덮어쓰기 모델을 `(effective_from, effective_to)` 구간 기반 이력으로 전환. `(vendor_id, etapa_id)` 당 동시 active 행 1개를 partial unique index 로 강제하고, 과거 단가를 시점으로 조회할 수 있게 한다.
2. **(TALLERES-15) 자동 liquidación + DRAFT→CONFIRMED 상태머신 + PDF** — 벤더+기간 입력으로 `generateForPeriod` 가 단일 트랜잭션 내에서 recepciones 를 집계 → settlement + lines 를 idempotent 하게 생성. 상태머신 DRAFT → CONFIRMED → PAID / DRAFT → CANCELLED 전이 외에는 401/400 으로 거부. CONFIRMED 이후 모든 변경은 `SettlementImmutableException` 으로 차단(INV-1). PDF 출력은 pdfkit 기반.

Purpose: Wave 4 이후 사용자가 직접 테이블에 행을 넣던 수동 정산을 제거하고, 법적으로 불변인 확정 liquidación + PDF 문서를 제공한다. 단가가 변한 이후 기간의 재계산 요청도 recepción 당시 시점 단가로 정확히 복원되어야 한다.

## 0) 운영 스키마 현실 — Option A 채택 이유 (주석용)

- 운영 + 로컬 모두 `talleres_settlements.status` 는 Postgres ENUM 타입 `enum_talleres_settlements_status` 로 정의됨, 값 `{OPEN, CLOSED}`. 값 수 0 rows 이므로 데이터 파괴 없음.
- **Option A**: `ALTER TYPE ... ADD VALUE IF NOT EXISTS` 로 DRAFT/CONFIRMED/PAID/CANCELLED 4개 값 추가 후, 서비스 레이어에서 신규 경로는 DRAFT→... 만 사용. 기존 OPEN/CLOSED 는 legacy 용으로 유지(읽기 호환). 가장 덜 파괴적이며 data-loss 위험 0.
- **PG10 제약**: `ALTER TYPE ADD VALUE` 는 트랜잭션 블록 내부 실행 불가 → 마이그레이션을 **3단계 파일로 분리** (Step1 트랜잭션, Step2 오토커밋, Step3 검증).

// 생성자
constructor(
  @InjectModel(VendorEtapa) private readonly vendorEtapaModel: typeof VendorEtapa,
  private readonly sequelize: Sequelize,

// Wave 7: 현재 또는 미래 시점의 단가 신규 등록 (이력 관리)
// - 같은 날짜로 재호출 + 동일 unitPrice → 기존 row 그대로 반환 (idempotent)
// - 기존 active 행이 있으면 effective_to = effectiveFrom - 1일 로 마감
// - 신규 row INSERT
async setRate(
  vendorId: number,
  etapaId: number,
  unitPrice: number,
  effectiveFrom: string,  // 'YYYY-MM-DD'
  externalTx?: Transaction,
): Promise<VendorEtapa> {
  this.logger.log(`setRate vendor=${vendorId} etapa=${etapaId} price=${unitPrice} from=${effectiveFrom}`);

  const run = async (tx: Transaction): Promise<VendorEtapa> => {
    // 활성 row FOR UPDATE 잠금 — 동시성 방지
    const active = await this.vendorEtapaModel.findOne({
      where: { vendorId, etapaId, effectiveTo: null },
      transaction: tx,
      lock: tx.LOCK.UPDATE,
    });

    // 멱등: 같은 날짜 + 같은 unitPrice 면 기존 active 그대로
    if (active && Number(active.unitPrice) === Number(unitPrice) && active.effectiveFrom === effectiveFrom) {
      return active;
    }

    // CHECK 방어: effectiveFrom 이 active.effectiveFrom 이하인 경우 금지
    if (active && effectiveFrom <= active.effectiveFrom) {
      throw new BadRequestException('effectiveFrom 은 현재 활성 단가의 시작일보다 커야 합니다');
    }

    if (active) {
      // YYYY-MM-DD 에서 하루 빼기
      const prevEnd = new Date(effectiveFrom);
      prevEnd.setUTCDate(prevEnd.getUTCDate() - 1);
      const prevEndIso = prevEnd.toISOString().slice(0, 10);
      await active.update({ effectiveTo: prevEndIso }, { transaction: tx });
    }

    const created = await this.vendorEtapaModel.create(
      { vendorId, etapaId, unitPrice, effectiveFrom, effectiveTo: null },
      { transaction: tx },
    );

    return created;
  };

  if (externalTx) {
    return run(externalTx);
  }

  return this.sequelize.transaction(run);
}

import PDFDocument from 'pdfkit';
import { SettlementDetailResponse } from './types';

@Injectable()
export class SettlementPdfService {
  // Wave 7: pdfkit 으로 A4 세로 PDF 생성 — 헤더 + 라인 테이블 + 합계
  async generate(
    detail: SettlementDetailResponse,
    vendor: { name?: string; cuit?: string } | null,
    store: { name?: string; aliasName?: string; cuit?: string } | null,
  ): Promise<Buffer> {
    return new Promise<Buffer>((resolve, reject) => {
      const doc = new PDFDocument({ size: 'A4', margin: 40 });
      const chunks: Buffer[] = [];
      doc.on('data', (c: Buffer) => chunks.push(c));
      doc.on('end', () => resolve(Buffer.concat(chunks)));
      doc.on('error', reject);

      // 헤더 — store
      const storeName = this.sanitize(store?.aliasName || store?.name || 'Tienda');
      doc.fontSize(18).fillColor('#1a1a2e').text(storeName, { align: 'left' });
      if (store?.cuit) doc.fontSize(10).fillColor('#6b6b8c').text(`CUIT: ${store.cuit}`);
      doc.moveDown(0.5);

      // Title
      doc.fontSize(14).fillColor('#1a1a2e').text(`Liquidación #${detail.id}`, { align: 'center' });
      doc.moveDown(0.3);

      // Meta
      const vendorName = this.sanitize(vendor?.name || detail.vendorName || '(sin vendor)');
      doc.fontSize(10).fillColor('#333')
        .text(`Vendor: ${vendorName}`)
        .text(`Período: ${detail.periodFrom} — ${detail.periodTo}`)

## 1) `api.service.ts` — AxiosRequestConfig 옵션 지원

기존 `get(path)` 시그니처에 두 번째 인자 추가. 이미 axios instance 가 존재하면 그대로 전달, 없으면 overload 로 확장. 기존 호출사이트는 하위 호환 유지.

```typescript
import type { AxiosRequestConfig, AxiosResponse } from 'axios'

// Wave 7: responseType 'blob' 등 전달 가능
async get<T = any>(path: string, config?: AxiosRequestConfig): Promise<T> {
  const resp: AxiosResponse<T> = await this.instance.get<T>(path, config)
  return resp.data
}
```

기존 `get` 구현이 `resp.data` 가 아닌 `resp` 전체를 반환하는 경우가 있다면 (`res?.data?.data || res?.data` 패턴) 행동을 유지하기 위해 별도의 `getRaw` 를 추가하거나, 현재 구현 style 을 그대로 따른다. executor 는 기존 LiquidacionesTab 에서 `res?.data?.data || res?.data` 패턴을 사용하는 것으로 보아 `get` 이 axios response 원본을 반환할 가능성 있음 → **현재 구현 그대로 유지 + config 만 추가**:

```typescript
get<T = any>(path: string, config?: AxiosRequestConfig) {
  return this.instance.get<T>(path, config)
}
```

## 2) `useSettlements.ts` — SWR 훅

```typescript
import useSWR from 'swr'
import apiConnector from 'src/services/api.service'

export type SettlementStatus = 'DRAFT' | 'CONFIRMED' | 'PAID' | 'CANCELLED' | 'OPEN' | 'CLOSED'

export interface SettlementRow {
  id: number
  vendorId: number | null
  status: SettlementStatus
  periodFrom: string
  periodTo: string
  totalGrossAmount: number
  deductionAmount: number
  netAmount: number
  settlementDate: string
  confirmedAt: string | null
  subconOrder?: { vendor?: { id: number; name: string } } | null
  notes?: string | null
}

interface Params {
  vendorId?: number
  from?: string
  to?: string
}

// 현재 백엔드 /talleres/settlements/all 이 페이지네이션 포함 { count, data, page, pageSize } 반환
const fetcher = async (url: string) => {
  const res = await apiConnector.get(url)
  const payload = res?.data ?? res
  return payload?.data || payload?.rows || payload || []
}

export function useSettlements(params: Params = {}) {
  const query = new URLSearchParams()
  query.set('page', '0')
  query.set('pageSize', '100')
  if (params.vendorId) query.set('vendorId', String(params.vendorId))
  if (params.from) query.set('from', params.from)
  if (params.to) query.set('to', params.to)

  const key = `/talleres/settlements/all?${query.toString()}`

  const { data, error, isLoading, mutate } = useSWR<SettlementRow[]>(
    key,
    fetcher,
    { dedupingInterval: 2 * 60 * 1000, revalidateOnFocus: false },
  )

  return { settlements: data || [], isLoading, error, mutate }
}
```
