**2. `dashboard.service.ts` 생성:**
- `@Injectable()` 클래스 `TalleresDashboardService`
- 생성자에서 `@InjectModel(Envio)`, `@InjectModel(Vendor)`, `@InjectModel(Lote)`, `@InjectModel(SubconSettlement)`, `@InjectModel(SubconPayment)`, `@InjectModel(Recepcion)` 주입
- `getDashboardStats(storeId: number)` 메서드: `Promise.all()`로 4개 쿼리 병렬 실행
  - `getKpiStats(storeId)`: 
    - `totalUnitsInTalleres`: Envio.sum('pendingQuantity', { where: { storeId, status: { [Op.in]: ['PENDING', 'PARTIAL'] } } })` → null이면 0
    - `activeTalleres`: `Vendor.count({ where: { storeId, isActive: true } })`
    - `openLotes`: `Lote.count({ where: { storeId, status: { [Op.in]: ['OPEN', 'IN_PROGRESS'] } } })`
    - `overdueEnvios`: `Envio.count({ where: { storeId, status: { [Op.in]: ['PENDING', 'PARTIAL'] }, dueDate: { [Op.lt]: new Date() } } })`
  - `getVendorDistribution(storeId)`:
    - `Envio.findAll({ attributes: ['vendorId', [fn('SUM', col('pending_quantity')), 'pendingQuantity']], where: { storeId, status: { [Op.in]: ['PENDING', 'PARTIAL'] } }, group: ['vendorId'], include: [{ model: Vendor, attributes: ['name'] }], raw: true, nest: true })`
    - 결과를 `{ vendorId, vendorName, pendingQuantity, percentage }` 배열로 변환 (percentage = 각 업체 / 총합 * 100)
  - `getDebtSummary(storeId)`:
    - `SubconSettlement.findAll({ attributes: ['vendorId', [fn('SUM', col('net_amount')), 'totalDebt']], where: { storeId, status: 'OPEN' }, group: ['vendorId'], include: [{ model: Vendor, attributes: ['name'] }], raw: true, nest: true })`
    - 지불된 금액 차감 필요 시 SubconPayment 합계를 별도 쿼리 후 빼기
    - 결과를 `{ vendorId, vendorName, totalDebt }` 배열로 변환
  - `getRecentMovements(storeId)`:
    - Envio 최근 10건 (createdAt DESC) + Recepcion 최근 10건 합쳐서 날짜순 정렬, 최대 10건 반환
    - 각 항목을 `{ date, type: 'ENVIO' | 'RECEPCION', loteNumber, vendorName, etapaName, quantity }` 형식으로 변환
    - Envio include: `[Lote(attributes: ['loteNumber']), Vendor(attributes: ['name']), Etapa(attributes: ['name'])]`
    - Recepcion include: 동일 관계 (Recepcion 모델의 association 확인 필요)

**주의 사항:**
- 모든 raw SQL에서 snake_case 사용 (`pending_quantity`, `net_amount`, `store_id`)
- Sequelize `col()` 함수에서도 snake_case: `col('pending_quantity')`
- `Op` import: `import { Op, fn, col } from 'sequelize'`
