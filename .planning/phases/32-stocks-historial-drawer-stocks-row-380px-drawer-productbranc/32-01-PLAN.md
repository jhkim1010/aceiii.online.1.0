<objective>
Backend: extend `reportsStocksCockpit.service.ts` with a `getHistorial` method and expose it via `GET /reports/stocks-cockpit/historial`. Returns the full stocks ledger for a single productBranch (or productId+branchId pair), enriched with counterparty sucursal name (note pattern parsing), user_name from audit_logs JOIN, and a header summary (current stock + 30-day net + variant identifier).

Purpose: the frontend drawer needs a single endpoint that returns timeline-ready rows already classified by movement type. Doing the classification in SQL keeps the frontend simple (no note parsing on client) and the backend uses 1 connection per drawer open.

Output:
- Service method `getHistorial({ productBranchId?, productId?, branchId?, storeId?, days?, offset? })` returning `{ header, rows }`
- Controller endpoint `GET /reports/stocks-cockpit/historial` consuming `?productBranchId=N` OR `?productId=N&branchId=M`, plus `?days=30&offset=0`
- Existing `@FunctionGuard('reporte-stocks', 'read')` reused

1. Resolve productBranchId:
   - If `filters.productBranchId` provided → use directly.
   - Else if `productId` + `branchId` provided → SELECT id FROM "ProductBranch" WHERE product_id = :productId AND branch_id = :branchId LIMIT 1. If not found, return `{ header: null, rows: [], hasMore: false }`.
   - Else throw new BadRequestException('productBranchId or productId+branchId required'). Import `BadRequestException` from `@nestjs/common` (add to existing import list).

2. Compute window:
   - `days = Math.max(1, Math.min(365, filters.days ?? 30))` — clamp 1..365 (D-03 protection)
   - `offset = Math.max(0, filters.offset ?? 0)`
   - SQL window: `created_at >= NOW() - INTERVAL ':offsetPlusDays days' AND created_at < NOW() - INTERVAL ':offset days'`. Use Sequelize replacements: `:offset::int` and `:offsetPlusDays::int` and embed via `(NOW() - (:offsetPlusDays || ' days')::interval)` to keep type-safe parameterization.

3. SINGLE raw SQL query using CTE:
```sql
WITH params AS (
  SELECT :pbId::int AS pb_id,
         :offset::int AS p_offset,
         :days::int AS p_days
),
header AS (
  SELECT pb.id AS product_branch_id,
         pb.product_id,
         pb.branch_id,
         b.name AS branch_name,
         p.name AS product_name,
         p.sku AS product_sku,
         col.name AS variant_color_name,
         tal.name AS variant_talle_name,
         COALESCE((SELECT SUM(stock) FROM stocks WHERE product_branch_id = pb.id), 0)::int AS current_stock,
         COALESCE((
           SELECT SUM(stock) FROM stocks
           WHERE product_branch_id = pb.id
             AND created_at >= NOW() - INTERVAL '30 days'
         ), 0)::int AS net_delta_30d
  FROM "ProductBranch" pb
  JOIN products p ON p.id = pb.product_id
  LEFT JOIN branches b ON b.id = pb.branch_id
  LEFT JOIN colors col ON col.id = p.color_id
  LEFT JOIN talles tal ON tal.id = p.talle_id
  WHERE pb.id = (SELECT pb_id FROM params)
),
parsed AS (
  SELECT s.id,
         s.created_at,
         s.operation_date,
         s.stock AS signed_quantity,
         s.type AS raw_type,
         s.note,
         CASE
           WHEN s.note ~ '^movido\(out→[0-9]+\)' THEN 'movido_out'
           WHEN s.note ~ '^movido\(in←[0-9]+\)'  THEN 'movido_in'
           WHEN s.note ~ '^fallado'              THEN 'fallado'
           WHEN s.note ~ '^corregido'            THEN 'corregido'
           WHEN s.type = 'sale'                  THEN 'sale'
           WHEN s.type = 'suspend'               THEN 'suspend'
           WHEN s.stock > 0                      THEN 'ingreso'
           ELSE 'other'
         END AS classification,
         (regexp_match(s.note, '^movido\((?:out→|in←)([0-9]+)\)'))[1]::int AS counterparty_branch_id,
         CASE
           WHEN s.note ~ '^movido\((?:out→|in←)[0-9]+\):\s*' THEN regexp_replace(s.note, '^movido\((?:out→|in←)[0-9]+\):\s*', '')
           WHEN s.note ~ '^fallado:\s*'    THEN regexp_replace(s.note, '^fallado:\s*', '')
           WHEN s.note ~ '^corregido:\s*'  THEN regexp_replace(s.note, '^corregido:\s*', '')
           ELSE COALESCE(s.note, '')
         END AS note_clean
  FROM stocks s, params
  WHERE s.product_branch_id = params.pb_id
    AND s.created_at <  NOW() - (params.p_offset || ' days')::interval
    AND s.created_at >= NOW() - ((params.p_offset + params.p_days) || ' days')::interval
)
SELECT
  pr.id,
  pr.created_at,
  pr.operation_date,
  pr.signed_quantity,
  pr.raw_type,
  pr.classification,
  pr.note,
  pr.note_clean,
  pr.counterparty_branch_id,
  cb.name AS counterparty_branch_name,
  al.user_id,
  COALESCE(u.name, 'Sistema') AS user_name
FROM parsed pr
LEFT JOIN branches cb ON cb.id = pr.counterparty_branch_id
LEFT JOIN audit_logs al ON al.entity_type = 'stock' AND al.entity_id = pr.id
LEFT JOIN users u ON u.id = al.user_id
ORDER BY pr.created_at DESC, pr.id DESC
LIMIT 200;
```
