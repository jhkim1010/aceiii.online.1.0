# Plan 10-01: DB 스키마 + Store Fiscal Config

**Phase:** 10-facturacion-electronica
**Status:** Not started
**Depends on:** Nothing
**Estimate:** 0.5일

## Goal

전자세금계산서 발행에 필요한 테이블을 생성하고, 매장별 fiscal 설정을 관리할 수 있는 기반을 마련한다.

## Scope (In)

- 마이그레이션: `store_fiscal_configs`, `invoices`, `invoice_items` 테이블 생성
- `sales` 테이블에 `invoice_id` nullable 컬럼 추가
- `sales.status` 에 `FACTURADO`, `PENDIENTE_AFIP`, `ERROR_AFIP` enum 값 추가
- 인덱스 (`idx_invoices_status partial`, `idx_invoices_store_fecha`, unique constraint)
- Sequelize 모델 3개 (snake_case 자동 매핑)
- Store 모델에 `@HasOne(() => StoreFiscalConfig)` 관계 추가

## Scope (Out)

- Fiscal config 관리 UI (Plan 10-04)
- 발행 로직 (Plan 10-02)
- PDF 생성 (Plan 10-03)

## Success Criteria

1. 3개 테이블 생성 + 인덱스 정상 동작
2. Store.fiscalConfig 관계로 eager loading 가능
3. invoice의 unique constraint `(store_id, punto_venta, invoice_type, numero)` 동작
4. 운영 배포 시 락 시간 1초 미만
5. 롤백 스크립트 제공

## Steps

1. 마이그레이션 SQL 작성 (`20260410-facturacion-electronica.sql`)
2. `StoreFiscalConfig` 모델 생성
3. `Invoice`, `InvoiceItem` 모델 생성
4. `Store` 모델에 `@HasOne` 추가
5. `Sale` 모델에 `@BelongsTo(() => Invoice)` 추가
6. dev DB 검증
