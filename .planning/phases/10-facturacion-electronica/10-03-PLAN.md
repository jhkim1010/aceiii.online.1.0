## AFIP PDF/QR 규격 요약

### QR v1 스펙 (RG 4291/2023)
QR 코드는 다음 JSON을 base64url로 인코딩한 후 `https://www.afip.gob.ar/fe/qr/?p=` 뒤에 붙인다.

```json
{
  "ver": 1,
  "fecha": "2025-01-15",
  "cuit": 20312929695,
  "ptoVta": 2,
  "tipoCmp": 1,
  "nroCmp": 100,
  "importe": 1210.00,
  "moneda": "PES",
  "ctz": 1,
  "tipoDocRec": 80,
  "nroDocRec": 20111111112,
  "tipoCodAut": "E",
  "codAut": 12345678901234
}
```

- `tipoCodAut`: 항상 `"E"` (CAE)
- `moneda`: ARS → `"PES"`, USD → `"DOL"`
- `tipoDocRec`: CUIT=80, CUIL=86, DNI=96, SIN_IDENTIFICAR=99
- base64url: `+`→`-`, `/`→`_`, 패딩(`=`) 제거

### PDF 필수 항목 (AFIP 규정)
1. 발행자 정보: Razón Social, CUIT, domicilio, iibb
2. 수신자 정보: Razón Social, CUIT/DNI, domicilio
3. 문서 번호: `{tipo} {ptoVta:0000}-{nroCmp:00000000}`
4. 날짜, CAE, CAE Vencimiento (+10일)
5. Condición frente al IVA (발행자/수신자)
6. 상품 명세 테이블 (descripcion, cantidad, precio unitario, subtotal)
7. IVA 소계 (21%, 10.5%, 0%, exento)
8. 합계 (NETO, IVA, TOTAL)
9. QR 코드 (좌하단 2.5cm × 2.5cm)
10. 레터헤드 문구: `"Comprobante Autorizado por la A.F.I.P."`

> **Pool 주의**: Puppeteer 브라우저 인스턴스는 요청마다 launch/close 하지 않고,

> 메모리 누수 방지를 위해 Page는 매 렌더링 후 즉시 close.

#### `api-ventago/src/app/facturacion/pdf/pdf.service.ts`
```typescript
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import puppeteer, { Browser } from 'puppeteer';

@Injectable()
export class PdfService implements OnModuleInit, OnModuleDestroy {
  private browser: Browser;

  // 앱 시작 시 브라우저 1개만 생성 (재사용)
  async onModuleInit() {
    this.browser = await puppeteer.launch({
      headless: true,
      args: ['--no-sandbox', '--disable-setuid-sandbox'],
    });
  }

  async onModuleDestroy() {
    if (this.browser) {
      await this.browser.close();
    }
  }

  // HTML → PDF Buffer 반환
  async renderHtmlToPdf(html: string): Promise<Buffer> {
    const page = await this.browser.newPage();

    try {
      await page.setContent(html, { waitUntil: 'networkidle0' });

      const pdfBuffer = await page.pdf({
        format: 'A4',
        printBackground: true,
        margin: { top: '10mm', right: '10mm', bottom: '10mm', left: '10mm' },
      });

      return Buffer.from(pdfBuffer);
    } finally {
      // 메모리 누수 방지 — 반드시 close
      await page.close();
    }
  }
}
```

### Step 2: QR 생성 유틸 (0.25일)

#### `api-ventago/src/app/facturacion/pdf/afip-qr.util.ts`
```typescript
import * as QRCode from 'qrcode';

// AFIP QR v1 데이터 구조 (RG 4291/2023)
export interface AfipQrData {
  ver: 1;
  fecha: string;          // YYYY-MM-DD
  cuit: number;
  ptoVta: number;
  tipoCmp: number;        // InvoiceType 코드
  nroCmp: number;
  importe: number;
  moneda: 'PES' | 'DOL';
  ctz: number;            // 환율 (ARS=1)
  tipoDocRec: 80 | 86 | 96 | 99;
  nroDocRec: number;
  tipoCodAut: 'E';        // CAE는 항상 'E'
  codAut: number;
}

// AFIP InvoiceType 숫자 코드 매핑
export const INVOICE_TYPE_CODES: Record<string, number> = {
  A: 1,
  B: 6,
  C: 11,
  E: 19,
  M: 51,
  NC_A: 3,  // Nota de Crédito A
  NC_B: 8,
  NC_C: 13,
};

/**
 * QR URL 생성
 * base64url = base64 with '+'->'','/'->'_', 패딩 제거
 */
export function buildAfipQrUrl(data: AfipQrData): string {
  const json = JSON.stringify(data);
  const base64url = Buffer.from(json)
    .toString('base64')
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=+$/, '');

  return `https://www.afip.gob.ar/fe/qr/?p=${base64url}`;
}

/**
 * QR URL → Data URL (PNG base64) 반환
 * HTML 템플릿에 <img src="..."> 로 삽입
 */
export async function generateQrDataUrl(qrUrl: string): Promise<string> {
  return QRCode.toDataURL(qrUrl, {
    width: 200,
    margin: 1,
    errorCorrectionLevel: 'M',
  });
}
```

### Step 4: FacturacionService에 PDF 생성 메서드 추가 (0.25일)

`10-02-PLAN.md`의 `FacturacionService`에 다음 메서드 추가:

```typescript
// facturacion.service.ts 에 추가
import { PdfService } from './pdf/pdf.service';
import { buildAfipQrUrl, generateQrDataUrl, INVOICE_TYPE_CODES } from './pdf/afip-qr.util';
import { renderFacturaHtml, FacturaPdfData } from './pdf/templates/factura.template';

// constructor에 PdfService 주입
constructor(
  // ... 기존 주입 ...
  private readonly pdfService: PdfService,
) {}

/**
 * Invoice 레코드로부터 PDF Buffer 생성
 * - MinIO 저장 또는 print-agent 전달에 사용
 */
async generateInvoicePdf(invoiceId: number): Promise<Buffer> {
  // invoice + items + storeFiscalConfig 단건 조회
  // pool 절약: 단일 JOIN 쿼리로 처리
  const invoice = await this.invoiceModel.findOne({
    where: { id: invoiceId },
    include: [
      { model: InvoiceItem },
      { model: StoreFiscalConfig },
    ],
  });

  if (!invoice) {
    throw new NotFoundException(`Invoice ${invoiceId} not found`);
  }

  // AFIP QR 생성
  const qrData = {
    ver: 1 as const,
    fecha: invoice.issueDate.toISOString().split('T')[0],
    cuit: Number(invoice.storeFiscalConfig.cuit.replace(/-/g, '')),
    ptoVta: invoice.storeFiscalConfig.puntoVenta,
    tipoCmp: INVOICE_TYPE_CODES[invoice.invoiceType] ?? 1,
    nroCmp: invoice.invoiceNumber,
    importe: Number(invoice.totalAmount),
    moneda: 'PES' as const,
    ctz: 1,
    tipoDocRec: invoice.customerDocType === 'CUIT' ? 80 : 96,
    nroDocRec: Number(invoice.customerDocNumber.replace(/-/g, '')),
    tipoCodAut: 'E' as const,
    codAut: Number(invoice.cae),
  };

  const qrUrl = buildAfipQrUrl(qrData);
  const qrDataUrl = await generateQrDataUrl(qrUrl);

  // PDF 데이터 조립
  const pdfData: FacturaPdfData = {
    emisorRazonSocial: invoice.storeFiscalConfig.razonSocial,
    emisorCuit: invoice.storeFiscalConfig.cuit,
    emisorDomicilio: invoice.storeFiscalConfig.domicilio,
    emisorIibb: invoice.storeFiscalConfig.iibb,
    emisorCondicionIva: invoice.storeFiscalConfig.condicionIva,
    emisorInicioActividades: invoice.storeFiscalConfig.inicioActividades,
    tipoNombre: `FACTURA ${invoice.invoiceType}`,
    tipoLetra: invoice.invoiceType,
    puntoVenta: String(invoice.storeFiscalConfig.puntoVenta).padStart(4, '0'),
    numero: String(invoice.invoiceNumber).padStart(8, '0'),
    fecha: invoice.issueDate.toLocaleDateString('es-AR'),
    cae: invoice.cae,
    caeVencimiento: invoice.caeExpiry.toLocaleDateString('es-AR'),
    receptorRazonSocial: invoice.customerName,
    receptorDocTipo: invoice.customerDocType,
    receptorDocNumero: invoice.customerDocNumber,
    receptorDomicilio: invoice.customerAddress ?? '',
    receptorCondicionIva: invoice.customerCondicionIva ?? 'Consumidor Final',
    items: invoice.items.map((item) => ({
      descripcion: item.description,
      cantidad: Number(item.quantity),
      precioUnitario: Number(item.unitPrice).toFixed(2),
      subtotal: Number(item.subtotal).toFixed(2),
    })),
    ivaItems: invoice.ivaBreakdown as any,
    subtotalNeto: Number(invoice.netAmount).toFixed(2),
    totalIva: Number(invoice.ivaAmount).toFixed(2),
    total: Number(invoice.totalAmount).toFixed(2),
    qrDataUrl,
  };

  const html = renderFacturaHtml(pdfData);

  return this.pdfService.renderHtmlToPdf(html);
}
```

### Step 5: GET /facturacion/invoices/:id/pdf 엔드포인트

`facturacion.controller.ts`에 추가:

```typescript
@Get('invoices/:id/pdf')
@UseGuards(JwtAuthGuard, SessionGuard)
async downloadInvoicePdf(
  @Param('id', ParseIntPipe) id: number,
  @Res() res: Response,
): Promise<void> {
  const buffer = await this.facturacionService.generateInvoicePdf(id);

  res.set({
    'Content-Type': 'application/pdf',
    'Content-Disposition': `inline; filename="factura-${id}.pdf"`,
    'Content-Length': buffer.length,
  });

  res.end(buffer);
}
```
