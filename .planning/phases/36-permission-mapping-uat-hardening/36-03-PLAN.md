### Task 1: U14 movBalance 알람 재검증

**Pre-condition:** dev 환경 `./dev.sh` 실행 중 + sales 테이블에 movido 데이터 존재 (현재 dev DB: movido id=99, 100, 102).

**Procedure:**

1. **터미널 A — 인터랙티브 psql 세션 시작 + DELETE 트랜잭션 열기:**
   ```bash
   psql -h localhost -p 5432 -U $USER -d ventago
   ```
   psql 프롬프트에서:
   ```sql
   ventago=# BEGIN;
   ventago=# DELETE FROM sale_items WHERE sale_id=100;
   -- 삭제 row 수 확인 (예: DELETE 2)
   -- ⚠ 절대 COMMIT 하지 말 것. ROLLBACK 으로만 종료.
   ```

2. **브라우저 — `/ventas` 새로고침 + Σ TOTAL 행 ⚠ 캡처:**
   - 새 탭 또는 새로고침 → Σ TOTAL 행의 MOV+ / MOV− 셀에 ⚠ 아이콘 노출 확인
   - tooltip 확인 (마우스 호버): "동일 store 내 이동인데 IN/OUT 합이 다릅니다 — 데이터 점검 필요" (또는 동등 텍스트)
   - 스크린샷 (Cmd+Shift+4) → `.planning/phases/36-permission-mapping-uat-hardening/u14-evidence.png` 저장

3. **터미널 A — ROLLBACK:**
   ```sql
   ventago=# ROLLBACK;
   ventago=# \q
   ```

4. **데이터 복원 확인:**
   ```bash
   psql -h localhost -p 5432 -U $USER -d ventago -c "SELECT COUNT(*) FROM sale_items WHERE sale_id=100;"
   ```
   예상: 원래 row 수 (movido 100 의 sale_items, 일반적으로 2 행).

**Acceptance:**
