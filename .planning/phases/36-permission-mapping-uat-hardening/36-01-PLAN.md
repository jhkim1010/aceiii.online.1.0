### Task 1: 마이그레이션 SQL 작성

**File:** `api-ventago/migrations/phase36-stock-movement-actions-backfill.sql`

**Content template:**

```sql
-- Phase 36 — stock.movement role_function_actions 보강
-- =============================================================================
-- 목적: Phase 35 Plan 02 마이그레이션이 role_functions 만 INSERT 하고
--       role_function_actions 매핑이 누락되어 admin UI 권한 매트릭스가
--       모든 role 에 "권한 없음" 표시. PermissionGuard 도 403 반환.
--
-- 본 마이그레이션: 기존 role_functions(function_id=149, slug='stock.movement')
--                 행에 대해 4개 action (create/read/update/delete) 매핑 INSERT.
--
-- Idempotent: ON CONFLICT (role_function_id, action) DO NOTHING 사용.
--             role_function_actions_rf_action_unique UNIQUE 제약 활용.
--
-- 호환성: PG10 (운영) + PG15 (docker dev) + PG18 (호스트 dev) 모두 동작.
-- =============================================================================

BEGIN;

-- 사전 검증: function_id=149 (stock.movement) 가 존재해야 함
DO $$
DECLARE
  fn_count INT;
BEGIN
  SELECT COUNT(*) INTO fn_count FROM functions WHERE id = 149 AND permission_slug = 'stock.movement';
  IF fn_count = 0 THEN
    RAISE EXCEPTION 'stock.movement function (id=149) not found. Phase 35 Plan 02 마이그레이션 선행 필요.';
  END IF;
END $$;

-- 보강: 모든 role_functions(function_id=149) × 4 actions CROSS JOIN INSERT
INSERT INTO role_function_actions (role_function_id, action, created_at, updated_at)
SELECT rf.id, act.action, NOW(), NOW()
FROM role_functions rf
CROSS JOIN (VALUES ('create'), ('read'), ('update'), ('delete')) AS act(action)
WHERE rf.function_id = 149
ON CONFLICT (role_function_id, action) DO NOTHING;

-- 검증: 최종 행 수 보고
DO $$
DECLARE
  total INT;
  expected INT;
BEGIN
  SELECT COUNT(*) INTO total
  FROM role_function_actions rfa
  JOIN role_functions rf ON rf.id = rfa.role_function_id
  WHERE rf.function_id = 149;

  SELECT COUNT(*) * 4 INTO expected FROM role_functions WHERE function_id = 149;

  RAISE NOTICE 'role_function_actions for stock.movement: total=% expected=%', total, expected;

  IF total != expected THEN
    RAISE WARNING 'Expected % rows but got %. UNIQUE 제약 충돌 가능 (이미 존재하는 행 무시).', expected, total;
  END IF;
END $$;

COMMIT;
```

**Acceptance:**
- 파일이 ESLint/SQL lint 통과 (Ventago 프로젝트는 SQL lint 없음 — psql 파싱 만 확인)
- PG10 syntax 호환 (`ON CONFLICT`, `CROSS JOIN`, `VALUES` row constructor 모두 PG10+)

### Task 2: dev DB 검증

**Commands:**

```bash
# Pre-state 확인
psql -h localhost -p 5432 -U $USER -d ventago -c "
  SELECT COUNT(*) AS pre_count
  FROM role_function_actions rfa
  JOIN role_functions rf ON rf.id = rfa.role_function_id
  WHERE rf.function_id = 149;"

# 실행
psql -h localhost -p 5432 -U $USER -d ventago -v ON_ERROR_STOP=1 \
  -f api-ventago/migrations/phase36-stock-movement-actions-backfill.sql

# Post-state 검증
psql -h localhost -p 5432 -U $USER -d ventago -c "
  SELECT r.slug AS role_slug, rf.store_id, ARRAY_AGG(rfa.action ORDER BY rfa.action) AS actions
  FROM role_functions rf
  JOIN roles r ON r.id = rf.role_id
  LEFT JOIN role_function_actions rfa ON rfa.role_function_id = rf.id
  WHERE rf.function_id = 149
  GROUP BY r.slug, rf.store_id
  ORDER BY r.slug, rf.store_id;"
```

**Acceptance:**
- pre_count = 4 (Phase 35 시점 확인됨)
- post-state 의 actions 컬럼이 모든 행에 `{create, delete, read, update}` 표시
- 모든 12 role_functions 행이 4 actions 매핑됨 → 총 48 행
