<objective>
Stocks Panel B 마지막에 **En producción** / **Listo aprox.** 두 열을 붙인다.

Purpose: 이 화면은 발주·이동 판단에 쓰인다. 지점별 수량은 DB 에 없는 **파생 추정치**이므로
(FINDINGS F1 · C5), 화면이 그 사실을 **툴팁이 아니라 값 옆에서** 말해야 한다.
</objective>

<constraints>
- `≈` 는 툴팁에 숨기지 않는다 — **숫자와 같은 시각적 무게**로 상시 노출(CODEX C5).
- TOTAL 행은 **원본 합계**를 쓴다. 지점 행 값을 다시 더하지 않는다.
- 권한 없으면 `—` 로 가리지 말고 **열을 만들지 않는다**.
- 행 높이는 Phase 79 규약(30px)을 따른다 — 2줄 셀을 만들지 않는다.
</constraints>

<tasks>
1. `En producción` 열: `≈ {estimatedBranchWipQty}` (지점 선택 시) / 전체 보기면 원본 총량.
   툴팁: "Distribución estimada en partes iguales; no es una asignación confirmada" +
   `allocationBranchCount` · `allocationAsOf`.
2. `Listo aprox.` 열 — `etaStatus` 에 따라:
   - `KNOWN` → 날짜
   - `PARTIAL` → `날짜 +N sin definir`
   - `UNKNOWN` → `미정`
   - `OVERDUE` → `Atrasado desde YYYY-MM-DD` (미래 날짜처럼 보이지 않게 색 구분)
3. 내역(공방 내 / 공정 사이 / 재고 미반영 / rework)은 열을 늘리지 말고 **툴팁 또는 셀 클릭 팝오버**로.
4. 권한 없으면 두 열을 `columns` 배열에서 **제외**(조건부 push).
5. 정렬은 권한자에게만 활성화.
</tasks>

<verification>
- 지점 3개 매장에서 지점 행 합 = TOTAL (화면 실측)
- 권한 없는 계정으로 열이 **보이지 않음** + 네트워크 응답에도 없음
- 지연 로트에서 `Atrasado desde` 로 보임
- 행 높이 30px 유지, 셀 잘림 없음
</verification>
