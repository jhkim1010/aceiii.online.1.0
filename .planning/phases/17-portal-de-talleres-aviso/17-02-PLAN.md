**2. VendorRecepcionesService** (per D-08 — 수령 확인):
- `createRecepcion(vendorIds: number[], dto: { envioId, receivedQuantity, rejectedQuantity?, notes? })`:
  - 트랜잭션 사용: `sequelize.transaction(async (t) => { ... })`
  - envio 조회: `Envio.findByPk(dto.envioId, { include: [Vendor], transaction: t })`
  - envio.vendorId가 vendorIds에 포함되지 않으면 `ForbiddenException('No tiene acceso a este envio')`
  - receivedQuantity + rejectedQuantity가 envio.pendingQuantity 초과 시 `BadRequestException('Cantidad excede pendiente')`
  - `Recepcion.create({ envioId, receivedQuantity, rejectedQuantity: dto.rejectedQuantity || 0, recepcionDate: new Date().toISOString().split('T')[0], notes: dto.notes, storeId: envio.vendor.storeId }, { transaction: t })`
  - `envio.pendingQuantity -= (receivedQuantity + (rejectedQuantity || 0))`
  - pendingQuantity가 0이면 `envio.status = EnvioStatus.COMPLETED`, 아니면 `EnvioStatus.PARTIAL`
  - `envio.save({ transaction: t })`
  - 알림 생성: Plan 02 Task 2에서 처리하는 VendorNotificationsService는 아직 없으므로, 여기서 직접 `VendorNotification.create({ vendorId: envio.vendorId, storeId: envio.vendor.storeId, type: 'NEW_ENVIO'... })` 하지 말고, 수령 확인 시에는 **매장 측에 알림**이 가는 것이므로 vendor notification 생성 불필요. (매장 알림은 Phase 범위 외)
