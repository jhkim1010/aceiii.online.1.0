<objective>
zebra-agent 의 QR 라벨 생성기 + 백엔드 통신 계층. `zpl-formatter.js` 에 순수 함수 `formatQrLabel` 추가
(1:3 좌우 분할, doble 복제, layout 수치 반영, 좌 QR = qrUrl 인코딩) + `main.js` IPC 2개
(`qr:fetchPending` -> get_qr_pending ack, `qr:print` -> formatQrLabel + sendZpl 항목별 -> 성공분 mark_qr_printed)
+ `preload.js` 노출.

Purpose: 델타 리스트를 받아(38-01 백엔드), 선택 항목을 Zebra 접착 라벨(좌 QR / 우 이름+가격, D-8)로
출력하고, 출력 성공분만 서버에 스냅샷 기록(D-11)해 다음 델타에서 빠지게 한다. 부분 실패(프린터
오프라인 등)는 항목별로 처리해 전체 배치를 중단하지 않는다.

Output: formatQrLabel 순수 함수 + node assert 단위 테스트, qr:fetchPending/qr:print main IPC,
preload 브릿지. 기존 sendZpl(TCP9100/USB), ^BQN QR 케이스, emitWithAck 패턴을 재사용한다.

DECISION - 통신은 WebSocket ack(emitWithAck)다(38-01 objective 참조). 기존 products:fetchByDate
(get_stock_today), priceTypes:fetch(get_price_types)와 동일하게 wsConnection.timeout(ms).emitWithAck(...)
를 쓴다. HTTP 클라이언트를 새로 도입하지 않는다(재발명 금지). 서버는 API key 로 branch/store 를 도출하므로
에이전트는 priceTypeId 와 items(성공분)만 보낸다.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-06 | Tampering | name/qrUrl 에 ^ 또는 ~ 가 섞여 ZPL 명령 injection | mitigate | formatQrLabel 이 sanitize()로 ^,~ 제거 후 ^FD 삽입 (기존 formatLabel 과 동일) |
