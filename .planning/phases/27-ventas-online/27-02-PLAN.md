## 서비스 메서드 (10개)

1. `findFiltered(storeId, filters, pagination)`
2. `findById(storeId, id)`
3. `create(storeId, userId, dto)` — 트랜잭션, order_number 자동
4. `confirmOrder(storeId, id, userId)` — SERIALIZABLE, 재고 차감
5. `prepareOrder(storeId, id)`
6. `shipOrder(storeId, id, dto)` — carrier + trackingCode
7. `deliverOrder(storeId, id)`
8. `cancelOrder(storeId, id)` — SERIALIZABLE, 재고 복구
9. `getDashboard(storeId, range)`
10. `createReturn` / `updateReturnStatus`

## 권한

- 읽기: admin/superadmin/gerente/vendedor
- 쓰기: admin/superadmin/gerente
- 반품 승인: admin/superadmin

## 수용 기준

- 모든 status 전환 메서드는 현재 status 검증 후 진행 (잘못된 전환은 `BadRequestException`)
- Logger.debug 로 status 전환 추적
- 트랜잭션 finally 에서 commit/rollback
- `npm run build` 통과
