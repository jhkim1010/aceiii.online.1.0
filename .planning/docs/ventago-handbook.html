4아키텍처 핵심 규칙

프린터 에이전트 · MinIO · API 서비스 · 인증 컨텍스트의 공통 규약.

프린터 에이전트 구조

branch_agents (지점당 N개 등록 가능)
  branchId    # NOT UNIQUE → 다중 프린터
  agentType   # 'thermal' | 'zebra'
  label       # 'Comandera Cocina' 등
  apiKey      # UNIQUE (에이전트별 고유)
  isOnline, socketId, lastSeenAt

terminals (터미널별 에이전트 매핑)
  thermalAgentId FK → branch_agents
  zebraAgentId   FK → branch_agents

파일 업로드 (MinIO)

· MinioModule 을 해당 모듈 imports 에 추가
· MinioService.uploadFile(file, fileName) → { fileName } 반환
· 프론트 이미지 URL: {API_HOST}/minio/{fileName}

인증 컨텍스트

· useAuth() 훅으로 user 접근 — storeId · storeName · aliasName · logoUrl + 권한 정보 포함
· AuthContext + BranchContext 분리: selectedBranchId 는 BranchContext 에서 관리 → 지점 전환 시 110+ 컴포넌트 불필요 리렌더 방지
· auth 응답은 auth.service.ts 의 /me 엔드포인트에서 구성

5세션 & 터미널 보안

🔒active_sessions

유저당 1개만 존재 (UNIQUE userId). 새 로그인 시 기존 세션 삭제 → 기존 세션 즉시 401 SESSION_EXPIRED

public IP ↔ 지점(sucursal) 매핑. 새 IP 접속 시 지점 등록 강제

7성능 최적화 규약

300ms 타겟 — 모든 사이드바 메뉴 클릭 → 콘텐츠 렌더 완료까지 P95 ≤ 300ms.

프론트엔드 규약

· 코드 스플리팅 필수: 신규 페이지는 next/dynamic(() => import(...), { ssr:false })
· SWR 캐시: 참조 데이터(sizes/colors/categories/…)는 src/hooks/api/ 훅 (5분 dedup)
· useEffect+apiConnector.get 금지 (참조 데이터) → SWR 훅 교체 필수
· 순차 API 호출 금지 → Promise.all()
· Context value 반드시 useMemo
· 고트래픽 리스트에 React.memo (ProductsList, SalesListView)
· 이미지 next/Image · Pagination pageSize 최대 50 (500 금지)
· AG Grid ensureAgGridInit() 1회만 호출

백엔드 규약

· 인메모리 캐시: 참조 데이터 60초, 대시보드 30초 TTL (MemoryCacheService)

12주의 사항 & 디자인 규약

핵심 주의 사항

· front-end의 lint 오류에 특히 주의
· apiConnector.remove() 사용 (.delete() 아님)
· DB 마이그레이션은 api-ventago/migrations/ SQL을 운영 Docker에서 직접 실행
