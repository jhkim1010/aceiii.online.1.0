## 5. 환경 메모
- `export NODE_OPTIONS=;` 를 node 명령 앞에.
- 커밋 게이트: `git add` 와 `git commit` 을 같은 명령에 두지 말 것. eslint 는 **추가한 줄만** 본다 — 기존 파일에 `eslint --fix` 금지(무관한 줄이 섞임), 새 파일은 OK.
- 자동 포맷 뒤 Python 치환이 안 맞으면 공백 무시 매칭(scratchpad `repws.py` 방식).
- zsh 는 `$r` 를 단어로 나누지 않는다 — `set -- $r` 로 만든 점검 스크립트가 전부 400 을 낸 적이 2번. `${r%% *}`/`${r#* }` 사용.
- CODEX 자동 훅은 diff 에 자격증명 형태(테스트용 `token: 't'`)가 있으면 멈춘다 → diff 를 직접 넘겨 `codex exec` (cd /private/tmp 에서 실행하면 이전 세션 이어 붙이기가 안 섞임).
