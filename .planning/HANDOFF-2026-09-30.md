## 2. 결함 원인 기록 (재발 방지)
- **Express 5 쿼리 파서 = simple**: `status[]=0&status[]=1` → `{"status[]":[…]}`. `@Query('x')` 로 배열을 받는 곳은 전부 의심. 이번엔 price-types 1곳만 고쳤다 — **프론트가 배열을 보내는 다른 엔드포인트 전수 조사 미실시.**
- **프론트 인터셉터는 login/me 외 모든 401 을 로그아웃으로 처리**(`api.service.ts:256`). 서버에서 «인증 실패가 아닌 것»에 401 을 쓰면 사용자가 튕긴다. 매장 없음·권한 없음은 401 금지.
- **yup `mixed().required()` 는 `""` 을 통과**시킨다 → 역할 없는 사용자가 만들어졌다.
- **`user_roles` 에는 store_id 가 없어** 테넌트 훅이 역할 id 를 검사하지 않았다(다른 매장/전역 역할 부여 가능했음). 운영 데이터는 위반 0건.
- 사진 업로드 경로는 **원래 파일 이름 그대로 MinIO 에 저장**(`IMG_0001.jpg`) — 매장 간 덮어쓰기 가능. Biblioteca 는 `lib-<store>-<uuid>` 로 피했지만 **기존 상품 업로드 경로는 그대로.**
- CODEX 백그라운드 실행은 `</dev/null` 필수(메모리 갱신함). 한동안 «검토 중»이 실제로는 안 돌았다.
- 커밋 게이트가 `grep -a` 를 `commit -a` 로 오인 → 커밋은 단독 명령으로.
