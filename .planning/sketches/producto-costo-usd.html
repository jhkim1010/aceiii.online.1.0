목업 메모 (v2)

원가를 ARS/USD 로 넣고 달러 환율로 Precio base 를 계산합니다. 이번 판은 CodigoVista 에서도 조정할 수 있게 했고, Productos nuevos 는 compact 로 줄였습니다. 앱 코드는 바꾸지 않았습니다.

v1 에서 바뀐 것

  • v2 탭 3개로 나눴습니다: Productos nuevos · CodigoVista · Cotización.
  • v2 Productos nuevos: 별도 「Costo」 행과 큰 환율 상자를 없앴습니다. 기존 「Precio base」 칸 자리를 「Costo → Precio base」 복합 칸 하나로 바꿨습니다: [ARS|USD] · 원가 + % = 기준가. 환율 계산식은 그 아래 한 줄 캡션입니다. 폼 높이는 캡션 한 줄만 늘어납니다. 컨트롤은 24px, 버튼은 26px 로 30px 행 규약 안에 들어갑니다.
  • v2 CodigoVista: 표에 Mon · Costo · % 열을 추가했습니다(「Mostrar costo」로 숨길 수 있음). 선택 행에서 편집하면 기준가가 즉시 다시 계산되고, 행이 호박색으로 표시되며 옛 가격은 취소선으로 남습니다. 선택 행 일괄 작업: 「Pasar a USD/ARS」, 「Recalcular con dólar」. 오른쪽 패널에는 「💵 Dólar」 탭을 추가했습니다.
  • v2 Cotización 탭: v1 의 환율 카드와 적용 미리보기를 더 조밀하게 줄였습니다(옵션 3개를 한 줄로).

결정이 필요한 것 (v1 공통)

  1. 환율 출처 — 수동만 할지, BNA·블루·MEP 자동 조회도 할지.
  2. 적용 방식 — 확인 후 적용(목업안)인지, 자동 적용인지.
  3. 반올림 — 단위와 방향. 매장 설정인지 매번 선택인지.
  4. % 의 의미 — 목업은 원가×(1+%) 입니다. 가격유형은 「기준가의 N%」 관행이라 읽는 법이 다릅니다.
  5. 따라가는 레벨 — % 레벨만 따라갈지, 수동 레벨도 따라갈지.
  6. 저장 위치 — cost · cost_currency · 「기준가 수동 고정」 표식을 어디에 둘지. 환율 이력 테이블도 새로 필요합니다.

결정이 필요한 것 — CodigoVista 신규

  1. 어느 열을 원가가 움직이나 — CodigoVista 의 BASE 열은 가격유형 레벨이고, Productos nuevos 의 기준가는 products.price 입니다. 원가 → 기준가 계산이 둘 다 쓰도록 할지, 먼저 기준 레벨 판정을 한 곳으로 합칠지.
  2. 자식 변형 전파 — 부모의 원가·통화·% 를 자식이 물려받을지(목업: 물려받음). 자식별로 원가를 따로 가질 수 있게 할지. 부모 기준가를 저장하면 자식끼리 다르던 가격이 통일됩니다(메모리 기준 약 13%).
  3. 저장 시점 — 지금 CodigoVista 는 셀 blur 에 바로 저장합니다. 원가 편집도 그렇게 할지, 목업처럼 「Guardar cambios (N)」 → 확인 → Deshacer 흐름으로 모아서 저장할지. 모으는 쪽이 환율 일괄 재계산과 맞습니다.
  4. 두 화면이 같은 상품을 고치면 — 마지막 저장이 이기게 할지, 저장 시 「본 값과 현재 값」을 비교해 충돌을 경고할지. CodigoVista 에서 기준가 셀을 손으로 고치면 그 상품을 「수동 고정」으로 돌릴지.
  5. 열 폭 — 원가 3열을 기본으로 보일지, 「Mostrar costo」를 켜야 보이게 할지(레벨이 많은 매장은 가로 스크롤이 늘어납니다).
  6. 엑셀 가져오기 — CodeImportDialog 에 cost · cost_currency 열을 추가할지.
