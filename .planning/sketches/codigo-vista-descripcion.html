Código Vista › 📝 Descripción (배포됨)

배포된 코드(DescripcionTab.tsx)를 그대로 옮긴 목업입니다. 위쪽 버튼으로 상태를, 표의 행을 눌러 상품을 바꿔 보세요. 칸에 쓰면 아래 「Vista en la web」가 바로 바뀌고, 「Guardar」가 켜집니다.

상태

  • Sin selección — 표에서 상품을 고르라는 안내.
  • Código madre — 그 설명을 5칸으로 편집, Descartar / Guardar.
  • Variante — 부모의 설명이 열리고 노란 안내 「la comparten todas sus variantes」.
  • Sin permiso — 「Editar un producto」 권한이 없으면 읽기 전용.

저장

  • PUT /products/:madreId 에 { description } 만 보낸다 — 다른 값은 안 건드린다.
  • 저장 형식은 상품 폼과 같은 HTML(WooCommerce 호환). 오른쪽 아래 미리보기는 그 HTML 이 웹에서 보이는 모양.

목업에만 있는 제안 3개 (실제 탭에는 아직 없음)

  • 「● Cambios sin guardar」 — 고친 뒤 저장 안 했음을 알려 줌. 실제는 Guardar 버튼이 켜지는 것만으로 알린다.
  • 「Vista en la web」 — 저장될 HTML 이 웹에서 보이는 모양.
  • 표의 초록 점 — 설명이 있는 코드 마드레 표시. 어느 상품이 비어 있는지 한눈에.

넣을 것을 골라 주시면 반영하겠습니다.
