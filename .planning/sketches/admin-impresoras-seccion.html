Cómo instalar

  1. Agregá el agente acá (sucursal + tipo + nombre). Se genera su clave.
  2. Instalá el programa en la PC que tiene la impresora conectada.
  3. Pegá la clave en el asistente (📋 Copiar en la pestaña Agentes). Una clave por PC.
  4. Asignala a las terminales en la pestaña Terminales y probá con «Probar».

설계 메모 — Admin › Impresoras

  1. 위치: Admin 그룹에서 Configuración 바로 다음. DB 모듈 impresoras(url /impresoras) 시드 → 사이드바는 structure 에서 파생되므로 시드를 코드보다 먼저 적용.
  2. 모으는 것 (지금 3곳에 흩어짐):
    · Sucursales › [지점] › Impresora 페이지 → Agentes 탭
    · Sucursales 의 에이전트 API Key 칼럼 → 같은 탭
    · 터미널 편집 모달의 Comandera·Adicionales·Zebra → Terminales 탭(한 표에서 일괄 편집)
  3. 새로 생기는 것: 매장 전체 한눈 요약 + 문제 감지(예: 기본 없는 터미널 + comandera 2대 = 티켓 안 나감 — 지금은 로그에만 남는 NOIX 사례).
  4. Sucursales 쪽: 기존 페이지는 한동안 남기고 「Gestionar en Impresoras →」 링크로 안내 → 다음 단계에서 제거.
  5. 권한: 보기 = 모듈 impresoras. 추가·수정·삭제·키 = 지금처럼 crear/editar/eliminar-terminal 그대로(서버 가드 변경 없음).
  6. API: 매장 단위 목록 1개 추가(GET /print/agents — 지점별 호출 N번 대신). 나머지는 기존 엔드포인트 재사용.

결정해 주실 것

  1. 메뉴 이름: Impresoras / Agentes de impresión / Dispositivos
  2. Sucursales 의 기존 Impresora 페이지: 링크로 남김 / 바로 제거
  3. 터미널 모달의 프린터 칸: 남김(두 곳 편집) / 이 화면으로만
