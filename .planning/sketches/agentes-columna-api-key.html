  2. 만들면 키가 자동으로 생깁니다 — 이건 지금도 그렇습니다(모델 기본값). 달라지는 점은 「Crear」 직후 키를 보여 주는 확인 창(복사 버튼 + 설치 안내)입니다. 지금은 생성 응답의 키를 화면이 버립니다.
  3. 재발급(🔄)은 그대로 두되, 끝나면 새 키가 같은 칼럼에 바로 반영돼 클릭으로 복사됩니다.
  4. Sucursales 🔑 제거: 지점 단위 키는 실제로는 「그 지점 thermal 에이전트 중 아무거나 하나」를 재발급하고, 없으면 여는 순간 에이전트를 만들어 버립니다. 버튼·모달·/print/config/:branchId 삭제.
  5. 전체 키는 목록 응답에 싣지 않습니다. 클릭 순간 POST /print/agents/:id/key(권한 확인 + 감사 로그 「누가 언제 복사」)로 받아 바로 클립보드에 넣습니다.
  6. 기존 키는 절대 바꾸지 않습니다. 이 작업은 화면·조회 API 만 바꾸고 api_key 값은 건드리지 않습니다. NOIX(매장 19, 지점 28)의 caja(#20)·caja1(#21)이 오늘도 붙어 있었습니다 — 배포 전후 키 지문(md5 앞 12자) 대조로 확인합니다.
  7. edge 유형(Edge Sync Agent)도 같은 테이블이라 같은 방식으로 복사됩니다.
