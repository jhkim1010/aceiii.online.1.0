E-2 · 완료 판정 = 컬럼이 아니라 술어(predicate)

단계단위완료 조건 (파생)

E-3 · 저장하는 것은 «의도» 뿐

store_onboarding_state          -- 완료 여부는 저장하지 않는다
  store_id, branch_id NULL, step_code
  dismissed_at   timestamptz NULL   -- "No aplica" → 분모에서 빠진다
  snoozed_until  timestamptz NULL   -- "Recordármelo luego"
  UNIQUE (store_id, branch_id, step_code)

onboarding_events               -- append-only 원장 (분석 + 완료 고정)
  store_id, user_id, step_code, event, occurred_at
세 가지 함정 ① 해당 없는 항목이 영원히 미완으로 남는다 → 모든 항목에 «No aplica». ② 완료 후 데이터를 지우면 미완으로 되돌아간다 → onboarding_events 의 completed 가 이긴다. ③ 홈 화면마다 EXISTS 8회 → 60초 캐시 + 이벤트 원장 우선 조회.
