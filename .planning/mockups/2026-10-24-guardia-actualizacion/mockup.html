Cómo funciona (propuesta)
  1. Guardia va a informar su versión al conectarse (por el socket que ya usa con el servidor). El servidor compara con la última publicada (GitHub Release guardia-latest, igual que las otras apps).
  2. Nunca se actualiza sola: alguien con permiso toca «Actualizar…» en la web y confirma.
  3. Guardia descarga el paquete, verifica sha256, lo prepara en una carpeta aparte (con npm install) y sólo entonces cambia de versión y se reinicia (la tarea de Windows la levanta). Si algo falla, queda la versión anterior.
  4. No se actualiza con ventas offline sin subir ni con una venta en curso. Los datos locales (DB ventago_edge, config.json) no se tocan.
