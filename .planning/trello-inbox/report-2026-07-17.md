### 6a591931 — Impresion de precios (VentaGo / zebra-agent) — `lo más urgente` 없음, 최신 활동

**증상:** 가격 라벨 인쇄 시 첫 번째 가격 **PRECIO 1** 을 선택하면 인쇄되지 않음.

**존재 검증 (DB 대조):** `price_types` 의 `PRECIO 1` 이 store 6·12·15 등에서 **`prices` 행 0개** — base 가격이 `products.price` 컬럼에만 존재. zebra-agent payload 를 만드는 `getStockTodayForAgent` / `searchProductsForAgent` 는 `p.prices`(테이블 행)만 매핑하므로 PRECIO 1 이 payload 배열에 **아예 포함되지 않음** → 에이전트의 `price-select.js` 매칭 실패 → 미인쇄. (반면 QR 경로 `buildQrPayload` 는 이미 base 폴백이 있었음 — 리스트 빌더 2곳에만 누락.)

**수정:** `api-ventago/src/app/print/print.service.ts`
- `getBasePriceType(storeId)` 추가 — 매장 최초 price type 1 SELECT (pool 안전, order id ASC findOne).
- `buildAgentPrices()` 추가 — 기존 price 행 + base 폴백 병합(순수 메모리). 행 없으면 `products.price` 로 PRECIO 1 보강 (buildQrPayload 와 동일 규칙).
- `getStockTodayForAgent` / `searchProductsForAgent` 두 경로 모두 적용.

**브랜치 / 커밋:** `fix/trello-6a591931` @ `602173e` (origin/main 기준, 단일 파일 +54/-10)
