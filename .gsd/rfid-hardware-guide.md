## 1. ★아르헨티나 주파수 규격 (구매 전 필수 확인)

아르헨티나는 ITU **Region 2**로 UHF RFID 대역이 **902–928 MHz(FCC 계열)**입니다. 미국·브라질과 동일 대역이며 유럽(865–868 MHz, ETSI)과 **호환되지 않습니다.**

- 리더·안테나·인레이 모두 **US/FCC(902–928 MHz) 모델**로 발주. EU 모델 구매 시 인식 불가·규제 위반.
- 벤더 견적 요청 시 "**Region 2 / FCC / 902–928 MHz**" 명시.
- 아르헨티나 반입 시 ENACOM 인증(homologación) 필요 여부를 디스트리뷰터에 확인.

## 2. 태그 발행기 — Zebra ZD621R

의류/소매 파일럿에 4" 데스크톱 프린터-엔코더가 표준입니다.

- **Zebra ZD621R**: 열전사 4" 데스크톱, ZPL `^RFW` UHF 인코딩 지원 → 기존 `zebra-agent` ZPL 파이프라인을 그대로 확장(신규 개발 최소).
- 대안: **ZD611R**(소형/좁은 라벨), **ZT411R**(산업용 대량).
- 소모품: **UHF 인레이가 내장된 열전사 라벨/의류 행택**(Region 2). 프린터 롤 규격(폭·인레이 위치=pitch)을 프린터 사양과 맞춰 구매.

## 3. 계산대 리더 — 근접(Near-Field) 확정형이 정답

계산대의 유일한 난제는 **"바구니 안 상품만 읽고, 옆 계산대·진열대 상품은 안 읽는 것"**입니다. 원거리(far-field) 포털 리더는 몇 미터를 읽어 **오독(stray read)**이 납니다. 해법은 **근접 안테나(near-field)**로 읽는 영역을 손바닥~바구니 크기로 국한하는 것입니다.

권장 구성: **고정 리더 + UHF Near-Field 안테나(리드 패드/트레이)**. 캐셔가 바구니를 패드 위에 올리면 그 안 상품만 일괄 인식됩니다.

- 리더 후보: **Zebra FX7500**(2포트, 카운터급·경제적) 또는 **FX9600**(4포트·견고), LLRP over TCP. 벤더 중립 대안 **Impinj R700**(LLRP/REST).
- 안테나: **UHF Near-Field 안테나**(예: Times-7 근접 패드 계열 등) — 최종은 데모로 결정.
- 튜닝 포인트: **송신 출력(power)을 낮추고** 안테나를 트레이 하부에 배치해 read-zone을 물리적으로 가둠. 필요 시 금속 트레이/차폐로 경계 강화.
- 데스크톱 리더/라이터(초근접 1~소량 태그)는 **바구니 일괄 읽기엔 부적합** — 발행 검증용 보조로만.

## 4. 태그(인레이) 선택

- **UHF Gen2(RAIN) 의류 행택 인레이, Region 2(FCC 902–928)**.
- 부착 대상이 금속·액체 근처면 성능 저하 → 파일럿 상품군(의류 위주)엔 일반 의류 인레이로 충분.
- 발행기 롤 규격과 **동일 pitch**로 발주(프린터-엔코더가 인레이 위치를 알아야 인코딩됨).
- EPC 스킴은 SPEC의 `epc-scheme.ts`(store+product+serial → 96bit)에서 서버가 생성·발행하므로, **사전 인코딩 없는 "빈(unprogrammed) 인레이"**를 구매(우리가 직접 굽는다).

## 5. TASK-0 검증 체크리스트 (통과해야 코딩 확정)

데모기(리더+near-field 안테나+ZD621R+인레이 소량)를 확보해 실제 계산대 환경에서 아래를 측정합니다. **모두 통과해야 Wave 1(서버) 이후를 하드웨어 확정 기준으로 진행.**

- [ ] **발행/인코딩**: ZD621R로 인레이에 EPC 굽기 성공, 리더로 되읽어 EPC 일치 확인
- [ ] **바구니 완독률**: 대표 바구니(예: 의류 15~30점)를 패드에 올렸을 때 **≥99%** 1회 인식(누락 태그 수 기록)
- [ ] **오독률(핵심)**: 인접 계산대(≈50cm)·진열대 상품이 **읽히지 않음**(stray read 0 목표) — 출력/안테나 위치 튜닝 후 측정
- [ ] **처리 시간**: 바구니 1건 인식 완료까지 목표 시간(예: ≤2초) 확인
- [ ] **중복/노이즈**: 같은 태그 반복 read가 에이전트 dedup 윈도우로 잘 합쳐지는지(부하 관점)
- [ ] **주파수/규제**: 장비·인레이가 902–928 MHz(FCC)인지, ENACOM 반입 이슈 없는지
- [ ] **연속성**: 10~20 바구니 연속 처리 시 리더 안정성(LLRP keepalive, 재연결)

측정값은 이 문서 하단 "검증 로그"에 기록해 벤더/모델을 확정합니다.

## 6. 조달 경로 & 액션

1. 현지/미주 RFID 디스트리뷰터에 **Region 2 기준** 견적 요청: ZD621R + 리더(FX7500/FX9600 or R700) + **near-field 안테나** + 빈 UHF 인레이 소량.
2. 가능하면 **데모기 대여(demo/eval unit)** 요청 — 구매 전 5항 검증.
3. Zebra 파트너면 기존 zebra-agent 사용 이력으로 상담 유리.
4. 예산은 견적으로 확정(모델·환율 변동) — 파일럿은 리더 1 + 안테나 1~2 + 발행기 1 + 인레이 소량 규모.

## 7. 다음 단계

- 5항 검증 통과 → 리더 모델/드라이버(LLRP) 확정 → SPEC의 Wave 4(TASK-10 LLRP부) 실구현.
- **병행 권장**: 하드웨어 발주·데모 대기 동안 서버 Wave 1~2 + mock reader로 E2E를 먼저 완성(하드웨어 도착 즉시 결합).
