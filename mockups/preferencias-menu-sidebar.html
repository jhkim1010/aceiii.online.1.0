Funciones visibles en esta tienda
Elegí qué secciones aparecen en el menú lateral para los miembros de tu tienda. Ocultar una sección no borra datos ni cambia permisos: sólo deja de aparecer. La podés volver a mostrar cuando quieras.
ℹ️
Las secciones que un usuario no tiene permitidas ya no le aparecen. Esto es un paso más: aunque tenga permiso, si la tienda no usa la función, no la ve.
¿Y el administrador?
Lo oculto puede seguir viéndolo el admin (marcado «oculto»), para no perder el camino de vuelta.
Aunque elija «Nadie», Configuración › Preferencias nunca se oculta: siempre se puede volver acá.
