설계 노트 — 웹에서 그대로 옮기지 않은 것
  • 스코프 바를 붙박이로. 웹은 화면이 넓어 날짜·지점 맥락이 늘 보이지만 폰은 스크롤하면 사라집니다. 어느 날짜·어느 지점을 고치는지 착각하면 재고가 엉뚱한 곳에 들어갑니다.
  • 범위를 바꾸면 확인받습니다. 편집 중에 날짜·지점을 바꾸면 입력이 무효가 되므로 "Cambios sin guardar" 다이얼로그로 묻습니다 — 조용히 버리지 않습니다.
  • 저장 전 요약. 재고를 움직이는 저장이라 수량 N건 / 변형 N개 / 색상 N개 삭제를 먼저 보여줍니다. talleres mockup 에서 세운 원칙과 같습니다 — 누른 뒤에 알면 늦습니다.
  • 삭제 단위는 색상입니다(deleteColorIds). 그래서 목록을 색상별 카드로 묶었습니다 — 삭제 버튼이 어디에 걸리는지 구조로 드러납니다. 삭제 표시하면 그 색의 수량 수정은 자동 해제됩니다(의미가 없어서).
  • 같은 색×사이즈를 두 번 추가하면 백엔드에서 중복 변형이 됩니다 → 시트에서 막습니다.
  • 저장 실패 시 서버 메시지를 그대로 띄웁니다. Error 만 띄우면 원인이 사라집니다.
