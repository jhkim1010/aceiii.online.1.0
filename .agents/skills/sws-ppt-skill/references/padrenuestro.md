# Padre Nuestro (주기도문) — 고정 텍스트 (3 페이지)

Anuncio **뒤**(예배 맨 마지막)에 3장으로. 사용자가 준 음절 구분(하이픈)은 노래용이므로 **그대로 유지**. 수정 금지.

## Página 1
```
Pa-dre nues-tro
que estás en el cie-lo
San-ti-fi-cado se-a tu nombre
ha-ga-se hoy-
Tu vo-lun-tad en la tierra
como en el cie-lo
```

## Página 2
```
Da-nos oh Dios el pan de hoy
Y per-dona-nos nuestras deudas como
Nosotros per-do-na-mos
```

## Página 3
```
y no nos
Metas en ten-ta-cion-es mas libra-nos
Del mal porque tu-yo es el rei-no
Tu po-der y la glo-ria para siem-pre
A---men
```
