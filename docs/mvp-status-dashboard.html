MVP 갭 — 첫 10명 유료 고객까지 막고 있는 것

1. Store Lifecycle (P9) — 고객을 '관리'할 수 없음

Trial 30일 → 자동 정지 → 수동 활성화가 없으면 무료 사용자만 늘어남. 과금의 기술적 전제. 예상 2주.

2. AFIP 전자영수증 (P10) — 판매 자격 요건

정식 영업 매장은 factura 없이는 도입 불가. relay(invoice.coolsistema.com) 재사용 설계가 이미 있어 예상 2~3주.

3. 데이터 이전 (P5) — 전환 장벽

기존 POS(todocodigos) 상품 데이터를 못 옮기면 영업이 안 됨. 백엔드는 완료, UI+검증만 남음. 예상 1주.

4. POS 코어 버그 0건 (Trello 잔여 6건)

첫 고객의 첫 인상. B8(suspender)·B6(색상/사이즈 미갱신)·B5(prefijo) 우선. 일일 루프로 소진 — 예상 1~2주 병행.

5. 온보딩 + 매뉴얼

셀프 등록 → 기본 세팅 → Manuales 4종. 과금은 MVP 단계에선 수동 청구(transferencia/MP 링크)로 충분 — CoolPay 는 고객 10명 검증 후.

첫 10명 고객 — 6주 실행 플랜

1~2주차 — 안정화

  • Trello 버그 일일 루프로 소진 (6→0)
  • P42 UAT 마감, P28·PhaseA 운영 적용
  • 가격 수정 직원 검증 완료

2~4주차 — MVP 게이트

  • P9 Store Lifecycle (trial/정지)
  • P10 AFIP (relay 재사용)
  • P5 임포트 UI 마감

4~5주차 — 온보딩

  • Manuales 4종 (문서 에이전트 초안)
  • 셀프 등록 → 기본 세팅 점검
  • 가격표: 예) 매장당 월 구독 + 지점 추가

5~6주차 — 영업

  • 기존 4매장 → 추천 2명씩 (Avellaneda/Flores 도매상권)
  • trial 30일 + 데이터 이전 무료 제공
  • 주간 지표: trial 전환율·이탈 사유 리포트

확장 가능성 (10명 검증 후)

검증된 순서: ① 공개몰(P51, 진행 중) → ② AI 피팅(P49) → ③ CoolPay(P50). 그 외 이미 자산이 있는 것: TiendaNube/Shopify 커넥터(P43/44 설계 완료), 모바일 판매 앱(P37 스펙 락), 외주 포털(P17 완성 — CMT 업계 세일즈 포인트), 레스토랑 모드(P39/40 — 별도 버티컬). 원칙은 사장님 말씀대로 — 소득 없는 확장은 안 함. 각 확장은 유료 고객 10명 이후, 고객 요구 빈도순으로.
