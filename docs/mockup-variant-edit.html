사용 흐름 (UX Flow)

  1. Historial에서 Codigo Madre 제품 클릭
  2. 우측 패널에 Color x Talle 매트릭스 표시
  3. 삭제: 잘못된 행의 🗑 클릭 → 취소선 표시 (즉시 삭제 X, 확인 후 반영)
  4. 추가: 하단 "Agregar variante" 에서 색깔+talle+수량 선택 → + 버튼
  5. 수량 수정: 매트릭스 셀 직접 클릭 → 인라인 편집
  6. 모든 변경 확인 후 Guardar cambios 클릭 → 일괄 반영
